# 调试

输入：冻结任务目标、资源范围、约束、共享进度和当前证据。

记录复现条件、时间窗口及环境。使用受限日志、固定查询和对照探测，逐项改变一个假设。保护用户数据并遵守输出限制。复现结果必须有工具来源；无法复现则报告观测窗口与限制。不要从时间相关性直接推断根因，也不要反复执行相同无信息探测。

输出：有出处的发现、行动或产物引用、验收结果及未验证项。权限、预算或执行环境不足时通过共享进度交回受阻事实，不扩大授权。
