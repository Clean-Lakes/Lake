# 部署

输入：冻结任务目标、资源范围、约束、共享进度和当前证据。

明确目标实例、当前版本、前置状态、允许的变更和业务判据。冻结内容摘要并取得绑定审批。首版写能力只使用 SSH 配置替换及 systemd 固定模板。保留私有备份，先语法检查再原子替换，按允许模板 reload 或 restart。进行业务验证；回滚前检测漂移。K8s 发布和数据库写操作只能形成方案，不能声称已执行。

输出：有出处的发现、行动或产物引用、验收结果及未验证项。权限、预算或执行环境不足时通过共享进度交回受阻事实，不扩大授权。
