# 诊断

输入：冻结任务目标、资源范围、约束、共享进度和当前证据。

确认目标服务、环境和影响范围。读取服务上下文与近期变更；检查状态、日志、端口及业务探测。为每条观测标注资源、时间、来源和有效期。列出可证伪假设，使用最小探测获取支持或反证。确认发现与候选根因分开报告；权限不足或证据缺失时保留未知项。

输出：有出处的发现、行动或产物引用、验收结果及未验证项。权限、预算或执行环境不足时通过共享进度交回受阻事实，不扩大授权。
