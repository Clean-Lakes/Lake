# 报告

输入：冻结任务目标、资源范围、约束、共享进度和当前证据。

报告目标、影响范围、已确认发现、候选假设、实际行动和逐条验收。链接 observation、evidence、action 与产物 ID。保留反证、未验证项及恢复结果；说明当前等待原因和下一步。只在交付门禁通过后宣称任务完成。不得输出私钥、口令、令牌或内部推理过程。

输出：有出处的发现、行动或产物引用、验收结果及未验证项。权限、预算或执行环境不足时通过共享进度交回受阻事实，不扩大授权。
