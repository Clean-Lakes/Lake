# 验证

输入：冻结任务目标、资源范围、约束、共享进度和当前证据。

读取冻结的必须与可选验收判据。为本次行动、资源身份和版本采集新证据；过期观测不作为当前证明。服务恢复检查业务响应与连续成功窗口；命令退出零和进程存活只作为局部事实。核对未知写效果。必须项失败阻止完成；可选项缺能力标记 qualified。回滚后的恢复验证独立于原变更成功判定。

输出：有出处的发现、行动或产物引用、验收结果及未验证项。权限、预算或执行环境不足时通过共享进度交回受阻事实，不扩大授权。
