Lake v0.3.25 · macOS Apple Silicon

- 修复旧程序无法打开已完成安全迁移收尾的数据目录的问题。完成记录与当前账本校验通过后，可以在历史迁移副本已清理的情况下启动；原操作、证据、验收和未决结果继续保留。
- 增加安全任务的步骤确认、执行尝试、人工验收和恢复核查能力。操作成功与目标完成分别记录；未知结果不会因更新或另一个任务成功而自动结清。
- 引入持续接单的 Pilot 和独立任务专员，沿用当前项目原资源目录与已有权限；主机诊断使用受控只读步骤，任务超出已确认范围时仍需单独确认。
- 优化专员回复身份、黑色用户气泡与灰色回复气泡，执行详情默认收起；恢复重启前选择的项目，旧版会话从日常导航中隐藏，原始记录保留。
- 保留 Memory 的现有同意、角色范围及实验开关；本次更新不自动启用完整专员记忆或恢复后的记忆使用。

## 下载与安装

本版目标平台仅为 macOS Apple Silicon（M 系列）arm64，要求 macOS 13+。提供 ZIP、DMG 及 SHA-256 校验文件；不提供 Windows 包。

更新前请结束当前操作并备份当前数据。已有会话、资源和凭据继续保留，重启会断开当前终端连接；不会自动重放历史命令。初始迁移异常时先保全账本并停止对应后端，再按实际状态使用离线恢复命令，不删除控制文件或改写未决结果。

已完成迁移收尾的数据目录不能直接降级到不支持完成记录的旧版本。若新版本启动失败，应保留当前数据并使用支持相同存储协议的兼容修复版本；不要手改迁移清单、伪造已删除的归档或用旧库覆盖更新后的操作记录。迁移收尾是单独的离线管理动作，更新本身不会自动清理备份。

macOS 包沿用 Lake Local Development Code Signing 持久证书，尚未使用 Apple Developer ID 公证；自动更新要求相同签名证书。
