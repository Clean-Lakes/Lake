Lake 0.3.4：原生 macOS 客户端，内置 Go 后端与 React 工作台。支持 Apple Silicon（M 系列）arm64，macOS 13 及以上。

- 提升 Agent 调查稳定性：按任务调整调查预算，分页读取大型证据，完善主机与集群状态观察、目录目标解析和模型任务分配。
- 改善上下文整理失败后的恢复，保留历史记录，并优化连续对话、工具轮询和操作进度提示。
- 项目、资源和资源文件夹新增删除确认与“已删除”恢复入口；正在使用的对象会提示先处理相关终端或任务。
- 资源导入支持直接读取本机 HexHub MCP 连接清单，完善 HexHub 导出格式兼容和重复连接识别。
- 每轮回复新增持续显示的回答耗时；会话列表和资源区域可折叠，长会话列表支持展开更多。
- 优化终端列表、侧栏操作菜单及动态思考提示，保留人工终端与 AI 后台命令的独立显示。
- master 源码补齐 Windows x86_64 客户端、自动标题栏配色及检查、下载、安装更新流程；本次 Release 提供 macOS 安装包。

macOS 更新：右上角更新入口检查 master 正式 Release，可下载并校验 SHA-256、版本、应用 ID 和同一签名证书；替换后自动重启，安装或启动失败时恢复原版本。更新保留 ~/.lake 内的模型、会话、资源和凭据，重启会关闭终端连接，不自动重放历史命令。

安装：下载 Apple Silicon DMG，将 Lake.app 拖入 Applications；也可解压 ZIP 到用户 Applications 目录。旧 Electron 客户端请首次手动安装当前原生版本。

安装包使用持久 Lake Local Development Code Signing 证书签名，尚未使用 Apple Developer ID 公证。首次安装可能需要在 macOS 系统设置中允许打开；自动更新只接受使用同一证书签名的安装包。
