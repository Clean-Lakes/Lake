Lake v0.3.13：旧会话恢复、上下文压缩与 Windows 终端修复。

- 长时间未使用的会话可继续对话：闲置超过 30 分钟且历史较长时，先整理上下文再回答；短会话直接续聊，达到上下文预算时仍自动压缩。
- 压缩期间显示“正在压缩上下文”，支持停止，摘要请求最多等待 45 秒。失败保留原消息、操作证据与回退点；原历史仍符合模型预算时可继续回答，超预算则明确提示重试。修复服务重启后遗留的整理忙碌状态。
- 修复 Windows SSH 初始化控制帧与 ConPTY 标题合并后就绪信号丢失的问题；改善含空格路径、远端工作目录、连接错误与重连按钮的处理。
- 修复单个工具超时导致整轮对话中断的问题。等待终端输出超时后继续跟踪同一命令，保留已有输出和执行状态，不重复执行命令。
- 优化回复段落、列表、行内代码和结论排版；兼容生成文本中短加粗标签的多余空格，保留原始消息和命令内容。适配浅色、深色和窄窗口。

## 下载与安装

- macOS：Apple Silicon（M 系列）arm64，macOS 13+。提供 DMG、ZIP 和 SHA-256；将 Lake.app 安装到 Applications。
- Windows：Intel / AMD x86_64，Windows 10 1809+ / Windows 11。提供安装 EXE、免安装 ZIP 和 SHA-256，内置 Bash 与 SSH，无需 Node.js 或 WSL。安装版缺少 WebView2 时会验证 Microsoft 签名并安装官方运行环境，首次补装需要联网。

更新保留模型配置、会话、资源和凭据；重启会关闭当前终端连接，不自动重放历史命令。macOS 与 Windows 的旧正式版均可检测更高版本更新。

macOS 包使用持久 Lake Local Development Code Signing 证书签名，尚未使用 Apple Developer ID 公证。Windows 应用暂未配置 Authenticode 签名。Windows 包由 Windows CI 构建并验证存储、权限、原生终端与上下文恢复；界面展示另以隔离预览验证。
