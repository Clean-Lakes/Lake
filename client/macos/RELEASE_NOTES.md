Lake v0.3.19：本地终端常驻、对话进度与资源引用优化。

- 本地终端改为项目固定入口，不能删除或移入文件夹；升级自动恢复缺失、已删除或被移入目录的入口，保留原有名称、Shell 配置和历史引用。界面不额外显示“内置”文字。
- 修复 SSH 连接警告混入文件正文及哈希，导致文件写入误报冲突的问题；写入前被拒绝的操作准确标为未执行，避免阻断后续操作，真正结果不明的操作仍需核实。
- 同一资源的连续普通操作在一行内更新，保留完整展开记录；新增正文与进度柔和出现，减少闪动和不必要的滚动。每轮开头展示耗时与真实状态，沿用“正在思考…”和“用时”文案。
- 资源文件夹默认折叠；支持直接添加资源到对话。正文与资源标签可自由混排，发送后恢复标签展示，不重复显示资源名或 @。
- 方案和文件产物提供可点击入口，支持查看会话中保存的文件版本和变更详情；变更摘要采用更轻量的透明样式。
- 改进模型配置同步与思考级别选择；思考级别仅显示中文。提供当前项目定时任务的启停、下次执行和历史记录入口。
- 关闭窗口后保留后台任务，支持从 Dock 或应用菜单恢复；正常退出才关闭后台服务。修复侧栏状态和菜单重叠等问题。

## 下载与安装

本次先发布 macOS Apple Silicon（M 系列）arm64 安装包，要求 macOS 13+。提供 DMG、ZIP 及 SHA-256 校验文件；将 Lake.app 安装到 Applications。Windows x86_64 安装包后续补发，本次不包含 Windows 包。

更新保留模型配置、会话、资源和凭据；重启会关闭当前终端连接，不自动重放历史命令。SRE 协作为实验功能，沿用当前会话权限。

macOS 包使用持久 Lake Local Development Code Signing 证书签名，尚未使用 Apple Developer ID 公证。自动更新只接受使用同一证书签名的安装包。
