Lake v0.3.18：轻量工作区、对话排队与跨平台窗口修复。

- 工作台改为轻量布局：悬浮会话标题、紧凑输入框与半透明工作区入口；会话、资源和权限菜单统一间距、图标及键盘操作，更新提醒集中到工作区。
- 运行期间可继续输入，消息按队列发送；待发送内容支持拖动排序、编辑和移除，减少重复状态和遮挡。
- 首次使用尚未连接模型时仍可编辑草稿，直接从输入区进入模型设置；配置完成后保留草稿，由用户确认发送。
- 优化回复正文与执行过程的呈现、实时文字更新和历史轮次预览；上下文预算跟随模型容量，减少重复压缩，保留操作记录和证据。
- 支持会话文件附件及相应操作确认，macOS 下载使用系统保存窗口。
- Agent 与 SRE 协作接入官方 ADK 运行时，持久化会话、审批、问题和执行检查点；恢复时不自动重放结果不明的操作。
- 修复 Windows 顶部空白区域无法拖动、双击最大化覆盖任务栏，以及 macOS / Windows 会话状态环与更多菜单重叠的问题。
- Windows Dev 包增加明确标识，使用固定且与正式版隔离的数据目录，后续更新保留 Dev 配置；正式发布的下载包为常规 Lake 版本。

## 下载与安装

- macOS：Apple Silicon（M 系列）arm64，macOS 13+。提供 DMG、ZIP 和 SHA-256；将 Lake.app 安装到 Applications。
- Windows：Intel / AMD x86_64，Windows 10 1809+ / Windows 11。提供安装 EXE、免安装 ZIP 和 SHA-256，内置 Bash 与 SSH，无需 Node.js 或 WSL。安装版缺少 WebView2 时会验证 Microsoft 签名并安装官方运行环境，首次补装需要联网。

更新保留模型配置、会话、资源和凭据；重启会关闭当前终端连接，不自动重放历史命令。Windows 安装会关闭终端连接并重新打开。SRE 协作为实验功能，开启后沿用当前会话权限。

macOS 包使用持久 Lake Local Development Code Signing 证书签名，尚未使用 Apple Developer ID 公证。Windows 应用暂未配置 Authenticode 签名。自动更新只接受使用同一证书签名的安装包。
