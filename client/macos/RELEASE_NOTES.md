Lake v0.3.17：资源目录、分段上下文整理与 Windows 客户端更新。

- 新建 SSH、数据库、Redis 或 Docker 资源时可以选择所在目录；资源树支持把新资源放入已有目录，目录和资源的移动、重命名保持一致。
- 长会话的上下文整理改为分段摘要后再合并：单段失败会自动缩小分段重试；任何一步失败或停止时，原始历史、操作证据、检查点与用量保持不变，可以重试或切换模型后继续。
- 修复开启 SRE 协作后偶尔显示“无法连接到 Lake 服务”的误报。服务与协作实际正常时，不再弹出网络错误，切换状态也不会被旧请求覆盖。
- 修复切换模型后思考级别选择器残留空选项的问题，并统一输入框工具栏浮层的样式与窄窗口布局。
- 修复会话目录在窄窗口和滚动时的定位，目录按钮与浮层保持在同一视野内。
- 移除 ZCode 源码运行时及相关构建脚本，桌面端仅保留 Go 后端与内嵌 React 前端；历史许可归属继续保留。
- 保留 v0.3.16 的上下文恢复、流式回复结束与 macOS 更新下载进度修复。

## 下载与安装

- macOS：Apple Silicon（M 系列）arm64，macOS 13+。提供 DMG、ZIP 和 SHA-256；将 Lake.app 安装到 Applications。
- Windows：Intel / AMD x86_64，Windows 10 1809+ / Windows 11。提供安装 EXE、免安装 ZIP 和 SHA-256，内置 Bash 与 SSH，无需 Node.js 或 WSL。安装版缺少 WebView2 时会验证 Microsoft 签名并安装官方运行环境，首次补装需要联网。

更新保留模型配置、会话、资源和凭据；重启会关闭当前终端连接，不自动重放历史命令。Windows 安装会关闭终端连接并重新打开。SRE 协作为实验功能，开启后沿用当前会话权限。

macOS 包使用持久 Lake Local Development Code Signing 证书签名，尚未使用 Apple Developer ID 公证。Windows 应用暂未配置 Authenticode 签名。自动更新只接受使用同一证书签名的安装包。
