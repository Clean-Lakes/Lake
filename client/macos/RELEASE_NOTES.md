Lake v0.3.20：执行进度、操作确认和权限恢复优化。

- 每轮回答中，同一资源始终复用一条灰色执行进度，穿插正文、思考、其他资源或授权后继续操作也不追加同资源行。展开仍保留所有操作和原始记录，失败、待确认、结果不明等状态明确计数。
- 灰色进度加入 Lake 细线语义图标，区分终端、文件、搜索、主机、数据库、容器、工作流和定时任务等操作，保持水平对齐和稳定行高。
- 文件读写、附件、目标资源、终端及通用操作确认统一使用紧凑中性面板，突出目标和实际影响。技术参数默认折叠；文件内容支持 Markdown 阅读与精确原文，命令和 SQL 可直接核对。高风险、目标输入校验和单次授权规则保留。
- 修复 Shell 的运行环境与资源不匹配、在执行前被拒绝，却误记为“结果不明”并阻断后续写入的问题。能证明未执行的历史记录会保留审计并准确修正；真正结果不明的操作仍需核实，不自动重放。会话中调整的写权限应用于下一轮操作。
- 修复短内容下点击执行进度后，自动跟随误停的问题。底部有空间时保持稳定，新内容溢出时平滑下滚；手动上翻保留阅读位置，回到底部后恢复跟随。

## 下载与安装

- macOS：Apple Silicon（M 系列）arm64，要求 macOS 13+。提供 DMG、ZIP 和 SHA-256 校验文件，将 Lake.app 安装到 Applications。
- Windows：Intel / AMD x86_64，要求 Windows 10 1809+ 或 Windows 11。提供安装 EXE、免安装 ZIP 和 SHA-256，内置 Bash 与 SSH，无需 Node.js 或 WSL。缺少 WebView2 Runtime 时，安装器验证 Microsoft 签名后安装官方运行环境，此步骤需要联网。

更新保留模型配置、会话、资源和凭据；请先完成当前操作，重启会关闭终端连接，不自动重放历史命令。SRE 协作为实验功能，沿用当前会话权限。

macOS 包使用持久 Lake Local Development Code Signing 证书签名，尚未使用 Apple Developer ID 公证；自动更新只接受使用同一证书签名的安装包。Windows 应用未配置 Authenticode 签名。
