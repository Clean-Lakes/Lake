Lake 0.3.6：多主机终端、资源快捷操作与客户端更新提示改进。支持 Apple Silicon（M 系列）arm64，macOS 13 及以上。

- 保留不同主机的终端标签和屏幕，修复切换主机后会话消失及终端显示错位；一个主机连接较慢时，仍可连接其他主机。
- 资源旁新增一键打开终端：已有会话直接打开，没有会话自动创建；更多菜单保留终端管理与新增连接。
- 终端右键菜单提供中文复制、粘贴、全选与清屏操作，终端标签支持打开、新建和关闭。
- 支持批量删除会话、资源、文件夹和项目，展示删除确认及失败结果；单项删除统一收进更多菜单。
- 客户端启动及每 5 分钟检查更新，有新版本时更新按钮自动变绿并闪烁，查看后停止闪烁；检查视图展示更新公告。
- 调整资源行间距，统一会话编辑按钮与选中行的背景颜色，隐藏侧栏“项目记忆”入口。

更新保留 ~/.lake 中的模型配置、会话、资源和凭据。重启时会关闭当前终端连接，不自动重放历史命令。

安装：下载 Apple Silicon DMG，将 Lake.app 拖入 Applications；也可解压 ZIP 到用户 Applications 目录。安装包使用持久 Lake Local Development Code Signing 证书签名，尚未使用 Apple Developer ID 公证。首次安装可能需要在 macOS 系统设置中允许打开；自动更新只接受使用同一证书签名的安装包。
