Lake v0.3.22：资源管理、初始化体验与会话操作更新。

- 新建资源支持 SSH 主机和 Kubernetes。K8s 可选择 Kubeconfig 文件或粘贴配置，支持 Context、命名空间、CA 和客户端证书；可测试连接，并在会话中直接查询集群、节点、Pod、事件与有界日志。其他新增服务类型暂以灰色禁用选项展示。
- 同层目录默认排在独立资源前，优化拖动排序、移入目录、悬停展开、边缘滚动和键盘操作；会话排序与置顶顺序可持久保存。
- 首次使用页改用 Lake 山水 Logo 与简洁的模型连接、项目创建入口；侧栏保留文字品牌。用户消息悬停显示复制按钮，保留引用名称、空白与换行，键盘和触摸均可使用。
- 优化模型与思考强度选择、统一工作台字体和主题、权限面板与文件预览。支持会话 Plan 制定、审核后执行，以及回复中的资源、文件和计划引用。
- 执行进度按真实资源类型显示图标，修复多行文字和加载标记重叠；历史待核实操作保留审计，同一调用防止重放，后续独立命令按当前权限执行。
- 项目记忆与用户资产使用范围、来源审核和复用反馈更明确；策略资产与后台学习标为实验功能，默认门禁和独立预算继续生效，不将未验证候选描述为有效优化。
- SSH 文件操作与终端共用主机指纹确认，修复主机检查的目标传递，保持凭据与 Dev / 正式版数据隔离。

## 下载与安装

- macOS：Apple Silicon（M 系列）arm64，要求 macOS 13+。提供 DMG、ZIP 和 SHA-256 校验文件。
- Windows：Intel / AMD x86_64，要求 Windows 10 1809+ 或 Windows 11。提供安装 EXE、免安装 ZIP 和 SHA-256，内置 Bash 与 SSH，无需 Node.js 或 WSL。缺少 WebView2 Runtime 时，安装器验证 Microsoft 签名后安装官方运行环境，此步骤需要联网。

更新保留现有模型配置、会话、资源和凭据。资源类型约束扩充前生成 SQLite 备份；降级前应备份当前数据并评估新增资源的兼容性。请先完成当前操作，应用重启会关闭终端连接，不自动重放历史命令。K8s 仅开放受控只读查询，不开放集群写入或 Secret 读取。

macOS 包沿用持久 Lake Local Development Code Signing 证书，尚未使用 Apple Developer ID 公证；自动更新要求相同签名证书。Windows 应用未配置 Authenticode 签名。
