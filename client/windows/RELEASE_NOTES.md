# Lake v0.3.21 · Windows x64

- 修复启动时短暂闪现 Windows 原生标题栏和空白窗口的问题，工作台就绪后再显示窗口。
- 修复后台托盘显示通用图标的问题，窗口、任务栏和托盘统一使用 Lake 品牌图标，适配不同缩放比例。
- 保持与 macOS 共用的工作台界面、排版和配色。

## 下载

- `Lake-0.3.21-windows-x86_64-setup.exe`：Windows x64 用户级安装包。
- `Lake-0.3.21-windows-x86_64.zip`：Windows x64 免安装包，完整解压后启动 `Lake/Lake.exe`。
- 两种软件包均附带 SHA256 校验文件。本次仅发布 Windows 软件包。
