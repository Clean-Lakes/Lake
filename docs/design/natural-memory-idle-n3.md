# N3 空闲增量整理

本阶段在 [N2](natural-memory-formation-n2.md) 的自然形成上增加有界整理，并将主入口收敛为“记忆 · 实验”。基线为 #112 合入后的 `409d2706`，随后同步 `origin/develop@1d83ac5a`。验收与限制见 [N3 验收](../validation/natural-memory-idle-n3.md)。N4 压缩捕获、N5 新偏好召回均未开放；原项目记忆、人工绑定、Skills、工具权限与未知操作账本保留。

## 调度与增量

继续使用 `MemoryOutbox → projectMemoryTurns/projectMemoryJobs → 唯一 memory worker → ExtractMemory`，没有另一套模型/工具循环。主任务不等待整理模型。Engine 的 ModelActivity 覆盖普通、角色及工作流前台模型活动；辅助提炼不递归注册前台活动。前台结束至少两秒、定时器下一次检查后才领取自然来源。

同项目、会话、模型、资源绑定、知识版本、新旧设置 epoch 一致的连续来源最多合为六条，一次无工具 completion。输入总量上限 64 KiB，已存索引有界；放不下的尾部继续排队，不能推进成功覆盖。完全相同且仍有效的明确原话可本地合并来源，零新增模型调用；有原项目事实证据时仍须经过提炼。

稳定来源身份包括项目/会话、真实用户消息 ID、原话 hash、证据与目标绑定、有效同意 epoch、旧记忆 epoch 和整理策略版本；不依赖回调名称、根尝试 ID、捕获时间或知识库修订号。`naturalMemoryCoverage` 分别记录 captured、processed、deferred、withdrawn。重复交付不会重复创建任务；队列满时保留原持久 outbox，由空闲重试登记表分批交接，不扫描所有历史补采。

## 语义与事务

每条输入显式提供宿主更正资格 explicitCorrectionAllowed，长期要求本身不等于替换授权；宿主仍独立核验原话。模型必须按来源顺序逐条返回完整 JSON，宿主严格拒绝未知/重复字段、缺项、丢失来源、猜测目标、错误范围及非准确用户原话。只允许当前输入给出的既有目标或同批已经形成的同范围目标。

| 关系 | 提交行为 |
| --- | --- |
| new | 当前范围无目标的新偏好 |
| equivalent | 同范围、同语义及条件，新增修订和独立来源支持，保留各条准确原话 |
| correction | 明确更正，准确目标 revision，形成前后版本，旧待核实矛盾标为 superseded |
| conflict | 明确长期但无更正授权的矛盾，保留候选原话及来源；不覆盖原偏好，管理状态显示待核实 |
| none | 临时/引用等 ignore，或无明确持久意图的 review；不写偏好 |

项目与全局相同 topic 互相独立，不借用另一范围的修订号。条件不同不能因表面相似合并；宿主补充保守条件片段检查。来源支持最多 50 个，超限保持未处理；不是静默丢弃来源。条件检查不是通用语义证明，仍保留模型误判风险。

整批在一个原 Store 事务中提交，沿用租约、封印、来源、同意、撤回与版本重验。任一来源失效则全部回滚。新消息、撤销、遗忘、关闭相关范围或来源删除优先于迟到结果；前台抢占撤销所有批成员租约。撤销合并恢复对应的准确旧正文与旧来源集，不覆盖后续版本。

原项目知识提炼可在同次请求中输出，继续使用原证据、键与知识版本检查。偏好不能重复写入旧表示。同批重复修改同一旧事实键暂时保守拒绝全批，记录 deferred，不声称该增量已覆盖；本阶段没有放宽 V2 的启用门槛。

## 费用、失败与隐私

每天按 UTC 预留最多 20 次/项目、100 次/Home。先持久预留再派发；取消、崩溃及未知用量仍计次数，不退款。达到上限进入 budget_wait，下一 UTC 日重新检查，不把主任务变为失败。供应商失败沿原有限重试（最多三次、30/120 秒退避）；格式、版本或上下文预算失败保留原因，未完成源不标为 processed。不保证所有暂缓项自动成功。

新 schema 使用独立 v1/hash，不修改策略 v1～v6、N1、N2 的 SQL/hash。旧库升级前生成私有一致性备份，事务新增表与 marker，并只补来源引用，不复制正文、不继承同意、不调用模型。未知版本/hash 拒绝启动。重新启动不重复备份、提交或通知。

支持集只保存对准确修订的引用；矛盾正文独立可删。遗忘或删除来源清除正文、抑制重采并撤回相关覆盖。全局视图仅显示可用/私有标记，不返回原项目、会话、消息或 hash；正文/topic 继续检查私有名称。关闭自动采集保留已保存内容。现有能力不支持将本机全局偏好跨设备同步。

## 界面与旧实现去向

主设置为“记忆 · 实验”，展示自动记忆、来源数量、近期变更、覆盖进度和待核实矛盾。同批有效更新合并为一条轻提示；多项撤销提供各项准确版本操作，不假装是原子批撤销。可在设置中选择“保留当前偏好”拒绝矛盾；无逐条审核阻塞。

“历史资产与兼容管理”默认折叠，展开后才加载旧人工资产、采用条件、来源、候选/报告和 N1 偏好承接。保留旧手动读写、导出、撤回及原运行绑定，不自动承接、清空或重启执行。

删除无产品调用者的旧候选/实验 worker、ticker、ModelActivity 旧回调、提取模型方法和不可达实验创建实现。严格历史解析器移到 `strategy_learning_history.go`；明确清理旧实验文件的逻辑移到 `strategy_experiment_history_files.go`。正常历史接口、旧 JSON 类型/表、未知状态、共享 AI/评测夹具与兼容退役 handoff 留存。AST 回归禁止产品重新调用退役派发器；C3/C4 其余依赖审计与平台清理仍待后续，不能据本次删除标为全部完成。
