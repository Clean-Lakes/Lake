# Lake Memory N5：按范围使用

基线为 PR #114 合入的 `develop@87cd9ea84eca1e7139820473f82212389842ae88`。N5 接通新自然表达偏好与后续请求，保持实验。资源事实/条件经验仍走原项目记忆 V1/V2 的来源、资源、时效及门控；本阶段不放开 V2，也不重启策略学习、纠错或实验。

## 设置与范围

新增可选独立表 `naturalRecallSettings`，独立 version/hash 标记；不修改 N1～N4 或旧策略 SQL/hash。用户全局及每项目的 `useEnabled` 均默认 false，以独立 revision/CAS 和幂等键修改。已有自动积累、旧应用、原项目使用/提炼选择保留。升级不会把旧开关或采集同意转换为使用同意。

关闭自动积累停止新采集/提交，已保存的偏好可按单独选择继续使用。项目使用开关只控制本项目自然偏好；全局使用开关独立控制用户偏好。本轮忽略同时停止新偏好读取/采集及原项目记忆，不删除对话。界面在统一记忆入口说明范围，并提供项目事实与历史经验入口；旧管理仍折叠，不为清理丢弃复杂条件资产。

宿主从真实业务会话解析项目，不接受模型提交项目、来源或权限。先检查使用设置、active、真实来源内容 hash、全部保留支持、未解决冲突和当前敏感内容。项目同主题条目优先，并屏蔽同主题全局条目，存在待核实矛盾时也不借全局旧偏好绕过。无项目读取只允许用户偏好。全局结果只含新的 entry ID、revision、表达正文、topic 和 hash，不含来源项目/会话/消息/标题；重新检查原项目/资源名称，来源删除或变化继续撤回依赖。

同一主题识别沿 N3，跨不同 topic 的语义冲突并非完全可由确定代码判定。提示中固定当前明确要求及会话指令优先、项目优先于全局；固定角色、目标、工具与审批边界始终有效。

## 请求与按需读取

复用官方 ADK 请求准备，宿主本地查询，不新增检索模型/向量服务。每请求最多 12 条短预览、单条最多 512 bytes、附件最多 4096 bytes，并计入实际输入预算。优先项目后全局；超过数量的条目可本地查询分页。与既有人工绑定正文完全相同的偏好只保留原适配器的一份，不改变原条件/范围。

新增只读 `list_memory_preferences(query, offset)` 与 `read_memory_preference(id, expectedRevision)`。后者只读已授权范围的当前准确版本，不返回来源消息，不读取历史版本或接受任意路径。单条正文沿 N2 的 2048 bytes 上限；同一请求的工具偏好正文交付合计最多 4096 bytes，超预算明确省略。工具不保存、采用、修订资产或授权任何操作。

普通会话、终端/数据库表达、Plan 的只读回复及 Pilot 协调层可使用。普通子代理、Pilot 专员和工作流本阶段不继承新偏好或获得新读取工具；其角色输出契约和执行范围保留。CLI/stdio 未绑定宿主适配器时没有新召回。

## 失效、持久化与诊断

每 provider 请求和工具执行前重验本轮已提供的准确 ID/revision/hash。变化、遗忘、来源撤回、冲突或使用停用后拒绝继续使用旧上下文，不重放操作；UI 停用、遗忘和撤销即时取消实际已使用偏好的在途轮次。未使用任何偏好时的可选服务故障跳过增强，不把普通任务变为失败。

偏好附件只存在于当次 provider 请求，不写入持久 system/摘要。工具持久回执只保存引用，不复制偏好正文；当轮请求前重新读取并交付正文，跨轮回执替换为历史提示。已用引用和忽略标志进入可选 canonical memory 信封，重启仍重验；不改变 SQL 操作账本或审批恢复。原消息、模型已生成的回复和已有摘要是历史对话，不等于当前活动偏好，也不因遗忘一条资产被批量删除。

沿用记忆访问记录，区分 `prepared`（准备提供预览）、`index`（工具索引）与 `read`（宿主按准确版本读取供请求使用）；记录不含正文，明确模型遵从/收益未知。可选诊断失败不增加前台失败点，业务持久化和权限错误仍保留。

## 集成与剩余范围

本阶段验证记录见 [N5 验收](../validation/natural-memory-recall-n5.md)。N1～N5 的实验链路不等于完整运维记忆 V2 或 C3/C4 清理完成。旧人工绑定仍为保真兼容适配器，旧报告与 unknown 记录保留；拆分提示槽位/实验清单等剩余清理继续走独立计划，不把旧研究收益结论改为新记忆收益。
