# R2：后台学习交付、前台优先与独立预算

本阶段基于 develop 的 R1、主机检查修复与 Dev 快跑实现；PR #67 保留且不合并。学习候选仍是 project scope 的 single_observation，需要明确采用；用户级晋升、拒绝反馈与相关性选择由 R3/R4 推进。P8 的收益结论仍为 inconclusive。

## 运行契约

1. 普通已完成/失败轮次在已同意学习时，仅追加有界 outbox 事件：真实消息、会话、轮次、epoch、历史区间及 hash。与主状态一同持久化，不进行工具结果哈希/证据整理、队列事务或辅助请求。主状态保存失败仍是业务错误，不被学习降级吞掉。
2. 后台每 5 秒检查、并发 1；启动库存只读取已登记 outbox，不回溯学习全部历史。每 tick 最多处理 8 个会话；新任务在运行时不领取学习。后台按原消息 ID/项目/用户角色/内容 hash 及 host-only 轮次锚点核实，再整理脱敏快照；只有明确纠正或成对工具失败触发提取。unknown 不是成功证明，失败只能形成观察。
3. 先幂等登记来源/排队，再提交独立 hash-only 交付回执，最后清理内存 outbox。复用 strategyReceipts，以 handoff-v2 的会话/轮次 hash 为键，不新增主 ADK 存储表，也不因 Ack 重写业务会话 JSON 或原生 projection。崩溃留下旧 outbox 时读取回执去重。入库失败/队列满保留交付，后台状态显示待重试。
4. 删除、编辑、压缩导致原历史区间不可核实则跳过可选学习，不能替换为另一轮。每会话最多 20 个待交付事件，满后跳过新采集。恢复不重放真实工具操作。旧版完整快照仍可交付；新索引事件不应由旧二进制处理。
5. 学习不等待同轮 projectMemoryJobs；只提供当时可读取的有界记忆索引用于去重。记忆提取不是候选学习的成功条件；候选仍不能充当项目事实。
6. 新前台消息或工作流/角色模型请求立即取消辅助上下文；模型槽非阻塞准入，不在前台前排队。尚未派发可延期，派发后的未知结果停止并保留请求身份/用量预留，不自动再次调用。侧路提取无工具、无自动重试，不产生第二套模型/工具循环。
7. epoch、租约、来源可用性和准确版本在派发/提交重验；源撤回后迟到结果不能生成候选。已持久化的已知结果可以重试提交，不重发模型。学习异常只影响后台候选，不改写已完成业务答复、状态或追加纠错卡。

前台仍承担原业务存储，以及一次有界引用/hash 封装；共享数据库/元数据锁存在短时竞争。取消只释放本地等待，不能证明供应商终止远端计算或释放远端并发，不承诺远端零额外费用。

## 固定预算 learning-v1

| 项目 | 实际默认值 |
| --- | --- |
| 并发 / 单候选请求 | 1 / 最多 1 次，无工具 |
| 完整两消息序列化输入封装 | 8,192 UTF-8 bytes（含 JSON 开销） |
| 输出 / 调用截止 | 至多 2,048 token（也受模型能力限制） / 30 秒 |
| 全局 UTC 日请求 / token | 12 / 61,440 |
| 待处理队列：全局 / 单项目 | 100 / 20（queued、leased、awaiting_reconciliation） |
| 队列有效期 | 48 小时，独立于在线活动时间 |

按来源保留全部 sourceId、失败/unknown 状态与 profile；文本和证据引用有界裁剪并标记 truncated，不改变原始来源。仍超限时不调用。派发前事务预留输入 bytes + 最大输出 token，保守按一 byte 一 token；已知可信 usage 结算实际 token，未知保留全额预留。历史运行也计入当日额度，重启/调整在线预算不能重置。限额是本机用户全局计数；GET proposals 返回 limits、budget（requests/tokens/resetsAt）、backgroundStatus，不返回密钥或其他项目正文。界面显示用量及预留和暂停原因，取消排队任务可释放队列空间，但不能撤销已发出请求的费用。

## 兼容、停用与验证

复用既有 schema，usageJSON 向前增加 reservedTokens、tokensCharged、budgetVersion；Message 增加仅宿主使用的 hostTurnId，模型 payload、摘要及历史预算忽略此字段。回退旧程序只能使用隔离的兼容副本，不能让旧 worker 消费新索引 outbox 或用旧库覆盖账本。关闭学习停止新采集/派发/提交，保留已有资产、真实来源、未知运行及审计。

本地回归包括：慢辅助模型被前台抢占、未知预留与不重发、槽位占满无派发/收费、在线预算独立、项目记忆积压不阻塞、日限额重启保留、UTF-8 裁剪/证据状态、交付故障/满队列重试、Ack 不重写会话、崩溃去重、关闭再开 epoch 拒绝旧来源、模型 payload 不含宿主锚点。原有撤回、迟到提交、CAS 与原生操作账本回归保留。

完整本地检查与签名 Dev 结果记录在后续验收段；不运行手动 CI，不发布生产，不以确定性夹具证明模型收益。
