# Lake Pilot

Lake Pilot 将原 SRE 协作和分层操作选择放在同一个入口。它按项目保存，默认关闭。输入区使用原风格的罗盘文字按钮：单击按关闭→手动选择→自动推进→关闭循环，关闭为灰色，开启为主题前景色（浅色主题为黑色），自动推进额外显示浅蓝 AUTO 标签。没有独立设置箭头或第二个 SRE 开关。

## 自动推进

“自动推进”默认关闭。关闭时，专员首次执行资源操作前提供 2～4 个方法或来源有区别的步骤级方向；相同工具、参数和依赖仅换名称不会变成多个选项。调查和独立验证不能以“只读”“单个目录”“需先读清单”为由省略备选方案。仅运行时已冻结的明确动作、最终汇总需补齐单一来源时，允许附原因的单一方向。方向覆盖本步骤的后续读取与正常回退，不按文件或单条命令反复询问；选中后点击实色“确认方向并继续”。默认收起“选择具体操作”；展开查看不会改变委托方式。主动调整勾选或点击“仅执行所选操作”才锁定命令集合，主按钮显示“执行所选 N 项”；收起详情保留锁定，“允许 Lake 调整”可恢复方向委托。变更仍需原有权限与审批。

选择区保留独立的“交给 Lake 完成本步骤”和“暂不执行”入口。展开、选择和勾选不会执行。命令正文在操作层展示，工具原名与 JSON 参数收在“工具与参数”内，供需要时核对。

开启自动推进后，新任务由 Lake 自行选择和推进。设置保存不改变已开始任务的策略；步骤委托也不修改项目默认值。关闭后再次开启固定从手动选择开始，不沿用隐藏的自动推进值。当前会话运行或断线时，入口禁用；服务端仍保留活动任务保护与设置版本冲突检查。

## 继续与重跑

普通聊天由模型结合会话判断是否需要专员。开启 Pilot 后，对已完成的只读调查说“继续再来一次”等要求重新执行的指令，应通过 `restart_task` 创建新任务，保留原目标及精确资源范围，重新制定计划并取证；已完成的旧任务和证据不改写。新任务采用当前项目的手动/AUTO 默认值，不继承旧任务的推进策略。暂停中的合格只读调查仍可继续或重新开始；变更计划、已派发的非只读历史操作和仍在执行或待核实的操作不能通过此入口重放。策略拒绝或明确未执行的提议保留原记录，不当成已发生的变更，也不重放该提议。

每次协调模型请求在上下文压缩后附上本轮 ID、开始时间及任务时间/状态，区分历史报告与本轮执行。提交交接并不代表执行完成，旧文件哈希也不能证明已经重跑。询问旧结果时可以直接解释，但不能把历史报告说成刚执行的结果。若模型只输出临时正文，沿用现有的一次补交机会，仅提供正式答复与协作交接工具；支持的 OpenAI/Responses/Azure 协议在此阶段要求函数调用。DeepSeek 的强制调用与思考模式不兼容，仅这次补交序列化请求临时关闭思考，保留用户配置及专员执行时的思考设置。仍未提交决策则如实失败，不增加循环，也不自动将正文当成执行结果。本轮模型答复失败不会被历史任务覆盖成完成。普通新一轮答复结束后，Lake Island 与上下文状态按本轮展示；旧的终态任务不覆盖本轮，仍在执行或待核实的操作继续保留其状态。

## 专员与进度

| 专员 | 分工 |
| --- | --- |
| 协调者 | 明确范围、制定依赖、分配工作、一次性汇总结论；常规只读巡检不另建表格骨架、比较或中间汇总步骤 |
| 调查员 | 只读收集现场证据、核对假设、交付发现 |
| 执行员 | 执行批准范围内的具体操作并记录实际结果 |
| 验证员 | 独立只读复测，按原验收规则判断结果 |

最终汇总逐字段区分历史基线、当前采样和健康预期。没有同字段的历史值时，只报告现状与缺口，不声称“没有变化”；独立重读相同的当前快照也不能补造历史基线。

步骤导航放在原专员消息头下方，复用原湖生态头像、正文与审批。导航由真实计划生成，不给每个角色复制相同的排障阶段；同一工作项仅显示一次。长说明在导航中省略显示，点击可查看完整说明、状态和完成条件；首条进度消息若仅重复步骤说明，不再同时铺开同一段正文。独立发现与报告保持显示。执行中的主正文保持稳定，模型实时叙述收入默认折叠的“运行详情”，只局部更新阶段与调用计数，避免流式内容反复改写整条消息。会话只在实际内容增高时跟随滚动，计数、状态、同一行文字和事件游标变化不会触发滚动；窗口尺寸变化仍适配布局，手动上翻仍暂停跟随。Pilot 活动条不使用独立计时器，用时显示最近一次真实活动时的快照；执行中的圆环、文字与当前步骤动效由浏览器独立推进，快照更新保留原节点和动画。方向与命令选择不会增加步骤数量或修改步骤身份，命令成功也不会直接增加步骤完成数。

## 单行状态岛

开启 Lake Pilot 后，会话顶部沿用原悬浮标题、玻璃底、共享字体与湖生态头像，采用 B「当前行动岛」：主行显示当前专员与正在做的事，次行显示其他专员状态，右侧仅保留状态色细环/结束图标与展开箭头，顶部不展示步骤数字，真实已完成/总步骤数保留在展开详情与无障碍说明中，不使用工具调用数、模型轮次或虚构百分比。切换方向、重试命令不增加步骤进度；恢复后沿用已完成记录，新计划按自己的记录计算。

等待方向选择、等待补充、等待审批、排队、执行、暂停和失败分别呈现；单个专员等待时仍显示其他专员继续执行。主动暂停为中性灰，尚在执行的原操作显示“正在暂停”，未知变更仍优先提示核实。结束调查不等于恢复验收通过，结论不足会保留在详情中。

右侧图标和环与下方上下文共用当前会话状态色：运行蓝、待确认黄、完成绿、需要关注红；结论不充分保留关注色和说明。

点击右侧进度可查看实际参与角色的分工与各自进度，点击角色定位原消息，“查看完整计划”定位原计划。面板左缘对齐上方标题与专员之间的分隔线，右缘对齐状态岛边界；窄窗口用整个标题气泡的宽度，避免外溢。以220ms展开、160ms收起，箭头同步旋转；没有重复的关闭按钮。入口只查看和定位，不执行命令、不授予权限；再次点击入口收起，Esc关闭后返回触发器，外部点击和移出焦点也会关闭。窄窗口优先保留会话名、真实状态图标与展开入口，长标题省略，完整内容通过提示和详情查看。

同一状态的快照更新原位保留节点、尺寸、展开状态与焦点，不为Pilot播放循环扫光或计时刷新。关闭 Pilot 时，专员信息用 120ms 淡出、宽度用 280ms 平滑收回普通会话状态；原标题锚点和会话正文位置保持不动，隐藏内容不可聚焦。减少动态效果时直接切换；开启时也可以读取历史SRE任务的实际进度，不补写历史执行策略。

## 专员资源执行过程

Pilot 的每个执行子级按真实资源 ID 分组，复用普通模式的资源行和 Mini Box。同一资源后续命令归回原组，原始参数和输出按需展开；没有明确终端类型的工具保留原操作记录。单个本机或 SSH 命令资源默认展开，同一轮计划涉及多个命令资源时默认折叠；第二个资源出现只收起尚未手动操作的盒子一次，用户手动开合及完整输出的阅读状态始终保留。

Mini Box 复用原材质、当前操作光带、状态和终止交互。并行专员只读取自己实际派发的命令记录：同时校验父会话、资源、终端 generation、attempt 时间与命令归属；准确终端/entry 句柄优先，缺少句柄时只接受唯一匹配的最近派发，歧义不展示和操作。终止仍由服务端验证准确命令与权限，不扩大职能或执行权限。

## 执行、恢复与兼容

| 选择方式 | Agent 可以调整的范围 |
| --- | --- |
| 交给 Lake 完成本步骤 / 自动推进 | 在当前步骤、职责、目标及权限内调整方向和命令 |
| 确认方向并继续 | 保持原方向标题和目的，通过验证后的新候选批次调整命令，无须再次选择；仅 ID 改名但目的逐字相同沿用原决定，真正换方向重新询问 |
| 仅执行所选操作 | 精确锁定工具、参数与依赖；失败不能静默改用其他操作 |

重复呈现已锁定的同一工具、参数及依赖集合，也沿用原决定，不扩大操作集合。自动推进或整步委托直接执行职责内的操作，无需先反复调用方向提议工具。相关读取及其回退归入同一专员交付项，只有真正前置关系才串行；需要独立验证时保留验证员，协调者消费已有事实与证据，不重复重算整份报告。

任务的自动推进默认值不能覆盖当前步骤后来明确选择的方向或命令。只读检查失败时，可以直接报告失败，也可以在委托范围内尝试替代检查。替代结果必须来自同一次 attempt、同一资源、失败之后真实成功且包含完整来源的只读操作，再关联原失败记录；失败历史保留，未取得证据的缺口仍阻止完成。单条字面量 `grep -c` 实际结束、输出完整的 `0` 且退出码为 1 时，视为检查完成但没有匹配项，保留原退出码和输出；其他非零退出、超时、复合命令和截断结果继续按原规则处理。策略拒绝及未执行的命令无需关联替代采样，工具会明确说明原因，不能误报为存储故障。每次模型请求都会带上当前未补齐的只读检查，以及时间、资源和来源均合格的替代操作候选；候选只通过来源校验，仍由专员判断是否真正覆盖原检查。关联被拒绝时明确指出旧采样、截断来源或错误操作ID，避免反复尝试同一无效关联。结构化 grep 会把零匹配规范为退出码0；需要原生退出码时使用单条 shell grep -c，工具结果本身已含退出码。专员提交报告后仍有只读缺口时，灵活委托的只读角色会在同一个步骤、同一份账本中得到一次补齐机会，最多使用原剩余额度中的8轮模型调用。补齐标记与上限持久化；命令锁定、执行员、冻结动作、未结束操作及待核实变更不走该流程。仍不满足条件则如实暂停。未知变更仍需原核实流程，执行成功也不能替代独立验收。

候选经服务端验证真实工具、参数、风险和依赖。提交只引用当前候选 ID，不接受客户端改写可执行正文；决策绑定原任务、计划、步骤和 attempt。未选择的资源调用会被阻止，其他角色的选择不能放行当前专员。调查员、协调者和验证员的新 Pilot 操作保持只读，自动推进不提升权限。

选择等待复用原 ADK 人工输入与专员调用；决策保存在原 SRE 任务，实际操作继续进入原账本。重启恢复原等待与 attempt，不创建另一套执行循环。结果不明的操作沿用原核实规则，不能用选择或自动推进重放。

首次迁移将主开关与自动推进设为关闭，并保存旧 enabled 来源；此迁移只运行一次。旧 SRE API 与新入口共享 enabled，旧 API 不覆盖子设置。没有 Pilot 策略的历史任务沿用原执行语义；已保存工作流继续按既有自动运行方式执行。专用终端、数据库会话和 Plan 模式保留原行为。
