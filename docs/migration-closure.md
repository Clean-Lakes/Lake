# TypeScript 迁移说明

运行链路已切换为当前前端 → Wails NDJSON → 签名 Go 启动器 → 源码构建的 ZCode TypeScript。Eino 源码、Go Agent、Go 数据层和运维执行器已移除。

保留 SQLite schema 19、原有湖/资源/对话/工作流/计划/湖志、附件和私有文件数据。旧版本数据库升级前创建私有备份；拒绝未知的未来版本。旧插件与子任务记录保持可读，不重新赋予执行权限。

普通运行不读取 Keychain。旧凭据的一次性迁移必须由签名 `bin/lake secrets migrate` 显式启动，凭据经私有文件描述符传递，先保存新凭据再删除旧项。迁移返回成功/失败的标识，不返回凭据。

原生 PTY 输出替代旧的终端接管提案队列。手动命令发送成功只表示已提交，前端展示实时输出；不把提交确认当作完成或成功。

合成数据库、模型服务器、SSH 服务与固定检查 fixture 覆盖迁移和端到端行为。真实模型服务、生产主机与外部连接器不属于合成回归的验证结论。

2026-10-02 最终验收：后端 58 项、SSH 集成 1 项、前端 38 项测试通过；75 个桌面方法签名兼容检查、Go test/vet、桌面并发检查、ZCode 根目录和 CLI 类型检查通过；LAKE lint 无警告/错误，变更模块架构检查无违规。macOS 桌面包与启动器签名验证通过。桌面点击检查因 Mac 锁屏未完成。

ZCode 根目录 lint 保留 70 项上游警告；完整 CLI lint 存在上游超长文件错误，未作为 LAKE 新代码通过的结论。原生浏览器/CUA 的宿主交互尚未接入当前 Wails 前端。

2026-10-02 会话身份与工作流创建修复：原生默认身份段仍写着 ZCode，创建和冷恢复会话现在通过受校验的产品身份参数声明 LAKE；保留原生工具、Skills、权限、上下文压缩与默认独立 CLI 行为。全局 Skills 的说明不能当成当前湖已连接的资源或授权，普通问候不再要求枚举这些扩展。

CPU 巡检创建失败记录的原生错误码是 `MODEL_CONTEXT_EXCEEDED`，旧适配器将它丢弃并统一提示配置与网络失败。现在前端收到固定的具体原因和恢复建议，不转发供应商正文或凭据。已超出容量的旧会话仍可能需要新会话或核对模型上下文窗口；此次修复没有扩大模型实际容量，也没有替换原生压缩策略。

Agent 原先只有运维工作流查询与执行入口，缺少保存定义工具。新增 `lake_workflow_save` 复用现有 LAKE 数据层验证、修订号和湖志写入，只在会话所属湖保存定义；保存事件进入严格事件契约并触发当前前端刷新。创建定义不会调度运维执行器，执行仍走现有授权与审批流程。

修复后发布验收：后端 60 项、SSH 集成 1 项、前端 38 项通过；根目录与桌面 Go test/vet/race、原生根目录与 CLI 类型检查、LAKE lint、变更架构检查和签名验证通过。桌面独立合成湖点击验收确认 LAKE 回复显示、CPU 定义保存后立即出现在工作流列表；后端端到端测试确认保存动作没有增加 CPU 执行或工作流运行记录。模型请求也验证了 LAKE 身份和保存工具的实际注入。真实模型服务与生产主机不在此次合成回归结论中。根目录 lint 仍为 70 项上游警告，完整 CLI lint 仍因上游多个包的超长文件报错。
