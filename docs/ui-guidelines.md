# Lake 前端 UI 规范

适用范围：`web-agent/web/src` 的 React 工作台，包括 macOS、Windows 桌面内嵌页面和独立 Web。新功能与修改已有页面时均遵守本规范。

会话、任务检查与 SSH 终端的整栏底色统一沿用最左侧资源/会话栏的 `--sidebar`；浅色和深色的 `--background`、`--terminal-background` 均引用同一值。终端渲染器、输入框外侧及上下渐隐遮罩一起跟随，避免残留不同色块；卡片、输入气泡和 Lake Island 继续使用各自的表面材质，保留层次。

Lake Island 是 Lake 状态岛的正式名称，语义与象形为“湖中岛”。会话状态、任务进度与终端围绕同一岛关联，沿用 Lake 的轻盈材质、连续轮廓与统一交互；后续命名、设计和实现均保留这一语义。

## 设置界面的圆角比例

项目、设置和更新共用控制台弹窗。左栏提供分类搜索及纵向导航，在窄窗继续显示。搜索栏与右侧固定页头对齐；右侧显示当前分类和页面操作，正文独立滚动。按 `/` 可聚焦分类搜索。关闭按钮固定在弹窗右上角，各页共用同一位置，页头给关闭按钮留出操作间距。

记忆和巡检在后台采用应用默认设置。巡检记录仍可在对应任务的执行过程查看。

控制台右侧使用 21px 页名、18px 分组标题、15px 正文与字段文字、14px 操作按钮和说明、13px 元信息。窄窗页名使用 18px，同组说明和操作可分行。页头和正文共用横向边距，正文最大宽度 900px，表单、列表和更新说明沿同一阅读列排列。模型来源和已安装 Skills 放在相应配置的上方。

设置页统一使用窗口的连续曲线 `--corner-window`，按层级缩放圆角展开范围；不把所有控件都变成胶囊。共享值定义在 `theme.css`，由 `surfaceGeometry.css` 应用到弹窗和设置控件。

| 元素 | 共享 token | 圆角 |
| --- | --- | --- |
| 控制台、独立表单和确认弹窗外框 | `--radius-settings-dialog` | 22px |
| 供应商选中卡片、模型列表外框、编辑/发现面板 | `--radius-settings-panel` | 14px |
| 输入框、API Key、AppSelect、添加/保存/测试按钮、普通菜单行 | `--radius-settings-control` | 10px |
| 小尺寸供应商图标底板 | `--radius-settings-icon` | 8px |
| 上下文容量等紧凑标签 | `--radius-settings-badge` | 5px |

开关保留胶囊、状态点保留圆形；半径不能超过元素短边的一半，不为容纳圆角随意放大控件。模型列表仅外框拥有圆角并裁切首尾行，内部横线保持直线，不给每行重复画框。嵌套的模型菜单沿用外框 18px、内缩 5px、选中/悬停底 13px；供应商侧边菜单外框同为 18px，实色底且仅单层细边，原生滚动容器显式关闭 bezel 和 focus ring。输入聚焦用细描边与轻量焦点反馈，不使用弹窗大阴影。

问答框、通用弹窗、操作审批和资源管理浮层复用这套层级，由 `surfaceGeometry.css` 在对应容器内映射通用圆角变量；不改全局紧凑对话的比例。问答框及独立弹窗外框为 22px，内层卡片和普通菜单外框为 14px，输入、按钮和菜单选中底为 10px；模型菜单继续使用其 18px/13px 的内缩比例。圆角和 `corner-shape` 必须同时覆盖选中、悬停底色，避免只有外框变圆、内部控件仍使用旧的小圆角。

支持 `corner-shape` 时使用 `superellipse(1.5)`；不支持时保留同一比例的标准圆角，不假称其为原生液态玻璃。弹窗背景、底部操作区和列表首尾必须跟随外轮廓裁切，禁止圆角外漏出方形背景。明暗主题、桌面/窄窗口、选中/悬停/键盘焦点均需检查实际显示；不能只比较 computed radius。AI 修改此类界面时同时遵守根目录 AGENTS.md 的圆角约束。

项目选中行和搜索结果使用主题的 `--info-soft` 底色，控制台分类使用主题中性选中底色。控制台各页共用页头、正文边距、分组标题和卡片表面。标题放在组外，组内说明居左，开关、下拉框和操作靠右。每组共用一层边框，设置行用细分隔线连接。窄窗允许字段和控件分行。项目列表保留单击切换，代码和多行编辑区域可占据整行。接入渠道按连接设置、接入配置和消息与任务排列。当前连接行保留所属项目和连接切换。新建、重命名和删除确认在控制台正文内完成，取消时焦点回到入口。

## SSH 主机信任

按 2026-11-11 用户最新选择，SSH 结构化工具、Agent 和手动终端对首次及已存公钥变化均在后台通过原校验保存观察到的公钥，再继续认证，不弹指纹确认；不为文件工具额外打开终端。保存失败或取消不能继续认证。连接错误仍区分端口不可达、主机信任持久化、身份认证及未知原因，不把 SSH 255 统一解释为密码错误。Dev 与正式版各自保存信任记录，不跨 Home 复制或复用。

## 焦点反馈

设置分类使用方向键连续切换，Home/End 跳到两端，Tab 从已选分类进入其内容。选中的模型来源在打开设置和调整窗口尺寸时保持在列表可视区。窄窗优先显示完整 API 格式名称，空间不足时可在触发器上查看全称。

控制台左栏的共享选中底使用 600ms 弹簧变换，连续切换从当前画面接续。各行使用一致字重，悬停时加深文字与图标。只有选中行超出左栏可视范围时才滚动左栏。搜索筛选或窗口尺寸变化后按可见分类对齐，筛选隐藏当前分类时也隐藏选中底。「减少动态效果」下直接定位。[Bento Card 参考](https://uselayouts.com/docs/components/bento-card)

模型设置选定云厂商后聚焦 API Key，自定义接入聚焦空地址，本地 Ollama 聚焦获取模型。已选来源收为一行，展开可切换或刷新，添加供应商在同组提供。仅浏览预设或撤回全部编辑不触发离开确认；真实修改（含模型编辑器）留在内存，放弃前确认，继续编辑回到原控件。API Key 不写入浏览器持久存储。

模型设置按当前内核的支持情况显示「重新识别模型能力」。支持自动识别时，保存后同步后台进度。TypeScript 内核保存后直接反馈结果，模型能力可在列表中手动编辑。

供应商的模型列表标题旁提供「全部启用」和「全部停用」。两项操作一次更新当前供应商全部已配置模型的开关草稿，随供应商设置保存。全开或全关时禁用对应的重复操作，窄窗允许按钮换行。

宽屏 Web 的任务检查栏与会话共享同一个展开进度，正文、输入框和侧栏一起让出或收回空间；减少动态直接切换。窄屏仍用浮层，原生扩窗仍固定原有会话宽度。

开合任务检查栏时复用已渲染的历史正文和当前目录的引用匹配器。正文、资源目录或该轮文件回执更新时，才重新解析受影响的内容。
会话目录在打开时读取当前滚动位置并选中相应的历史轮次。目录收起后暂停测量各轮次的位置。

Pilot 的目录默认进入「任务」，按当前项目的公共任务 ID 将协作专员合为一行，显示标题、更新时间、状态和上次结论。支持按标题、资源和日期查找。原提问在已加载会话中时可以定位，「消息」页保留逐轮定位。点「接着问」在 Pilot 输入框上方挂入可移除的任务标签并恢复输入焦点，保留草稿和滚动位置。任务行与续接标签共用对应任务的真实专员头像，最多显示三张，超出时显示 +N，完整姓名可通过悬停和无障碍描述查看。消息接收成功后，长标签收为工具栏中的头像和「续接中」，窄窗收起状态文字，较窄时最多显示两张头像，悬停及无障碍名称可读任务标题。后续发送携带同一任务 ID，点 × 清除。已发送消息显示宿主确认过的任务标题。任务引用仅提供上下文和路由身份，执行沿用当前权限及任务状态。

Pilot 空会话居中显示一只静止的翠鸟、一条淡水线和「从一个问题开始」，沿用会话底色、输入框和状态岛。

焦点描边共用 `--focus-outline`，由 `focusModality.ts` 在应用启动时统一跟踪鼠标/触摸与键盘导航。鼠标或触摸打开弹窗、菜单、点击按钮以及恢复焦点时，不绘制键盘蓝框；Tab、方向键、Enter/Space 等键盘操作恢复可见描边。保留真实 DOM 焦点、弹窗焦点限制、Escape 关闭和返回入口，不用 blur() 或全局 outline:none 取消键盘可达性。输入框自己的聚焦边框使用 `--focus`，与按钮的键盘描边分开。

## 下拉选择框

所有表单单选字段统一使用 `AppSelect`（`web-agent/web/src/AppSelect.tsx`），不得在业务组件中直接添加可见的原生 `<select>`，也不得另写一套下拉弹层。模型设置、会话配置、资源类型、SSH 登录方式与 Shell、工作流角色、目录和记忆类型已统一接入。聊天输入框的模型选择器也使用 `AppSelect`，通过选项渲染、分组及头尾插槽保留搜索和设置入口；不得另写模型下拉弹层。项目切换等专用菜单视觉上复用相同主题变量。 展开侧栏时，项目菜单与项目按钮等宽，左右边缘对齐。收起侧栏后，图标入口保留可读的菜单宽度。

“新建资源”弹窗支持 SSH 主机、Kubernetes、MySQL、PostgreSQL、Redis、APISIX、Prometheus 和 VictoriaMetrics，统一使用 AppSelect。六类服务资源可配置连接、私有凭据并单独测试；保存仅登记配置，不隐式连接。数据库通过固定 SELECT 1、Redis 通过 PING、APISIX 通过插件列表读取、监控服务通过常量查询验证连接，测试不改变任务验收或当前健康结论。类型、配置或认证方式变化后清除旧测试结果；取消或关闭清除秘密草稿并中止测试。服务配置编辑保留原资源身份和目录，已有凭据不回显、留空保留，支持明确清除。Kubernetes 默认使用 Kubeconfig，支持文件选择或粘贴 YAML/JSON，内容默认遮蔽并可显式显示；选择新文件、切换认证方式和关闭弹窗清除对应凭据草稿。高级选项包含 Context、命名空间、1～60 秒超时和 TLS 验证方式；点击“测试连接”才读取版本信息，取消或改动配置后忽略旧测试响应。按类型展示连接字段，切换类型和关闭弹窗清除凭据草稿；保存只添加配置，不隐式测试连接。Docker / SQLite 保留已有资源及服务能力。

聊天输入框将模型与思考强度合并到同一个 `AppSelect` 弹层，工具栏使用 30px 高的模型入口，模型名左侧显示 16px 本地厂商图标，右侧显示展开箭头。支持思考强度时，模型名后显示 14px 柱形图标和当前中文档位。按会话、模型和供应商识别读取结果，切换后不沿用上一模型档位；调整保存完成后同步更新。采用默认设置时优先显示服务端声明的档位，档位未声明时显示「默认」。能力读取失败或模型不支持时隐藏思考强度。弹层顶部单行显示当前供应商的本地品牌图标与名称，点击右侧箭头展开供应商侧边菜单，列出供应商、当前勾选与“管理模型”；再次点击入口可收起。菜单支持上下键、首尾键、Enter 与 Escape，只显示所选供应商下的真实可用模型与视觉能力；打开时回到当前模型所属分类，切换供应商不改变实际模型，长列表搜索仅作用于当前分类，不再增加 API 徽标，下部通过 footer 插槽展示会话的思考强度。Web 供应商子菜单仍使用公共 AppSelect，父菜单保留对子菜单的点击归属，选择分类不关闭模型卡片。思考强度使用离散滑杆，仅使用服务端返回的支持档位，采用 28px 胶囊，已选部分为系统蓝色、未选部分为中性灰色；按实际支持级别等距显示固定小圆点，不再使用紫色渐变和漂浮光点。中性玻璃滑钮在点击/键盘选档时以 240ms 轻缓过渡、拖动时直接跟手，松开后自然吸附；减少动态效果时取消过渡；默认是滑杆首档，不再显示刷新/重置图标，后续仅列出当前模型实际支持的级别。使用默认时显示“默认 · 模型实际默认档位”，拖回首档仍保存空 effort。弹层右边缘与下方模型入口对齐，最小宽度 240px，入口更宽时随入口加宽，受屏幕安全边界约束；供应商行与模型列表用细分隔线区分，固定图标与勾选位置。模型名去掉重复的供应商路径前缀，保留自定义别名；原始全名保留在提示及搜索中，超长名称单行省略，思考强度标题必要时换行；模型行高 32px；触摸设备保留至少 44px 点击区。轨道与滑钮共用窗口的连续圆角曲线；填充和档位点在同一轨道内裁切，滑钮独立绘制并使用轻阴影，避免左端出现双重圆角的彩色缺口。macOS 26 及以上的桌面客户端使用系统 `NSGlassEffectView`（clear）承载模型卡片，以通透的液体玻璃显示正文后的材质，原生 18px 圆角、边缘反光和透光由系统合成；透明 WKWebView 只复用公共 AppSelect 分类、模型和强度内容，不再叠加 CSS 底色、边框、阴影或背景模糊。供应商子菜单使用实色原生面板，不使用液态玻璃；与主卡片统一 18px 连续外圆角，使用单层单物理像素描边，明确关闭 NSScrollView 的凹槽边框与焦点环，避免双层框。模型行与供应商入口的灰色底使用向内缩进后的 13px 连续圆角。原生弹层共享同一认证 origin 与 cookie store，不传递密钥；验证主 frame 和消息 origin，点击外部、Escape、移窗、最小化和失活关闭，保存请求在关闭后仍能完成。Web、Windows、旧 macOS 或旧 SDK 构建继续复用顶部会话标题的 `--title-glass-*` CSS 材质，并保留减少透明度和背景模糊不支持时的主题实色回退。拖动时仅预览，松开或键盘调整结束后保存；方向键、Home/End 不触发模型列表选择，Escape 关闭整个弹层。切换模型后重新读取能力，未知、加载失败及运行期间不可调整；保存期间滑杆保持可用和焦点，采用串行后台保存并合并未派发的中间选择，始终显示最新选择，较早响应不能把滑钮拉回旧值；错误在弹层内展示并支持重试。无思考能力的模型不显示该分区。默认项保留模型默认语义，不能将默认偷偷保存为显式档位。模型列表继续使用公共定位、勾选、搜索及键盘行为，适配窄窗口、深色主题和长列表滚动。

任务详情与会话目录的选中标记在页签间滑动。项目切换、记录来源和模型菜单沿按钮边缘展开并收回，原生模型弹层按窗口所在显示器的帧时钟绘制。输入区在换行或附件增减时保持底部工具栏对齐，光标和输入即时响应。目录从原行进入重命名，保存反馈以实际写入为准，消息图片预览从可见缩略图展开并返回原处。减少动态效果时直接展示对应状态。

输入框默认提示使用“想让 Lake 帮你做什么？”，引用类型在 `@` 菜单展示；排队、待确认时继续显示对应状态提示。思考强度在运行期间保留级别和完整不透明度并说明不可调整；保存状态仅用不占布局的无障碍播报表达，不临时禁用滑杆或增减提示段落，卡片尺寸和输入焦点保持稳定。模型行在强度保存期间保留高亮与颜色，不切换禁用外观或重新加载列表，但锁定模型提交，避免模型与强度的保存相互覆盖。强度保存按会话单独记录忙碌状态，不占用全局 pendingOperation，资源侧栏、附件和工作区入口不因此刷新禁用外观；仅在当前会话强度保存期间锁定发送。

无草稿且未输入时，输入区保留单行编辑入口。收起和展开都占满会话输入栏，并与状态岛左边缘对齐。鼠标悬停时，当前模型图标在完全收起后从右侧旋入，触摸端省去悬停预览，减少动态效果时图标淡入。点击或按 Tab 进入编辑区时，同一输入节点随外框向上展开。外框使用 Prompt Box 的 Motion 弹簧，工具栏在 80ms 后用 200ms 淡入，收起用 160ms 淡出。发送控件以 150ms 从 0.85 缩放到 1，收起时逆向播放。收起时预留工具栏的实际高度，包括窄窗换行，使会话滚动视口保持原位。高度弹簧只驱动绝对定位的外框，编辑区随外框平移，圆角和文字保持原尺寸。空草稿点击外部或将键盘焦点移出后收回。已有文字、引用、附件或正在执行的任务保持展开。展开时编辑区与底部工具栏之间保留 10px 间距，外框上下各留 10px。下方一行收纳附件、权限、Lake Pilot、模型与用量提醒、发送和停止。附件、权限与发送操作保持 30px。发送按钮使用圆形底和上箭头，可发送时使用前景色底和反色箭头。多行编辑、附件预览、粘贴和拖放沿用原行为。聊天框外缘使用共享底部留白 `--workbench-bottom-inset`。外框在收起和展开时均与状态岛共用窗口转角和一层细描边，编辑区聚焦时加深描边。模型上下文圆环不常驻底栏：正常和未知用量隐藏，模型菜单的 footer 增加默认折叠的“上下文用量”行，点击展开输入预算、剩余和缓存等真实数据。Web 和 macOS 原生模型窗口使用同一组件，原生桥接只传当前 Session 的用量字段，不传对话或执行卡片。实测占用达到输入预算 85% 时，底栏显示可打开详情的轻量警示，达到预算时提示需整理；窄输入栏仅显示带完整无障碍标签的警示图标。整理失败继续在会话中呈现具体错误，避免重复告警。菜单内详情采用透明内联布局和有界滚动，不叠加浮层、边框或阴影，Escape 关闭整个模型菜单。

## 回复正文排版

界面与回复共用系统优先字体栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`，普通界面文字采用系统字体与 500 字重，按用户当前并排截图校准为共享 14px（不再把 Codex 包的 13px 默认值当作用户当前显示值）。`--font-size-body` 引用 `--font-size-ui`；会话阅读正文独立使用 `--reply-body-size: 15px`，不影响身份名称、状态和审批控件的紧凑字号。常规文字与选中名称共用字重，不因颜色另设大小。普通文字只使用黑色 `--foreground` 和灰色 `--text-muted` 两档（浅色界面按截图使用固定 `#8e8f90`，避免不同底色透出第三档灰度）；`--text-secondary` 为同一灰色的语义别名，不再建立第三档灰度。输入占位文字、计时、提示、计划入口、计划日期和错误说明沿用共享字号；输入工具栏采用 `--font-size-toolbar: 12px`，实验型徽标采用 `--font-size-badge: 10px`，保持紧凑但不缩小按钮点击区域。不同颜色不改变字重。代码采用 450，标题 650。

助手正文采用共享系统字体、15px、500；正文 strong/b 保留语义，不另加粗，避免局部文字再形成另一套外观。真正的页面标题和品牌标识可以保留标题尺寸与 650 字重；代码、终端保留等宽字体，错误、警告和状态色保留功能含义。不能把局部缩小或减字重当成灰色文字样式。

会话标题采用随项目名、会话名和真实状态收缩宽度的悬浮圆角气泡，圆角使用 `--radius-window`，不添加横贯正文的分隔线或背景条。顶部空白区域和标题气泡支持窗口拖动及双击缩放，交互控件、弹窗和菜单不触发拖动；Windows 在移动超过 4px 后才交给原生拖动，保留完整的双击事件。标题气泡外框、正文容器和输入框外框共用工作区宽度计算的左边界和内容宽度；滚动条位于右侧留白，不通过正文两侧额外占位导致错位。正文滚动区域延伸到气泡背后，首屏和跳转预留标题空间；长标题省略并提供完整悬浮提示，窄窗口保留导航入口。左侧图标栏使用分栏窗口 Glyph 作为控制台入口。打开时保留原侧栏、正文和终端，背景使用主题遮罩及模糊。减少动态时直接显示弹窗。

开启Lake Pilot时，顶部状态岛采用单行紧凑布局，保留原标题的玻璃表面、边线、窗口圆角和共享14px字体；专员使用原AgentIcon，不加头像圆底、字母占位或另一套品牌图标。采用 B「当前行动岛」：主行显示一个当前专员与实际活动，次行保留其他专员状态，右侧只保留状态色细环或结束图标及展开箭头，顶部不展示3/3等数字；真实已完成/总步骤数保留在入口无障碍说明和展开详情中；等待或未知结果优先显示需要介入的专员。关闭时信息 120ms 淡出、宽度 280ms 收回普通会话状态，标题锚点、正文和滚动位置不变，退场内容隐藏并禁止交互；减少动态效果时取消过渡。不按调用次数增加进度，Pilot 的实际运行状态沿用共享标题扫光，等待、暂停和结束时立即冻结当前相位并淡出；正在暂停但原命令仍在途时也停止运行扫光，保留真实在途说明和静态进度。等待选择/补充/审批、排队、实际执行、暂停和未完成必须区分，不能把等待中的专员计作并行执行；原操作尚在途和未知变更保留实际提示。暂停用中性灰，关注用现有警告色，实际失败保留错误色。会话状态岛在所有窗口宽度下均不渲染项目图标、项目名称及其斜杠分隔符，直接从会话标题开始；窄窗口优先省略长会话标题，保留状态图标和展开入口；Windows预留原窗口控制区。点击 Lake Island 的专员区打开会话右侧的固定“任务检查”栏，任务计划与执行详情共用同一栏；再次点击状态岛、关闭按钮或 Escape 收起。任务检查栏默认收起；进入 Pilot 或专员、切换会话及新任务进入计划/运行阶段均不自动展开。用户点击顶部箭头、专员行动区、执行过程或证据入口时才展开；手动展开后继续跟随既有选择，收起后计数和快照更新不再弹出。专员状态已展示时不再追加底部“几个子任务执行中”的重复运行行，结束后的真实耗时入口保留。右栏采用随内容增高的悬浮卡片，计划 / 执行页签与关闭入口置于卡片内部顶部；统一通过状态岛尾部箭头开合右栏，关闭后该箭头继续常驻，再次打开默认跟随当前会话最新一轮，仅保留页签偏好；最新一轮暂无执行记录时展示空状态，不回退到旧任务。默认跟随时新轮次自动更新右栏；仅在用户显式打开历史用时、历史任务或步骤时固定该历史目标，快照和新轮次不覆盖手动选择；不另外显示右上方“计划与执行”按钮。箭头固定向右，开合不旋转。普通模式在状态标签旁提供相同的箭头按钮与键盘操作，沿用右栏入场240ms、退场180ms动效。目标与范围默认折叠，避免摘要与原始长目标重复占位。桌面右栏宽 382px，与正文并排，窄窗口改为靠右覆盖并保留可关闭入口。沿用主题表面、单层细边、共享字体与图标；步骤、资源、Mini Box 和原始证据复用已有组件。右栏切换步骤只查看记录，不开始任务或派发命令。旧轮次显式打开的 attempt 必须使用原计划与原运行记录，不能借用新计划的同名步骤。当前快照优先于入口保留的历史任务，切换会话、资源详情或 Plan 页面立即清空选择。主对话保留交付正文、方向选择和审批，计划与原始执行内容收进右栏；点击证据引用直接定位右栏中的原始证据。普通会话的“查看执行过程”打开该轮执行详情。打开和关闭保留可见消息的位置，输入框随可用宽度布局；右栏独立滚动，不滚动主会话。入场 240ms、退场 180ms 淡入淡出和轻微横移，退场立即 inert，减少动态效果时直接切换。关闭恢复入口焦点，标签支持键盘切换，快照更新保留已展开资源、输出和输入状态。

内置 Pilot 主对话的顶部状态岛右侧采用 16px 状态图标和现有详情展开箭头。二者的图形中心相距 23px，展开按钮的点击区为 28px。处理中使用蓝色开口环，待确认使用黄色盾牌圈，已暂停和已停止使用不同的灰色圈内符号，已结束使用绿色圈勾，需关注使用红色圈叹号。状态文案用于悬停提示和可访问名称，布局只计算图标和可用的展开控件，不为文字预留宽度。

点击主对话的 Pilot 状态岛旁的箭头，右侧检查栏随当前轮次显示最新关联任务。状态岛箭头在右栏开始展开时向左转，在收起时转回向右，沿用右栏 180ms 的缓动。Worker 详情按同一任务 ID 展示专员、实际派单和回传，可进入对应 Worker 的执行记录。Pilot 操作按本轮已有记录的时间排列，原始执行详情可继续展开。历史入口保留所选轮次和任务。面板页头显示「执行过程」和关闭按钮。面板沿用状态岛的玻璃表面，当前操作共享标题扫光的 3.4 秒相位，结束后冻结并在 700ms 内淡出。macOS 预先绘制展开后的右栏，由窗口边缘同时揭开底色和详情卡。快速反向时以当前窗口位置接续。减少动态效果时直接切换。

TypeScript Pilot 派发给独立专员后，在对应用户轮次的回复下保留轻量实时进度行，说明专员名称、当前行动和任务；多位专员分别展示，点击进入准确专员频道。该行不是聊天消息，不保存“执行中”占位回复，不读取旧步骤或自由文字猜测状态。只有宿主提供的实时思考、实际工具活动使用共享状态文字扫光；排队、审批、补充信息、外部等待保持静态，持续无法更新进度时停下动画。原消息未加载或活动来自另一频道时不挂到最新问题上；停止、结束或缺少实时活动时移除，由实际结果接续。Pilot 自己回复结束而专员仍运行时，顶部仍显示处理中；真实确认优先显示待确认。长名称在窄窗口单行省略，保留入口箭头及完整可访问名称；后台、减少动态效果及稳定节点规则与共享组件一致。

方向选择区域仅在新的请求出现时，以280ms淡入、轻微上移及实际高度展开进入；同一请求的计数、快照、方向选择和命令展开不重播动画、不重建控件。结束后恢复自动高度与可见溢出，聚焦或窗口尺寸变化立即结束入场以免裁切操作；后台或减少动态效果直接展示。计划底部“修订与详情”与共享箭头保持单行，空间不足时整组操作换行。已结束/已取消的状态岛用静态勾号/关闭符号代替进度圆环，仍保留真实完成数与结论不足说明；进度图标、圆环直接共用下方上下文的当前会话状态与--session-state-color，运行蓝、待确认黄、完成绿、失败/需要关注红，结论不充分按原会话关注色显示。此颜色只表达会话状态，不改写恢复验收结果。

## 旧会话恢复与上下文压缩

- 默认上下文预算跟随当前模型的已知容量，取其 90%，并另外预留单次输出；容量未知时使用 64K，不把默认预算当作模型容量。旧版保存的 64K 默认值升级为自动模式，其他自定义预算保留为手动模式；显式手动设置可以保留较低预算，但不能突破已知模型容量。切换模型后自动重新计算。
- Lake 与 ADK 的自动压缩共用实测占用判断，SDK 回调不能绕过预算强制重复摘要。摘要完成后尽量降到输入预算的 75%，给后续对话和工具结果留出余量。压缩仅改变模型上下文投影，历史消息、原始操作记录和持久证据保留。
- 聊天输入框和用户消息气泡的圆角统一使用 `--radius-window`，桌面宿主按系统窗口外角提供尺寸与曲线（macOS 26 为 22px 展开范围、`superellipse(1.5)`，旧版回退为 10px / round），浅色、深色及窄窗口保持一致。输入框收起时外框高 52px，空白展开时桌面外框高 92px，收展都保留会话输入栏宽度和文字字号；多行按内容展开。聊天输入框明确使用文本鼠标指针和主题前景色光标。自适应高度使用独立测量层，不得在输入期间将聚焦的 textarea 高度先设为 0；多行展开、缩回单行及补齐建议变化应保留焦点和选区。

- 会话不会因闲置而过期。闲置至少 30 分钟且模型历史达到 8192 个估算字符时，下一轮先整理历史；较短会话直接续聊。日常对话达到上下文预算时仍按预算触发压缩，不依赖闲置时间。
- 自动压缩进行中，当前轮唯一的底部状态入口复用共享扫光状态文字；悬停与无障碍状态仍说明“正在压缩上下文”及真实耗时，停止操作保持可用。不增加第二条进度、不展示内部摘要。已完成或旧轮的压缩卡片不得让当前轮显示忙碌。
- 压缩请求共享 45 秒上限（包含排队及摘要输出超限的一次重试）。失败或停止保留原消息、操作证据和回退点，解除忙碌状态；服务重启后遗留的整理状态标为中断，可以继续。
- 闲置恢复的可选整理失败，仅在原历史仍符合当前模型预算时继续；“保留原上下文继续对话”的内部说明只放在执行详情，不出现在 Pilot、专员或普通聊天正文，历史记录重新加载同样处理。只识别宿主 notice/system 来源，不隐藏用户或助手引用的相同文字，不删改原记录。真正阻塞本轮的整理错误仍明确提示重试或切换可用模型。超预算时必须先成功压缩，不得靠删除用户约束或重放命令恢复。摘要仅供上下文参考，不构成操作授权。

## 流式文字呈现

- 正文从首个可见片段到完成、保存和恢复都使用同一阅读列及原始消息身份；只追加实际收到的文字，不在完成时重算为气泡宽度、补加署名或重播整段入场。活动/耗时单行固定在本轮正文之后，原位更新真实状态，不在正文前后搬动，也不为计时等待人为延迟首包。专员流式与持久正文按准确来源 ID 衔接，同正文的不同原消息不能被误合并。

- 会话导航只保留轻量“目录”入口，按需打开有界弹层，按真实用户提问逐轮列出并标记当前阅读位置；重复提问按原消息 ID 分别定位，图片/附件轮次使用现有占位名称。少于两轮且没有更早记录时不显示入口。按钮在会话上方保持可达并避开 Lake Island；标题过长时在阅读列外侧收为图标入口，弹层遵循视口边界，不再常驻密集刻度或回复摘要。点击提问跳转，方向键/Home/End 移动，Enter 确认；Escape、外部点击或焦点离开关闭，Escape/选择后恢复入口焦点。更早记录和回到最新收纳在目录中，不打开执行检查面板，不额外调用模型；完整历史与正常正文跟随保持原行为。

- Pilot 与普通工具会话按同一用户轮次及准确 SDK RootTurnID 区分公开阶段说明与执行记录。Ops 运行及等待期间，主对话继续显示公开阶段说明和已收到的回复。确认本轮结束且存在后置回复后，工具前的说明才收进默认关闭的执行详情。只有内部协调的轮次仍可在真实回复到达时收起前言。结果可以由多个连续消息组成，不按相似语义去重，不截短或重新生成总结。没有后置结果、只有空包、截断历史、未知或混合执行来源时保留可用说明，不把过程播报冒充完成结果。问题、审批、真实失败、停止和结果不明提示继续可见，专员报告按真实作者保留；不跨用户轮次、独立 SDK 执行或角色边界折叠。过程说明使用共享 reply-process-text 的 13px 次要色排版，无重复头像或署名；执行详情保留原文与原始工具记录，显示过滤不修改持久历史。

- 当前轮新回复或暂停后收到的追加从首个可绘制帧开始呈现，首个快照已完成的本轮回复也可在原处短暂呈现。按待显示字素量调节推进速度，正常绘制时每包上限 180ms。前台错过绘制帧时用接下来的帧分批补齐；连续分块不重置已有文字的截止时间。首个非空公开文字事件的 SDK 根尚未同步时，立即请求一次权威快照。已有正文与历史恢复直接显示。
- 正常连接时通过 SSE 直接更新指定消息或专员正文，同一显示帧合并处理事件；不为每次文字更新重新拉取全量会话。实时文字事件携带目标正文的已接收前缀，重复或漏帧不会造成文字重复；完成、审批和结构变化仍以权威快照为准。TypeScript Pilot 将当前专员的进度订阅集中到已有的项目工作区事件流，按专员会话分发，各自用准确的快照恢复游标。断线重连或目标尚未加载时恢复快照，不通过动画推断成功。
- SRE 专员必须透传实际文本增量；结构化调查报告仅呈现已收到的 summary 正文，不暴露未完成 JSON。流式展示不按分块重写任务审计记录；专员结束到最终报告保存之间保留已收到的正文，不退回原步骤描述。
- 定时目录同步复用未变化的数据，模型信息更新不得重建会话订阅。并发快照按事件游标拒绝旧响应，避免正文、确认状态或任务状态回退。
- 按 Unicode 字素边界呈现中文、组合字符和表情。正文已显示的文字在完成时保留原节点；若同一回复仍有未呈现的尾部，沿用每包 180 ms 的截止时间原位补齐，任务状态与发送入口即时更新。停止、错误或正文替换立即显示实际完整内容。不让视觉缓冲延长任务状态或等待确认。普通回复的完成标记以本轮已证实的模型结果和错误记录为准，旧暂停任务的遗留操作保留原会话警示，但不能把后来独立完成的回复标为未完成。只自动校正最近一轮有完整结束记录、无本轮错误/待核实操作的计时，不推断早期历史或改写操作账本。
- 页面进入后台、或系统开启“减少动态效果”时直接补齐，取消未完成动画。Markdown 使用稳定组件引用，追加正文不得重建已有表格和链接；沿用现有滚动跟随，用户阅读历史时不强制拉到底部。
- Markdown 随实际接收的数据更新。逐帧呈现只更新仍待显示的纯文字节点，换段时继续使用同一显示位置。链接、引用、代码块和表格在结构收到后呈现。仅文字发生变化时，沿用历史消息原有的引用目录。

## 流式回复结束

- 回复是否结束以当前模型协议的完成标记为准，不等待供应商或代理关闭 HTTP 连接。完成后同步结束正文状态、会话调查状态和本轮计时，允许继续发送下一条消息。
- OpenAI 兼容接口的 `finish_reason` 后最多等待 1 秒收取用量尾帧；收到用量或 `[DONE]` 即完成。未收到用量时保持未知，不能当作零消耗。空的完成原因、正文中提到 `[DONE]`、心跳均不代表完成，工具调用仍须完整校验。
- 已有回复开始输出后连续 60 秒没有新的有效流事件，停止等待并以“未完成”结束本轮，保留已收到内容、操作记录和继续发送入口；不能把缺少完成标记的半条回复标为成功。用户停止始终优先，不被正常收尾覆盖。

Pilot 的文字召集使用紧接正文的协作栏。同一轮的召集回执与真实结论匹配时，结论在原派单确认的位置显示，原文收进执行过程。结论和专员原话按记录的用户消息归回原轮次，独立回复照常显示。报告入口与回应状态靠左相邻排列，空间不足时随内容换行。正在回复的专员用头像与人数显示，点击排队人数展开名单。已经收到的回复直接进入同一栏。结束时，执行过程、耗时和专员原话一并收进多头像报告入口。执行过程与耗时在展开区顶部，只有执行记录的轮次仍可直接查看。正在阅读、聚焦或选中的回复保留展开状态。失败和未回应的专员集中在独立入口，打开可查看实际原因。

## 图标

侧栏三个入口使用 22px 的 Lake `Glyph`。专员用水滴头像和并肩人形，资源用叠层，工作区用分栏窗口。未选中时为圆头线框，选中时为主题蓝色的实心图形，留白区分头像、层次和分栏。选中按钮使用淡蓝底色，图形在两种状态下共用同一尺寸与位置。

聊天输入框的发送使用 17px 上箭头，有草稿且发送可用时使用主题中性实底。停止按钮在 30px 方形的中性浅底点击区内居中显示实心方形。有草稿时停止和发送等高并排。模型入口使用 11px 展开箭头。生成中且输入区不足 370px 时，用供应商图标保留模型入口和完整的可访问名称。

通用操作图标统一通过 `Glyph`（`Icons.tsx`）使用 Lucide，常用尺寸为 14/16/18px，线宽沿用组件默认值。图标与文字间隔 8～10px。仅图标按钮必须提供 `aria-label`；装饰图标设为 `aria-hidden`，不重复朗读相邻文字。

资源侧栏保留实际已连接终端的绿色状态点，悬停和键盘聚焦时同样可见，不显示终端数量。连接状态未知或已断开不能显示绿点。“管理终端”使用 `Glyph` 的 `more` 图标、零内边距的固定尺寸按钮，与打开终端按钮留出间隔，避免图标裁切或覆盖名称。

厂商品牌图标统一通过 `ProviderIcon` 使用。快速接入卡片、供应商侧栏和详情标题必须保持同一品牌图形，不得以首字母、随意几何字符或自制近似标志替代。自定义 API 使用通用插头图标；不识别的代理地址不伪装成某个厂商。侧栏可按准确厂商名或受信任的预设端点匹配图标，域名必须完整匹配，本机服务还必须匹配端口。

聊天模型列表和输入区的模型入口使用 `ProviderIcon`。由 `modelBrand` 优先按模型 ID / 系列识别实际厂商（含 Magpie 和聚合接口的路由前缀），其次按显示名、已知厂商来源识别；无法识别时使用通用插头。聚合平台和本地运行器的图标不得用作未知模型的厂商图标。来源分组保持独立，同名模型通过供应商 ID 和模型 ID 区分。当前模型的显示名称、来源和图标必须使用启动响应里的 `modelSelection`，刷新页面后即可显示；不得依赖先打开菜单加载目录，也不得从同名模型的第一行猜测来源。页面可见时每 2 秒读取本地模型状态，窗口重新聚焦或页面恢复可见时立即同步 Magpie 的目录、显示信息和默认模型；设置页打开期间也自动同步，保留未保存的供应商编辑。同步不得触发上游模型发现请求或覆盖手动供应商选择，暂停期间及旧请求返回不得回滚本地保存结果。每次展开模型菜单时仍同步刷新当前选择。菜单刷新期间保留当前模型的展示信息，长名称在触发器省略并通过提示显示完整名称和模型 ID。

厂商 SVG 位于 `web-agent/web/public/providers/`，当前来源为 MIT 授权的 Lobe Icons 静态 SVG 包。新增或更新时同时维护 `provenance.json`、原始许可文件和第三方声明。不得运行时请求远程图标；保留 SVG 原始比例和彩色品牌色。单色图标在深色主题下统一反色，彩色图标不反色；不拉伸、不加文字水印。

待发送消息采用输入框上方的轻量气泡队列，移除整块外框和横线；所有待发送消息直接列出，不提供收起或展开入口；长队列内部滚动。不显示“接下来”标题或常驻暂停按钮，数量和发送状态仅用于无障碍播报。编辑或异常使队列暂停后，在消息下方按需显示无底色的“继续发送”，避免无法恢复；操作悬停、按下及聚焦时也不加背景，保留文字反馈与键盘焦点框。编辑入口仅使用铅笔图标，与移除按钮始终可见，不再依赖悬停；保留无障碍名称与悬停说明。多条消息常显 28px 操作区的拖动手柄，采用指针捕获，移动超过 4px 后开始排序，显示插入位置并在列表边缘自动滚动；拖动期间队列修订变化时取消并提示重试，Escape 可取消，不再显示上下移箭头按钮；手柄继续支持键盘方向键排序；仅一条时不显示排序控件。键盘排序保留移动后消息的焦点；编辑继续先暂停队列，引用、附件、修订检查和错误恢复沿用现有逻辑。排队成功用队列内容与无障碍状态反馈，不再叠加成功提示；输入框提示为“继续输入，稍后发送…”。

## 聊天输入

TypeScript Pilot 的普通消息在 Router 或专员执行期间也直接接单，输入框可提示“继续发送新任务或补充要求…”，发送入口始终使用“发送消息”。不把运行状态或旧待发送草稿转换成整段对话的排队模式；停止入口独立保留。新消息出现在主对话内，当前回复和过程按宿主真实来源消息保持原轮次，不能借最新用户消息、到达时间或相同专员名称重定向在途回复。独立任务继续并行，补充沿准确旧任务续接；前端不自行判断任务去向或广播消息。非 Pilot 与旧 Go 队列行为保持。

聊天主输入框统一使用 `ComposerTextInput`。「设置 → 对话 → 文字补齐」管理空框建议及草稿续写，默认开启。空框聚焦后显示一条本地起步或追问建议，单行省略。草稿停顿且光标在末尾时，可以补齐未写完的话或在问句后建议一句追问。「真的吗？」等简短的核实问句在已有回复时使用本地建议，其余续写使用当前可用模型。排队、待确认和资源选择期间优先保留各自的交互。中文输入法组字、输入中途移动光标、页面隐藏、模型切换及清除草稿会取消或清除旧建议。

灰字建议在 Tab 接受后才进入草稿，支持撤销。Escape 忽略，Enter 沿用发送快捷键。建议和光标锚点不进入复制、保存或发送的内容。TypeScript 内核的补齐请求只使用当前草稿和现有模型连接，不读取历史、记忆、项目资源或工具。发送草稿继续沿用原会话及任务关联。

草稿随内容自动增高，最高 160px 后内部纵向滚动；长文本和连续路径按实际列宽换行，不产生横向滚动条。引用的插入、移除、复制粘贴、撤销及可见光标继续使用同一编辑文档，适配窄窗口与深色主题。

TS Pilot 的停止入口跟随当前项目真实活动的 Worker，包含排队、执行和等待实际交互；Router 回复结束不隐藏停止。空草稿期间仅显示停止。写新草稿时发送按钮在停止按钮旁出现。停止后保留草稿，焦点从停止按钮返回编辑区。停止当前项目活动任务及待派发输入，保留历史停泊任务、其他项目和原操作记录；unknown 仍须核实。

输入区仅显示停止图标，悬停提示和无障碍名称按实际范围区分 Pilot 的“停止当前项目全部任务”、专员频道的“停止该专员全部任务”和单任务的“停止当前任务”。窄窗优先缩短模型展示名称，生成中进一步缩为品牌图标，让停止与发送按钮保持可见。任务详情按钮显示“仅停止此任务”，悬停提示包含任务标题和停止范围。提交期间显示“正在停止…”。

## MCP 与 Skills 配置

在设置页面内提供 MCP 和 Skills 标签页，沿用主题色和 `Glyph` 图标。MCP 使用服务器列表和独立编辑页，编辑页右上角以胶囊选项切换“表单 / JSON”，作用域显示实际支持的“用户 · 本机”；连接类型与协议版本使用共享 `AppSelect`。表单包括名称、类型、超时毫秒、协议版本、命令与空格分隔参数或远程地址，环境变量 / 请求头默认折叠。保存后返回列表，保留单独的连接测试、启停和移除操作。Skills 保留左侧来源与详情结构；窄窗口相应堆叠，保存操作保持可见。

- MCP JSON 支持服务器名称映射和 `mcpServers` 包装对象，可粘贴或选择不超过 100 KB 的 JSON 文件，一次导入 1～50 个服务。完整校验后在同一私有文件事务中保存；同名服务不覆盖，任何条目无效均不部分导入。多条配置只在 JSON 模式保存，不在切回表单时丢弃条目；单条表单 / JSON 切换保留参数顺序、引号、空格、空参数与全部控制字符；包含控制字符时用 JSON 字符串数组展示，避免改变实际传入参数。超时范围 1000～300000ms，新配置默认 30000ms；协议默认自动协商，可显式选择当前 SDK 支持的版本。校验错误不得带出用户粘贴的认证内容。

- MCP 支持 Streamable HTTP、SSE 与本机 stdio。保存只写入配置，测试连接才进行握手、读取工具列表；不得以保存操作隐式启动程序。连接错误保持表单可编辑，返回可读错误，不显示认证材料或服务原始错误。正常工具发现和调用按服务配置共享握手，不让慢服务阻塞其他服务；停用、移除或改配可取消未完成握手，旧连接失败不得断开替换后的连接，不自动重放已发出的工具调用。
- 请求头和环境变量使用密码输入，保存后不回填原值。留空保留原配置，输入 `{}` 清空；服务地址不得携带用户密码、查询参数令牌或片段。
- MCP 工具按启用配置提供给聊天 Agent；没有启用服务时，不占用工具目录与默认上下文。调用遵循会话的静默执行命令、本机执行和资源范围权限。操作确认显示服务名、实际工具名和本次参数，隐藏内部服务 ID；MCP 工具自述不能代替授权。
- Skills 支持新建和编辑 Lake 管理的 `SKILL.md`、导入本机技能根目录或单个技能目录、刷新与启停。外部导入的内容只读，移除目录配置保留原文件与相对引用。
- Skill 停用后不得再次发现或加载；目录和内容不构成越权授权。默认目录及启停状态跟随当前 Lake Home，Dev 和正式版保持隔离。

## 窗口转角一致性

主要容器通过 `windowCorners.css` 共用 `--radius-window` 与 `--corner-window`：侧栏入口、选中行、资源目录、工作区按钮、悬浮标题、消息气泡、代码框、引用候选外框和候选行。macOS 26 以实际窗口截图的轮廓为基准，使用 22px 转角展开范围和 `superellipse(1.5)`；宽高至少为半径的两倍，避免浏览器因高度不足把 22px 压缩为不同尺寸。文字字号与横向留白保留，仅调整必要的最小行高。支持的浏览器直接绘制同一曲线；macOS 26 的旧 WKWebView 通过本地九宫格矢量蒙版绘制相同背景与边框，随主题、悬停和焦点继承样式，不添加轮询或逐帧测量；不得把仅 computed border-radius 相同当作实际一致。

会话状态徽标、输入区已选引用与消息引用标签使用相同窗口曲线，转角展开范围缩放为 8px，保留原有 20.5～24px 高度、类型配色、状态点与无边框的引用底色，不扩成 44px 标签；原生兼容绘制使用对应的小尺寸曲线遮罩。输入框收起和展开时均与状态岛共用 `--radius-window`、`--corner-window` 及其兼容描边。输入框内附件、权限与停止按钮共用外框的连续曲线，30px 点击区使用 `--radius-composer-action: 9px`，包含旧 WKWebView 的同曲线遮罩。其他图标按钮和系统红黄绿按钮保留圆形语义。旧版 macOS 继续由宿主提供系统对应的尺寸与 round 回退。验收同时测量宽高、有效半径和 corner-shape，并比较实际截图中的转角轮廓；覆盖悬停、选中、深色与窄窗口，检查滚动、焦点、弹层和复制交互。

## 聊天 @ 引用

主输入框的 `@` 候选统一包含资源、Skills 和 MCP，提供“全部 / 资源 / Skills / MCP”分类、数量、名称及简介搜索。资源候选保留真实 `resourceKind`，与输入区已选标签、发送后的引用共用 `ResourceIcon`：SSH 主机、数据库、Redis、容器与本机分别展示实际类型图标，右侧同时显示类型名称；Skill 使用 `book`、MCP 使用 `plug` 的 `Glyph`。不按名称或 IP 猜资源类型，同名对象通过稳定类型和 ID 区分；按“数据库”等类型名称也可筛选。只列出已启用扩展，展开时重新读取配置；读取失败显示重试入口，不隐式连接 MCP。

资源引用标签按真实类型使用浅底、深色文字的圆角配色：SSH 主机蓝色、数据库青绿色、Redis 琥珀色、容器紫色、本机中性灰色。侧栏资源图标及 `@` 候选图标使用相同的类型前景色；资源目录图标使用主题淡金色，箭头、名称、数量与操作按钮保留中性色，悬停、选中与键盘活动时不改变类型色。输入区与消息共用配色规则，图标和文字使用同一前景色；标签不加彩色边框与阴影，以内边距维持原有宽高和文字位置。深色主题使用对应的低明度底色和高明度文字。未知类型和非资源引用保留中性样式，不能按名称或 IP 推断类型，不把类型颜色当作连接或执行状态。

输入区已选引用使用 24px 高 / 12px 转角，消息引用使用 22px 高 / 11px 转角，均按短边缩放同一窗口曲线；上下文引用及文件附件标签沿用 `--radius-window`；代码块复制与标签移除图标按钮沿用相同圆角，在方形点击区内自然呈圆形。保留标签大小、原始文本、复制、移除与键盘焦点行为；行内代码继续使用文字层级的小圆角。

`@` 弹层外框、候选行与分类标签沿用 `--radius-window`，与工作区胶囊控件一致。列表只用唯一的 `aria-selected` 绘制活动背景；真实鼠标移动同步活动项，键盘上下键更新同一项，静止鼠标和列表滚动不反向抢回选择，不能同时出现悬停与键盘两块高亮。点击、Enter、Tab 继续按实际选中对象引用，焦点保留在输入区。

- 长列表内部滚动，不截断后面的扩展选项；键盘活动项自动滚入可视范围。方向键移动，Enter / Tab 选择且不发送消息，Esc 关闭；空结果时 Enter 不得误发消息。中文输入法优先，候选展开期间暂停行内文字补齐。保留焦点、无障碍名称、活动项及展开状态，点击外部关闭。
- 引用由实际选择的类型与稳定 ID 建立，在草稿内以可移除的标签表示，正文编辑不影响标签选择。资源 ID、Skill 名称与 MCP 服务 ID 分开传递，同名对象互不混淆。发送时扩展引用保留服务端校验的真实文字范围；待发送队列保留引用，编辑时移除被删改的扩展引用，派发前重新校验启用状态。
- 服务端从本地配置解析 Skill / MCP 元数据，不信任客户端传入的内容、描述、调用参数或权限声明。所选 Skill 引导 Agent 使用 `load_skill` 加载，所选 MCP 指定工具发现的服务；选择操作不执行工具、不新增授权、不改变资源目标。MCP 认证材料不得进入候选或消息引用。

## SRE 专员回复

输入框的 SRE 协作开关保存时保持当前颜色、尺寸和焦点，不通过原生禁用按钮显示禁止光标或变灰闪动；使用 `aria-busy`、`aria-disabled` 和提交保护防止重复写入。运行中或连接中断时保留禁用约束，以普通箭头光标和提示说明原因。保存失败可重试，不先展示尚未确认的开关状态。

专员沿用无底色、小尺寸湖生态头像和对话正文，不把报告包成独立大卡片。正文最大宽度 820px，使用 14px 字号、1.85 行高；分组之间保留 20px，事实列表之间保留 9px。浅色、深色、窄窗口共用主题变量。

专员频道复用已有频道 SSE 的快照游标更新当前进展，轮询仅作补充；请求重叠时接续读取最新状态，不丢弃刷新通知。具有准确 taskId、sourceSessionId 和 SDK root 的同一任务重试，默认只展开最新一轮回复，前轮报告收在“之前的执行”，原报告与执行账本保留。每轮正文前用轻量元信息区分“最新一轮/历史轮次”、原始发言者和真实记录时间；历史分页不编造或重排全局轮次序号。不同任务、来源、用户补充和没有准确归属的旧记录不得按正文或名称合并；待确认和未知操作入口仍属于原任务。当前任务回复保持稳定节点，替换进度文字及完成总结以 220ms 轻移淡入承接，流式追加与未改变的轮询不重播；首次加载历史、后台页面、减少动态效果、断连及重要等待/失败状态直接显示。

旧顺序分工的多步调查计划应说明“调查员先完成采集，协调者再汇总”，不能让单专员执行看起来像已并行。升级沿用的完成记录显示“已沿用”，提示未重新执行。执行中的专员使用共享 StatusText 和轻量旋转指示显示真实活动、耗时与证据数量；暂停、待确认、未知和结束停止执行动效，prefers-reduced-motion 下完全静止。Plan 的未知结果优先于“处理中”，核实入口直接定位实际操作记录。并行专员分别在对话中显示发言，定向交流在名称旁以 `Glyph` 箭头和接收专员名称标识。进展状态来自真实 AgentRun，等待确认不能显示为正在执行。进展与团队交流不重复附带整个操作记录；最终回复在完成时追加，保留交流时间顺序。

同次专员的成功操作默认合并为一行折叠记录，按需展开查看每条参数和原文。失败、等待确认、未知和未执行的操作保持直接可见，未知结果的人工核实入口不可收入成功分组。同次失败依据 attempt 归属和完成时间去除父错误卡、系统消息的重复副本；不能删除其他轮次的错误，也不修改持久审计记录。

中断或停止 SRE 后，不在输入框上方自动显示“原操作结果待核实”面板或核实表单。原始操作与未知状态保留在执行记录中，按需查看，不用额外弹窗占用对话输入区。普通会话不因历史操作 unknown 或仍在运行就锁住后续新命令；新调用按当前目标和权限执行，同一持久调用不重复派发。“执行记录”仍提供默认折叠的“待核实操作”：仅列出服务端返回的 unknown 变更，运行中只查看、停止后才可记录。核实是审计入口，不是解锁普通会话的前置条件；记录时必须显式选择真实结果并填写核实依据，不能以“忽略/放弃”代替事实，也不能从该入口重试原操作。

调查报告直接使用后端已保存的 `attempt.report`：先显示结论，再分别展示观察事实、待验证假设、尚未确认、后续检查；隐藏空分组，不通过正文关键词猜测事实或验收状态。证据编号只匹配同次 attempt 的真实记录，点击展开该消息的证据区并聚焦对应原文；不执行新的采样操作。错误、进度和用户消息不得继承已完成报告。没有结构化报告时，以及其他专员的正文，使用禁止原始 HTML 的 Markdown 渲染，支持段落、列表、表格和等宽代码。

SRE 正文的 Markdown 渲染器必须保持稳定引用；未变化的正文复用已有节点，快照和计时更新不得重建表格或链接。耗时使用固定宽度，已在底部且内容高度未变化时不重复写入滚动位置。命令因静默检查未通过而额外确认时，不应仅凭审批类别就显示为“删除或移动”；保留实际审批要求和目标确认。

普通对话在当前轮运行及等待确认期间，黑色正文统一显示在该轮灰色进度上方；后续新增说明仍插入进度区之前，正文之间保留原始顺序。已完成及恢复的普通对话也保持正文在上、灰色过程入口在下；执行记录视图仍按原始顺序展示。执行过程入口在同一轮内保持稳定挂载，不得因流式更新重建进度节点或丢失展开状态，审批、错误及子任务入口保留。每轮回答中，同一真实资源只保留一条灰色操作摘要，固定使用首次出现的卡片 ID；后续思考、黑色说明、其他资源交错、终端或容器切换、失败与审批均不另起该资源的进度行。摘要原位更新当前操作与累计项数，失败、待确认、未知、未执行、已停止和后台操作在原行明确计数，不用后续成功掩盖。展开后保留全部工具参数、结果和原始思考；审批、错误正文和子任务仍保留各自入口，不改变执行或权限。不同资源保持独立，不因名称相同就合并；新一轮提问重新建立分组。后台命令的失败、完成及等待/读取/停止记录按原始 shell_id 和派发资源归组，后台卡保存原始资源与父操作身份；旧记录仅在精确句柄能找到唯一派发资源时关联，不沿用当前选中主机或按邻近位置猜测。来源不明或冲突时保留独立记录，不能隐藏错误。仅新资源行播放入场动画，既有行更新不重播、不重新挂载、不改变开合状态。下方仍有空白时不写入滚动位置；溢出视口后正常跟随，用户上滚阅读时暂停。同高度的进度与计时更新不得触发额外滚动。

主会话输入区上方的确认面板与问题入口使用共享 composer-session-controls 内容列，宽度、居中位置随输入框和会话列同步变化；不得沿用独立660/860px上限使宽窗口偏左。专员内嵌确认仍服从其所在报告列。专员当前待答问题直接显示在 Pilot 该内容列，问题面板内保留真实专员姓名、湖生态头像和任务标题；无需先打开任务详情。多个原任务的问题分别保留草稿，以 worker/question 身份稳定挂载，答复使用准确来源 Session 与原问题 ID。补充使问题继续、停止或失效后撤下面板，断连只禁用交互。操作与计划审批保持独立，不将补充或问题答复当作批准。

附件上传确认使用中性表面、细边框和共享文件图标，直接展示原文件名、大小、目标名称与完整保存路径。工具名、资源 ID 和原始参数收在默认折叠的“技术参数”中。按钮使用“取消 / 上传文件”；明确请求覆盖时使用“覆盖并上传”并提示同名文件的影响。保留原有权限、输入目标确认和操作记录，不用大面积警告色表达普通上传。

文件读写与删除确认同样使用中性表面和轻量文件面板，直接显示操作名称、文件名、目标与完整路径；不默认展开资源 ID 或整段 JSON。内容预览默认折叠，准备好的 Markdown 文件展开后按文档排版，支持切换原文，不加载远程图片或执行原始 HTML；其他内容保持等宽文本。预览仅滚动内容区域，授权按钮始终在其外部，保留空文件及原始精确内容。已有变更前后版本时显示真实增删行数；缺少完整预览时不把补丁伪装成完整文件。技术参数按需展开，按钮明确为允许写入、允许修改、允许追加、允许读取或删除文件；高风险、目标确认输入、排队数量和单次授权规则继续保留。

## 验证要求

每轮真实文件变更在折叠统计上方直接列出文件超链接，方案 Markdown、YAML 和脚本均可点击；本轮已成功写入且未删除的本机文件使用独立文件卡片：左侧共享文件图标、完整文件名入口和“本机 · 文件类型”，右侧“打开”在 Lake 内预览已记录版本；窄窗口截断长文件名，同名文件补充路径，完整路径保留在提示和预览中。失败、待确认和已删除记录不得伪造为可打开的新文件，差异统计与原记录继续保留。来源主机或容器重名时保留区别。预览只使用本轮操作中已保存的文件版本，明确注明来源和完整路径，不额外读取主机、不执行脚本。Markdown 方案默认排版阅读并保留原文，相关文件链接仅解析到同一目标、同一目录语义下的已记录文件；未知或歧义路径不猜测，不加载远程图片或原始 HTML。原有差异对比保留，已删除记录可查看变更前内容。预览使用原生模态对话框，Escape 关闭、焦点返回原链接，窄窗口可完整滚动查看。

“跟随系统”必须保留为独立的外观偏好；macOS 窗口清除显式 appearance，继承系统外观，再由 WebKit 的媒体查询同步正文、导航、终端和弹窗。不得把当前解析出的浅色或深色重新固定到原生窗口，否则后续系统切换不会生效。手动浅色、深色继续固定，重启后恢复已保存的偏好。

修改公共选择框时，检查键盘导航、禁用项、受控值和默认值、Escape 与外层弹窗的关系、焦点回到触发器、窄窗口边界、底部向上展开、长列表滚动和深色主题。SSH 等字段还需确认原有变更事件及凭据保留/清空逻辑正常。厂商图标检查快速入口、侧栏、详情的一致性及离线可用性。

运行 TypeScript 检查和相关前端测试，通过签名脚本构建并在 Lake Dev 中验证。仅使用隔离测试数据；不在截图或验证记录中包含密钥。验证结果和截图存放在 `docs/validation/`。

历史任务不占用会话任务槽位，新目标可直接建立独立任务，不要求先取消、收尾或恢复旧任务；旧计划、证据与记录原样保留。运行中的父轮仍串行调度，实际操作继续使用原权限、审批和持久调用防重放规则，建立新任务不代表恢复或执行旧任务。

SRE 输出节奏按实际 Plan 节点区分：observe/analyze/act/verify 完成时给 1～3 句节点小结；summarize 只在结束时汇总一次。调查报告正文只默认展示 summary，结构化事实、假设和缺失证据收在“查看节点详情”；历史长篇节点回复收在“查看节点小结”，不删减持久记录、不自动编造摘要。不能仅凭协调者身份或旧消息 kind=summary 判定为任务最终总结，必须关联该 attempt 实际执行的历史 Plan 步骤。正在执行、协作请求、错误和审批不受节点详情折叠影响。

持久终端命令的等待超时与命令失败必须分开。原命令仍有实际终端/entry 句柄时应继续通过 wait/output 查询，不重复派发，也不把专员或其同伴一并取消。Plan 的操作完成状态只根据唯一匹配的原终端完成记录与退出码更新；不能由模型文字、相似命令、其他会话或不完整输出推断。明确“重新开始”通过 restart_task 原子结束旧的暂停只读调查并建立同目标同范围的新调查，保留历史；结果不明的变更、仍在运行的操作和变更任务不能靠重启绕过。只读超时保留原记录并允许新采样；只有结果不明且不能证明为只读的操作才提供核实入口。正在运行的操作仅显示原命令进度，不能提示人工确认成功。正常回复结束沿用下方“计时与执行过程入口”的中文用时样式；没有真实起止时间则不编造耗时。正常运行的思考等待立即显示水波加载状态，专员不附带聊天头像，不显示小于 1 秒的耗时提示；确认、失败、停止和结果未知等重要状态立即显示。停止、未完成、中断、后台执行和结果待核查仍须显示，任务状态独立保留。并行专员对同一主机和配置共同等待一个真实指纹决定，不自动信任。

## 轻量交互细节

回复正文和 SRE 报告的代码块使用共享 `MarkdownCodeBlock`：主题底色、细边框、`--radius-window` 圆角，单行随内容收缩，长代码在自身区域横向滚动。右侧仅常显 Glyph 复制图标，不显示执行按钮，也不再使用独立的顶部工具栏；多行代码的复制按钮靠右上角。复制按钮不随长命令滚出可视范围、不遮挡代码。明确标记为 Shell 的单行命令采用主题终端蓝色命令名和绿色参数，多行、其他语言与普通文本不套用此配色。复制保留整段原始文本的路径、引号、空格及换行；成功短暂切换为勾选图标并报告“已复制代码”，失败明确提示使用键盘复制，不误报成功。行内代码保持原样，按钮支持键盘、触摸与深色主题。

次级详情、证据、操作记录和技术参数统一使用 `DisclosureSummary`，透明入口配右侧细线箭头，保留原生键盘开合、可见焦点和原文；执行过程等具有独立布局的主入口保留原布局。排队消息与普通问题使用中性主题表面，真实错误才使用错误色。操作按钮统一使用共享 Glyph，不用字符拼接关闭、编辑或排序图标；深色模式的表单、问题和资源标签不得写死白底。

待发送消息气泡使用浮层材质变量：55% 中性底色、12px 背景模糊、系统窗口圆角、细边框，悬停/聚焦为 68%。待发送气泡使用更轻的独立阴影，外层及滚动列表完全透明，避免阴影被裁成整块方形底。队列悬浮在正文滚动区域上，不占用正文高度；仅在记录末尾按实际队列高度预留空间，正文可从其背后经过。队列增减、编辑和窄窗口随测量更新留白；减少透明度或不支持背景模糊时使用实色回退。 新追加的待发送消息在 260ms 内展开高度、轻微上移并淡入；发送或移除时在 200ms 内淡出收高。剩余消息保持稳定身份，排序以 260ms 平滑移位；退场副本立即 inert、隐藏于辅助技术且不再提供队列操作目标，不延迟实际发送。队列接入下一轮后，新用户消息以相同的 260ms 轻移淡入承接；同一队列/正文刷新与历史恢复不重播，减少动态效果及后台页面直接切换。

新增黑色正文和灰色操作行使用 360ms 缓出动效，从下方一行（23px）上移并淡入；只作用于新追加的记录，不缩放、合并或重建前面的行。既有行的文字/状态更新、历史恢复及完成状态切换不重播。遵循减少动态效果偏好。回复正文不另占一行展示流式圆点，整轮执行状态由每轮开头的参数行承接；运行与结束状态保持相同的耗时行高度和底部留白，避免完成时滚动区域骤缩。

执行中的灰色操作摘要使用中性扫光文字，3.6 秒循环，仅重绘文字，不位移、重建节点或改变行高；失败、待确认、未知、后台和已结束轮次的记录不播放。减少动态效果时保持静态可读文字。每轮耗时与状态放在用户提问之后、回答正文与灰色执行行之前，不放在整轮末尾；历史轮次同样保留准确归属。该参数行保持固定的单行高度，避免状态切换推动下方正文。仅移动展示位置，不改变模型、权限与思考级别的操作入口。

同轮属于同一项目功能类别的普通操作也始终复用首行：工作流、任务进度、资源目录、Skills、历史会话、工具结果、任务输出与 MCP 分别归组。旧定时任务的执行记录沿原分类归组。历史会话、工具结果、任务和 MCP 服务必须保留真实 session_id/result_id/task_id/server_id 的作用域，不把不同对象或缺失句柄的记录误合并。询问用户、正文和审批保留独立入口，但不打断同作用域的摘要分组；失败、未知、停止和后台状态在该行明确显示。展开后保留全部原始操作，新增同类项不重建行、不重播入场或扫光、不写入滚动位置。新增会话工具时必须明确分组类别或边界规则。

输入区使用同一可编辑文档混排正文和原子引用标签，文字可位于标签前、后及标签之间，侧栏添加和 `@` 选择均插入光标位置。标签只显示类型图标和名称，不显示 `@`，不另列一行重复资源名。引用在文档中占一个原子位置，按稳定类型和 ID 解析；移动光标、跨标签选择删除、点叉、撤销和重做保持正确身份与顺序。Shift+Enter 保留换行，中文组合输入期间不重建编辑节点、不误发消息。粘贴默认只接收纯文本；同一编辑会话的内部剪切粘贴可保留已选引用，其他来源不得仅凭名称或剪贴板声明新建绑定。自动补齐、附件、发送及排队入口继续有效，发送按句子实际顺序展开引用并保留服务端校验的真实文字范围。

发送后的用户消息按已保存的 UTF-16 引用位置恢复内联标签，与文字保持原顺序；标签显示资源/扩展图标与名称，不显示 @ 和删除按钮，刷新会话后仍保留。展示引用不改变发送文字、模型上下文或资源权限。新消息显式保存空标签数组时保留字面 @ 文本；旧消息仅以当前已知资源名兼容展示，匹配优先完整长名称，不改写历史。队列保留标签位置，编辑时随文字移动或移除，实际发送后沿用同一展示。

每轮计时行与第一条进度/正文之间保持 12px，计时行不额外叠加底部 margin；同轮条目沿用 12px 间距。当前轮最后一条正常灰色进度在工具已返回、模型准备下一步期间继续文字扫光，本轮结束后停止；生成正文期间继续显示当前正常摘要的扫光；历史、失败、待确认、未知和后台状态保持静态。同一资源行更新不重新挂载或重启动画，减少动态效果设置继续禁用扫光。

每轮进行中的状态图标采用首版“湖面流动”：共享 Glyph 的 waves，18px 单色细线、20px 固定占位，使用次要文字颜色；三条水纹按 0 / -0.35 / -0.7 秒错峰，在 2.4 秒内柔和明暗和 ±0.5px 轻微横移，不旋转整体。待确认与完成时沿用现有隐藏规则；减少动态效果时显示静态清晰水纹。

文件变更摘要使用透明、无边框的轻量详情入口：左侧文件图标，文件数量、绿色新增和红色删除统计及右侧展开箭头保持单行水平对齐。默认不铺灰底，悬停或展开时使用主题浅底色，保留键盘焦点与原生 details 行为；窄窗口文字可换行，统计不可截断。回答进行中沿用“正在思考…”等真实状态，耗时、停止状态与执行过程入口统一使用下方规定的中文用时样式，不再重复定义时钟或英文单位；运行中的动态水纹继续保留。用户停止本轮后，仅在计时行以次要文字显示“用时 … · 已停止”；该轮已有停止计时状态时，普通对话不再重复显示红色“已停止本轮”。真实错误、工具停止状态及执行记录继续保留；旧记录缺少计时信息时仍保留停止提示。

本地终端是项目内置入口，固定在资源列表根目录顶部，不显示“内置”文字标签，不显示拖动手柄、移动和删除操作，也不参与资源批量删除或全选。保留终端打开、新建连接、Shell 配置、资源信息和添加到对话。服务端拒绝本地资源删除及移动，不能只依赖前端隐藏。升级时为缺失的活动项目补齐入口，恢复旧版已删除的本地资源并保留 ID、名称、Shell 配置及历史引用；已嵌套的移回根目录。恢复旧目录不得把本地终端重新收进去；项目本身仍可删除与恢复，本地入口随项目生命周期展示。

普通 Agent 的目标资源、终端创建、MCP、SQL、命令和导入确认统一使用中性紧凑面板，不再使用整块黄色底色。突出目标名称和本次影响，资源/终端 ID 与完整技术参数默认折叠；完整命令或 SQL 仍直接可见，导入预览与文件差异继续展示。高风险、必填目标输入、等待队列及未执行状态不得隐藏。仅替换展示组件，原有单次决策 ID、子任务身份和确认校验保持不变；SRE 专属动作继续使用其影响、停止条件及回退说明。

普通操作、文件和附件确认面板的标题图标统一使用共享 `Glyph` 的 `lakeConfirm`（湖面确认）：上方勾选、下方双水纹，24px 画布、1.4px 圆头细线，以 18px 显示并沿用主题次要文字灰色，保持与标题对齐。图标保持静态，文件类型、危险/删除提示仍使用各自语义图标，不以品牌图标替代风险说明。

灰色执行摘要在文字前使用 20px 固定占位、18px 共享 Lake 语义图标，命令/终端、文件、搜索、目录、主机、数据库、容器、工作流、MCP、提问和旧定时任务记录分别区分；仅根据真实工具身份选择，未知工具使用通用水纹，不从命令或返回内容猜图标。展开记录复用同一映射。非运行图标静态、保留类型色、圆头细线；运行时使用下方执行图标的横向彩色水流规则；保留同资源唯一行与全部异常计数，图标更新不改变行高、不添加状态环或重启入场动画。

对话自动跟随按实际滚动意图区分：内容未溢出时，点击正文或展开/收起短进度不得永久暂停跟随；新增正文溢出后继续平滑跟到底部。底部向下滚轮/按键因无法产生 scroll 事件，不得误锁跟随。向上滚动、拖动滚动条、触摸滚动、选择文本或阅读可滚动的操作详情时暂停；手动回到真正底部后恢复，仍保留像素取整容差、无高度变化时零滚动写入和减少动态效果偏好。加载更早记录继续表明阅读历史的意图。

后端最近 300 条卡片的连续分页窗口向前推进时，前端保留本会话已展示的前缀，并按卡片 ID 应用新的结果。不能把分页淘汰当成历史删除，导致每执行一步都改变正文高度、替换历史节点或重新定位滚动。切换会话不混入其他会话记录；真正缩短历史及非连续的页面仍保留正确的替换/加载更早边界。新增步骤保留原进度行和已展开的命令详情。

上下文用量圆环与顶部会话状态共用当前会话（含 SRE 展示状态）和同一主题色：调查中蓝色、待确认黄色、回复结束绿色、需要关注红色、待命灰色。状态和主题变更在同一轮渲染更新，不单独缓存颜色。圆环长度和详情继续使用当前模型的服务端实测用量，未知时不编造比例；接近输入预算上限时在详情和无障碍说明中保留警告，不覆盖状态色。

上下文详情采用约 292px 的紧凑浮层，使用共享 UI 字体与等宽数字排版，不使用整块等宽字体。概览展示输入预算使用率、实测输入 / 有效输入预算、剩余预算和最近请求缓存命中；缓存率按该次请求输入计算，不称为平均命中率，也不扣除缓存来缩短占用。没有服务端分类明细时不生成消息、工具或技能占比。模型窗口、总预算、输出预留、输入/输出、缓存 token 和会话累计收在默认折叠的“用量明细”中。浮层按视口避让，展开后重新定位，低矮窗口内部滚动；悬停可进入卡片，点击固定、外部点击关闭，Escape 关闭并返回入口焦点。

计时行中的用时、分隔点与运行状态文字作为同一个共享 StatusText 整体扫光，耗时每秒更新但不重建节点或重启动画；等待确认、结束或停止时不播放。工具已返回、随后新增正文或正在生成正文时，当前最新正常执行摘要继续扫光，直到本轮结束或出现下一条操作；包含失败、待确认、未知、未执行、停止或后台结果的摘要保持静态。更新文字与计时不重新挂载节点、不重启动画，减少动态效果设置下全部静态可读。

Pilot 和专员的新回复正文沿用 AccordionOS 的入场节奏。正文从上向下裁切展开 400ms，淡入延后 80ms，轻微模糊及 8px 位移过渡到清晰的正文位置。首个有效正文到达即按实际内容排版，后续流式追加保留同一节点与动画进度。恢复历史和减少动态效果时直接呈现。[AccordionOS 参考](https://uselayouts.com/docs/components/accordionos)

普通对话的“本轮文件”入口与文件变更统计在整轮回复结束后统一出现，作为一个整体复用 360ms 淡入上移入场；模型仍运行或等待确认时不提前展示。失败、停止和中断结束后仍展示实际已完成的变更，不把部分成功写成整轮成功。实时完成记录只入场一次，后续更新、展开详情和预览不重播；恢复已结束的历史直接显示，减少动态效果时静态展示。执行记录视图仍可实时查看已落地的文件差异。

过程正文从收起状态恢复时立即使用完整固有高度，不播放 0fr 到 1fr 的展开过渡，避免正文已经绘制而外层高度仍在增长时与下一项重叠；归档收起仍保留原有裁切和淡出动画。

### Mini Box

普通会话及 Pilot 专员执行子级中，每个已明确解析的本机或 SSH 资源在“执行命令”三级节点内复用一个 Mini Box，本机标注“本机”、远程标注“SSH”；单台执行时命令派发默认展开；同轮涉及两个及以上不同本机/SSH 命令资源时，Mini Box 默认仅显示 36px 标题栏。计数包含已完成命令，不依赖同一采样时刻是否都在运行；执行完成和历史恢复仍适用。第二台出现时首台若尚未手动操作，自动收起一次；手动开合或查看原始输出后不再自动改变。折叠标题栏直接展示当前命令（等宽单行、长命令省略、悬停显示全文），没有命令时显示“等待命令派发…”，保留状态、终止按钮和异常入口；同台多命令、非终端工具、其他资源类型不增加资源计数，各轮单独判断；Pilot 以当前计划运行中所有专员的实际命令资源计数，同资源归回首次出现的分组。Mini Box 首次出现以 320ms 淡入、轻微上移及布局高度展开，折叠/展开以 280ms 平滑改变 36/144px 高度，预览文字随之淡入淡出，开合箭头同步旋转；收起预览立即从辅助技术和键盘导航隐藏，输出更新不重播入场或改变开合状态。减少动态效果时取消上述过渡。统一最大宽度 720px、高度 144px（标题 36px、预览区域 106px），窄窗口只压缩宽度；当前命令固定一行，默认最多三行输出，新命令及输出原位更新、不随输出撑高。空行清理、连续重复合并计数、回车进度原位更新，原始记录不受预览整理影响。首处异常线索及相邻上下文固定，其余位置显示最新输出；异常入口显示数量并展开定位，不能将文本匹配直接判为失败。退出码、未知结果、终止和连接状态以真实执行记录为准；退出码零但有异常线索时明确提示核查。完整输出按资源独立展开为 280px 内滚动区，保留全部已收到记录，用户阅读期间不自动抢滚动；Mini Box 自身尺寸保持不变。终端接近原有 32KiB 记录上限或尾部已滑动时，入口改为“保留输出”并提示容量限制，不虚称完整记录；当前视图已观察到的异常单独保留，收起资源不卸载其异常缓存。权限失效、切换会话/轮次/资源及 terminal generation 替换清除相应缓存和操作目标。沿用 Lake 主题、14px 面板窗口曲线、轻微磨砂材质及共享 Glyph；文字不参与背景模糊。原始命令记录按需展开，其他工具和资源保持原分组。

`inspect_host` 的主机检查同样会执行真实终端命令，须从工具派发的首次渲染就显示 Mini Box，不等后续 shell 调用、历史接口返回、effect 或进度入场动画。原始工具参数与结果收在“原始执行记录”；终止检查中的当前命令后，不再派发该次检查的后续命令，其他资源不受影响。

工具之后开始输出总结时，采用顺序切换：先停止刷新并淡出、收起原过程与中途播报，待旧区域完全清空后再淡入总结。切换期间收到的总结保留在原始状态中，暂不绘制正文；过程退出约 360ms，总结采用 400ms 的正文展开入场，不能同时显示旧过程和新总结，也不能重复两层入场动画。正文一旦显示，后续追加和完成保持同一节点、不重播。若后续又有工具调用，取消待显示的总结并恢复真实过程，不提前伪装成结束；失败、停止及历史恢复保持直接可读。减少动态效果或后台页面跳过等待和入场动画。原过程、命令及文字记录仅从当前视图收起，仍能通过“查看执行过程”回看。

正在执行时状态文案统一为“Lake 正在操作”；当前 Mini Box 使用 2px 短蓝色光带沿真实圆角周长匀速绕行，每圈 5.2 秒；亮头约占周长 4%，连同两段渐弱尾迹总长约 18%。整圈底边及框内 12px 柔光只用 6% 强度，让移动位置清晰可见；无亮白尖峰、呼吸或闪烁。使用归一化 SVG 路径与固定 2px 圆角遮罩，三段光带保持相同周期和固定相位差；输出刷新保留动画对象与起始时间，尺寸只在真实 resize 时测量。受控状态跟随该资源真实操作生命周期，inspect_host 等多命令操作中的短命令间隔不退出蓝框。动效只覆盖当前 Mini Box，不遮盖正文或拦截点击；执行 240ms 淡入，等待确认、断线、终止、未知及操作结束暂停并在 600ms 淡出。减少动态效果下静止，后台暂停；检查明暗、窄窗口、圆角和终止按钮。

Mini Box 只读取本会话、本轮、本资源、准确终端 generation 的 AI 命令块；Pilot 同时按专员 attempt 的实际派发与准确句柄隔离并行命令，无句柄时仅接受唯一最近派发且在两秒窗口内的同命令记录，歧义不展示/操作；不混入手动终端屏幕。终止请求必须同时绑定 terminal ID、generation 和 entry ID，服务端再次验证当前命令及写权限；过期按钮不得影响替代命令或其他资源。用户终止后向 AI 返回明确通知并阻止同轮自动重试该命令，其他资源继续独立执行。会话结束后在正文保留资源级终止说明，未知结果须提示核查，不将停止请求解释为命令成功。

## 首次使用与空工作台

欢迎页由 WelcomePage 承载，使用已批准的 Lake 山水 Logo，高清母版来自 assets/branding/lake-app-icon.png，前端通过 LakeLogo 复用本地资源。侧栏主对话入口使用 Lake 字标。连接工作台入口复用同一 Logo，不以工具图标代替品牌。不使用英文标语、轨道装饰、步骤编号、模型厂商展示或宣传式文案。

首次进入显示“欢迎使用 Lake”和“连接模型 / 创建项目”两项操作，以共享圆角面板中的两行呈现；两个入口独立可用，不强制配置顺序。已有项目时显示项目名称和新建会话入口，模型状态只依据 bootstrap.modelConfigured 展示“已配置”，不编造连接状态。未创建项目时侧栏只显示“暂无项目”与新建入口，不使用伪加载占位。

欢迎页复用共享主题、窗口曲线及 Glyph，不加载远程字体或图片，不自动请求模型、创建项目或会话。检查明暗主题、键盘焦点、hover/禁用状态及窄、低高度窗口；内容正常纵向滚动，保留项目导航入口。

用户消息气泡悬停时在左侧显示复制按钮，指针移到按钮时保持显示；键盘聚焦同样可见，触摸设备直接显示并保留 44px 点击区。复制原始消息全文，保留资源引用标签、空白和换行，不将图标、附件地址或反馈文字混入剪贴板。成功显示勾选并自动复位，失败显示明确提示；纯图片消息不增加空文本复制入口。


桌面 Pilot 与其他会话共用右侧任务检查栏。面板从窗口右侧滑入，状态岛保持紧凑并与聊天输入框对齐。执行过程、最新任务、任务状态和关闭按钮固定在页头。Worker 详情和带派单说明的操作行可用鼠标或键盘展开，操作按宿主时间排列。记录区独立滚动，4px 滑块向内留 8px。展开和收起共用 180ms 缓动。macOS 支持扩窗时，WebKit 先绘制完整右栏，AppKit 再沿窗口边缘裁切，聊天保持已经量好的宽度和阅读位置。扩窗跨过宽窗口断点时，状态岛沿用同一尺寸和阴影。固定窗口在聊天旁逐步露出右栏。退出期间面板停止交互，减少动态效果时直接切换。

「完整执行记录」在标题右侧显示尚未恢复的失败数量。展开后按原顺序平铺工具调用，行内展示实际操作名、记录时间和状态，点击行查看参数及结果。原始思考和终端记录保留各自的展开入口，Pilot 说明沿用正文颜色。调用记录在首次展开时渲染，保留键盘焦点与主题样式。

右侧「任务检查」在 macOS 桌面通过受主 frame 和同源检查保护的原生桥接扩展整个窗口，按首选右栏宽度扩展，默认 382px。开合前锁住原会话画布，保留正文宽度和当前位置。先利用右侧空间，不足时将窗口向左避让。屏幕容不下加宽后的窗口时，在原窗口内采用并排布局。关闭时仅收回本面板实际增加的宽度，保留用户期间的移窗与调整；刷新页面或退出时还原扩展宽度，避免下次启动重复加宽。减少动态效果时取消原生扩窗动画。浏览器、旧客户端及 Windows 不宣称支持原生扩窗；桌面视口采用并排布局，手机视口保留抽屉。


任务检查栏的概览卡将“步骤进度”和“任务结论”分开：真实成功步骤使用主题绿色，执行中蓝色，待选择/审批和结果待核实使用琥珀色，失败红色，待开始与暂停保持中性。全部步骤完成可以显示绿色勾与完成数量，但 `inconclusive` 仍独立显示“结论不充分”和琥珀色提示，不能因 3/3 已完成而宣称恢复。仅服务端 `recoveryStatus=verified` 才显示“恢复已验证”；修订计划不沿用旧运行的进度，暂停和结束不保留运行中的段状态。进度提供真实完成数和无障碍文字，不编造百分比；主题、节点和记录保持原有来源。

输入框底部工具栏使用 `lake-composer` 的实际容器宽度适配。会话、任务检查与终端并排时，620px 以下缩短间距、允许省略模型名称，保持工具栏单行。420px 以下用行内柱形图标表示思考强度，入口提示、无障碍名称和菜单均保留完整档位。300px 以下省略 Lake Pilot 标签，保留图标与 AUTO 标记。各宽度保留附件、权限、模式、模型和上下文入口的可访问名称与焦点反馈。

右侧检查栏的开合和页签切换不暂停主对话的滚动跟随：原本正在查看最新回复时，布局重排和新增正文后继续保持末行可见；主动上滚阅读历史时保留原阅读锚点，不强制拉到底部。正文内的执行过程入口始终使用朝右的导航箭头，点击打开或定位对应的检查卡，不再旋转为向下箭头；内嵌展开区仍按原来的上下展开语义。

桌面仅展示导航和会话时，两栏贴齐窗体。会话栏的左上和左下沿共享窗体曲线接入细分界线。顶部保留 46px 高的独立 Lake Island，目录按钮与岛居中对齐。会话顶部使用底色渐隐遮罩。状态岛外框与输入框外框共用左边缘，侧栏开合时同步移动。正文与输入框在会话区内居中，开合期间保留阅读宽度。调整窗口或拖动侧栏时，阅读宽度随布局更新。侧栏收起后图标栏融入会话底色。展开侧栏、后退、前进并入岛的左段，用短竖线隔开右段的会话身份、状态和详情入口。侧栏展开时，三枚按钮回到标题栏。侧栏的拖动分隔控件在悬停、键盘聚焦和拖动时亮起。

常规桌面对话和专员任务页的主栏贴齐窗体上下和右侧，左侧沿用同一条细分界线。专员页收起侧栏时为标题栏控件预留空间。带终端的桌面对话沿用内嵌背景与单层细边框，上、右、下各留 8px，四角沿用窗体曲线，macOS 26 的有效半径为 14px。缺少 `corner-shape` 的 macOS 26 WebKit 使用共享连续曲线遮罩绘制面板边缘。窄屏单栏保留导航抽屉，Windows 为原生窗口操作区预留空间。

桌面内嵌工作区的深色配色为左侧导航和窗体外沿 `#262626`、右侧主卡 `#181818`、主卡细边 `#3b3b3b`。输入框使用 `#2b2b2b` 底色和 `#3d3d3d` 空闲细边，聚焦与附件拖入时沿用对应的交互反馈。

工具执行后的结论从首个非空片段开始直接呈现。正文后使用同一个静态页脚，依次显示「执行过程」、朝右的详情箭头和真实用时。输出期间冻结截至正文开始时的处理用时，收到最终计时后原位更新总用时，保留正文、过程入口的焦点和阅读位置。失败计数放进执行详情，停止和待核查状态仍可在正文后看到。没有执行记录的纯 Pilot 对话省略页脚，缺少可信耗时的专员报告只显示过程入口。审批和原始记录持续可查。

完成时正文、身份和计时行保持原有顺序与宽度；仅原本跟随最新回复时在绘制前校准到底部，之后由布局触发的滚动继续跟随。主动阅读历史不被完成事件拉回。侧栏以Lake品牌左边缘统一会话图标、查看全部、资源标题与一级资源图标；资源子项按层级缩进，拖动入口位于右侧操作区，只有子目录保留前导展开箭头。

用户已发送消息按两张参考截图使用中性灰：浅色主题为浅灰底 `#ececec`、深字 `#262626`；深色主题为深灰底 `#282828`、浅灰字 `#d4d4d4`，深色桌面内嵌对话的气泡底色为 `#303030`。由 `--user-message-background` 和 `--user-message-foreground` 统一覆盖普通消息、Pilot、专员频道及图片消息的独立文字气泡。资源类型色与气泡前景色混合，本机引用使用气泡前景色；气泡外复制按钮、附件、图片和 Assistant 正文沿用所在表面的主题色与布局。WebKit 连续曲线回退只在原遮罩伪元素绘制气泡底色，文字层不使用 background-clip:text，避免原生明暗切换后文字漏绘；不重建历史消息或改变滚动位置。

Pilot 的活动与真实耗时沿用普通模式，固定在对应轮次正文之后，运行和完成状态原位更新，不插入正文前的用时行或分隔线。同一用户轮次、同一 Pilot 任务的每个角色只保留一个稳定区域，最新内容和状态原位更新，不能合并不同任务或用户轮次。计划入口、所有待审批/待选择控件及历史错误提醒仍保留；活动记录与持久化原文不合并或删除。

首段输出、断线重连、阶段更新和最终回执沿用已挂载的会话与输入框。连接短暂波动时用快照补齐进度，保留已显示的正文与状态，快照重试仍失败才显示重连提示。专员回执按原用户消息、Worker、角色与任务身份原位接替阶段内容，宿主发出的正式回执可跨 SDK 调用。阶段内容保留句内标点，句末省略句号，正式结论显示原文。头像在阶段内容显示期间及已知的报告交付阶段持续跃动，等待人工或重连时静止。

Pilot 对话和专员直聊的阶段正文使用 15px 的句尾光标，图形跟随当前回复的专员头像。兔耳轻抬，翠鸟飞羽倾斜并掠过微光，猫头鹰双眼眨动。其他形象使用自己图稿中的尾鳍、翅翼、蟹螯等特征，沿各部位的动作以约 1.32 秒循环。光标贴住末字，随本条回复的正式结论、等待、断线或排队收起。后台暂停循环，减少动态效果时保留静态形状。

Pilot 的综合结论留在正文。共同任务的正式报告全部交付后，Pilot 依据同一轮的报告综合实际结果、关键变化和未确认事项。汇总期间，该轮 Pilot 的头像、名称和正文尾部使用工作动效，句尾用小水滴标记。收到首个正文片段后在原派单确认的位置逐步显示结论，正式消息原位接替。文字全部呈现后收起水滴，断线和停止时暂停动效，页面隐藏和减少动态效果沿用既有规则。来自同一用户轮次的多份报告在实际执行结束、原文已呈现后合成一条多头像入口，展开可查看原文和各自的执行过程。读者正在选择报告文字或操作该区域时保持展开。原文缺失时继续显示系统合抄回执。不同任务的同一专员各有自己的记录，并显示实际任务名。

活动轮次完成多专员交稿时，报告列表向上收拢约 480ms，报告入口内的头像依次轻移 4px 并淡入一次。Pilot 与专员的头像列和正文左缘保持对齐。召集对话已收到全部实际回应并进入汇总时可开始收拢；同一轮的综合结论接替原位派单文字，若两者同批到达，先收拢报告，再在原正文内短暂退场并呈现结论。历史恢复、断线、页面隐藏和减少动态效果直接显示结果；展开状态、焦点和选区沿用读者的实际操作。

右侧检查栏不保留说明性底栏，“主对话保持在当前位置 / 返回对话”由顶部关闭入口替代。计划底部仅保留“详情”和实际可用操作；在途命令提示简写为“等待命令结束”，真实失败、审批及待核实提示仍完整呈现。

窄分栏下会话岛的标题与状态各自省略，展开箭头保留固定热区，完整文本提供悬停及无障碍名称。辅助岛只受本栏限制，不能占用会话岛宽度。终端分割线绘制在终端裁切容器内部，不能依赖负 left 的伪元素。

桌面窗口双击缩放、手动缩放和分栏重置时，导航、终端和任务检查共用同一宽度预算；会话列至少保留 416px，三联同时展开时辅助栏允许缩至 240px，导航允许缩至 200px。不可分别为两条辅助栏重复占用会话保留宽度；开合终端或检查栏后，React 提交阶段在首帧绘制前同步应用三栏宽度预算，不能先使用旧的检查栏/终端宽度挤窄正文，再在下一帧修正造成换行闪动。恢复大窗口后按保存偏好还原栏宽。

桌面导航开合使用 420ms 缓动。按钮和分栏位移沿用侧栏底色渐变的实际时长，开发预览与桌面安装包保持一致。折叠状态由导航管理，切换时保留已渲染的聊天记录。对话栏宽在一次开合的端点更新，分界面、导航列表、正文、状态岛及三枚导航按钮从同一渲染帧开始播放，动效中保留阅读宽度和滚动位置。首帧绘制前保留原位置，快速反向时取消上一段待播放的动画。侧栏收起时，展开侧栏、后退和前进随动画移入会话岛的左段。图标栏按钮原位保留，收起后使用右侧内容区底色，分隔线随导航内容淡出。收起即从键盘与辅助技术隐藏导航内容，保留滚动位置和首选栏宽。减少动态效果时直接切换，移动端沿用侧栏抽屉。

状态岛的独立页眉与分栏浮岛模式统一为 46px 高，纵向内边距统一为 5px；普通状态均使用相同短标签，完整状态保留提示和无障碍说明。切换单栏、二联、三联和窄窗口时不得因旧 Pilot 最小高度、双倍内边距或长状态回退让岛变高变宽；会话标题前保留与侧栏相同的共享 Glyph，会话未指定图标时统一使用对话气泡；窄窗口保留图标与展开入口，长标题省略，已展开的计划、执行和终端控件按布局增减。

Pilot 状态岛将协作头像放在「Lake」字标旁。单人显示一张真实头像，多人时依照栏宽预览两至四张头像，超出时用「+N」表示。栏宽有限时优先保留字标和专员头像，状态可用图标与完整的无障碍说明呈现。点击头像组查看所有参与者的名字及当前状态。新头像以短距离平移、缩放和淡入加入，真实执行或交付中的头像继续活动，减少动态效果时静止。Pilot 在等待已知报告落屏时显示「收尾中」，真实综合意见阶段显示「汇总中」。

项目 Pilot 的状态图标和短文案共用岛的玻璃底色，状态色柔和渗入现有圆角内。保留 46px 岛高、原有内边距和向右的任务检查入口。处理中的专员头像随岛宽向右展开，进入汇总时在 300ms 内收回，正文和输入框仍保持原来的位置。退场时关闭头像列表并取消其交互，减少动态效果时直接切换。

展开终端时，终端岛从会话岛的实际位置出发，以 380ms 平移到自身栏顶部并淡入；收起时以 280ms 回到会话岛并淡出。飞移只动画 transform 和 opacity，内容提前按目标栏宽排版，不逐帧改变 left、top、width，不缩放文字；移动中暂停背景模糊，结束后恢复玻璃材质。浮岛模式的正文网格一次完成重排，不逐帧动画列宽；落点取布局坐标，不跟随检查栏和终端的入场 transform 重建。移动中若原生扩窗或分栏尺寸改变，从当前位置接续到新目标，不重播动画、不放大文字。快速反向开合取消旧动画后连续接续，收起时立即 inert 和隐藏辅助技术入口，动效结束后再隐藏表面。快照、计数、终端切换和普通重排不重播分出动画。拖动分栏及减少动态效果时取消飞移动效，直接落位；卸载、切换窄窗和刷新清理动画、监听器与内联布局变量。

分栏浮岛沿用 Pilot 当前行动区，不能因启用独立浮岛而切回普通状态标签。普通状态与 Pilot 区互斥，普通区隐藏时必须 inert；收起、展开任务检查和终端不改变 Pilot 模式。岛宽不足380px时保留专员图标、当前动作、次行说明及末尾进度/结束图标与箭头，省去重复专员名称，文字单行省略；完整专员与状态保留在入口无障碍说明中。首选宽度独立于已压缩宽度，扩大窗口后恢复完整布局。

会话列表每行末尾使用 6px 状态亮点，与更多按钮保留独立空间。普通会话复用 Island 的短状态与主题色（处理中蓝、待确认/需关注琥珀、待命/暂停/停止中性），绿色已结束状态不显示亮点；可用的当前 Pilot 快照复用其行动区色调。悬停及无障碍名称说明状态，不只依赖颜色；亮点保持静止，明暗与窄侧栏均不遮挡标题或更多操作。后台目录更新优先于旧缓存，不能沿用过期任务状态。

发送消息后立即在发送按钮旁显示“正在发送”并使用共享 loader；请求确认后到会话刷新结束显示“已发送，正在更新”。反馈仅属于发起会话，发送期间阻止重复提交；接口失败保留原草稿和附件。已接受消息后的同步失败不恢复已提交草稿，不把发送反馈当作模型已经输出或工具开始执行。回执目标仍为当前会话时直接刷新消息。需要跳转的回执在发起会话仍处于前台时切换。减少动态效果时 loader 静止，按钮尺寸保持不变。

从 API 添加模型的搜索框下方，常显「全选当前结果」「全部取消」及已选数量，使用共享按钮、Glyph 和设置控制圆角。全选勾选当前筛选中尚未添加的模型，并保留其他筛选下的勾选。全部取消会清空所有待添加勾选，包括当前筛选隐藏的项目。已添加模型显示状态文字。有可选结果且未全部勾选时可全选，有待添加勾选时可全部取消。窄窗口允许按钮组和计数自然换行，不裁切控件。

Lake Pilot 开启后顶部始终保留角色 Logo、真实短状态和执行详情箭头。自动推进/手动选择模式只保留在底部入口及顶部悬停、无障碍提示中，顶部不重复显示 Lake Pilot 名称和两行模式说明。当前轮存在 Pilot 任务时显示既有专员行动区；后续普通对话或尚无本轮任务时显示紧凑的角色入口、真实会话短状态和执行详情箭头，不因任务筛选退回纯普通状态。入口不得复活历史任务的活动专员、进度或结论，历史计划仍由用户主动打开检查栏查看；关闭 Pilot 后恢复普通入口，单栏、多联与窄窗口一致。

Pilot 顶部统一复用 AgentIcon 的角色 Logo。有当前任务时显示真实优先专员；无本轮任务的 Pilot 模式入口使用协调者 Logo，并以“协调者入口”提示区分角色入口与执行状态。角色图标不加圆底或字母替代，普通页眉、独立浮岛和窄栏均保留，优先省略文字。

无本轮专员任务时，Pilot 入口使用单行“角色 Logo · 短状态 · 右箭头”，不再使用状态胶囊底色及重复状态图标；角色区首选宽度收为 100px，不保留原专员两行布局的 238px 空间。有当前任务时仍沿用真实专员行动区。

会话记录距离底部超过 64px 时，在输入区上方居中显示 36px 的玻璃圆形“回到最新消息”按钮，使用共享向下 Glyph。按钮锚定会话内容列，检查栏、终端多联展开时不跨栏；有待发送队列时避让其高度。点击滚到最新并恢复正文跟随，焦点回到会话记录；手动上翻仍保留阅读位置，回到底部后隐藏。没有溢出或切换到短会话时不显示；明暗主题、键盘焦点及减少动态效果保持可用。


普通 core 的长期任务跟踪是内置运行机制，执行详情不展示内部工作账本、工作项卡片、模型调用额度及暂停/继续/停止跟进控件。用户通过正常会话补充条件或停止当前轮次；审批与需要实际回答的问题保留原入口。顶部继续复用七类短状态：外部等待为“处理中”，等待用户为“待确认”，额度暂停为“已暂停”，无法核对为“需关注”；不新增顶部双行文字或影响 Pilot 角色 Logo。只关联当前 RootTurnID 的目标影响当前岛和侧栏亮点，历史后台结果带任务名汇报，不覆盖新话题。

跟踪器自行观察原句柄并在结果到达后接续，完成/失败/取消后释放等待检查点、租约及已结束的临时接续缓存；真实消息、原始操作与观察证据保留，不删除审计记录。等待用户不自动满足前置条件。后台等待释放输入区，实际模型接续仍遵守同会话单执行占用。MCP 服务编辑页使用共享 AppSelect 显式选择可信发布状态适配器，默认不自动观察。

待发送消息每行右侧常显共享向上箭头，与编辑、移除并列。运行中点击“推送到本轮”将选中消息补充给当前任务，若正在等待模型回复则取消仅该模型请求，通过官方 ADK 回调携带真实补充继续同一轮；若工具已启动则等工具返回再接入，不能取消或重复已启动操作。保持当前 RootTurnID、额度和执行记录；其他排队消息及输入框草稿不变。请求成功后恢复输入框焦点，选中消息立即以用户消息显示在当前对话末尾，使用静态“补充已发送 · 等待接入”区分主机收件和模型实际接入；不等模型回执才显示，不播放持续加载图标。该消息从待发送列表隐藏，不能重复推送、编辑和移除；模型回执以同一消息标识替换展示，避免重复。未接入就停止或失败时恢复为待发送消息，保留恢复提示；其他队列项排序仍须携带完整服务端队列标识。空闲或本轮正在结束时不伪造即时接入，消息保留供继续发送。

消息以真实人类输入持久化，SDK 投影提交后才从队列移入对话；重启对照原消息 ID 去重，未接入的补充保留并暂停队列。补充不代替审批/问题答案，不取消已经开始的命令；在新输入到达前生成而尚未派发的后续调用先返回未执行，再由同一官方循环结合新输入决定下一步。正在进行的审批/问题先沿用原确认流程。工作流仍使用原有消息准入规则。

候选后端尚未提供准确补充接入时，队列返回 `pushSupported=false`：保留箭头位置并禁用，提示本轮结束后继续发送。未提供此字段的现有后端沿用原流程；不得用可点击按钮或空成功响应冒充能力已接通。普通暂停、编辑、排序、移除和继续发送仍独立可用。

Pilot 中的活动专员以普通角色发言展示头像、名称、Agent Logo 和本次实际公开回复，不再在对话末尾另列灰色派单进度条。按准确人工来源定位到原轮次，按项目／角色／Worker／任务／SDK RootTurnID 读取和续接；只取当前执行的公开正文，不展示内部思考、工具原始输出或之前执行的回答。尚无正文时在角色发言内显示真实等待状态，正文到达后原位接替。已有正文时，新的确认、回答或外部等待在这条回复的「执行过程」旁以静态文字显示。完成后把宿主交付的正式报告接入准确执行的原发言位置，保留署名与正文容器，不先追加报告再删除实时行；原用户来源、Worker、角色、任务、会话及已观测 SDK root 必须匹配。报告仍保留附件、图片与计划引用。未观测的历史报告沿用原消息展示，其他专员独立继续。流式正文复用原 SSE 前缀更新及字素缓冲，不逐字拉取快照；断线保留已收到正文并提示重连。页面隐藏、等待和离线停止工作动效，不派发新任务或改变原执行与审批目标。

已出现的专员发言在同一准确绑定内保持身份与正文容器挂载。启动执行或报告交付期间，活动字段短暂缺失不清空整行；保留已收到的公开文字并显示静态更新提示，真实等待、错误和结束状态优先，不沿用旧工作动画。来源、角色、Worker、会话、任务或执行目标变化，以及明确删除、归档、切换项目时清除原绑定；只以实际观察到的 SDK root 和对应正式报告去重，不拿旧报告结束新轮次。收到真实首包后，正文直接接替思考状态，并按 400ms 入场节奏逐字呈现。进度换段和正式结论接替时，旧文在同一正文容器用 80ms 从右向左退去，随后展开新收到的正文。状态文案以 160ms 横向入场。退场期间保持旧高度，新文入场时局部平滑衔接高度，始终只挂载一份正文；同一条正文或状态的增补和修正原位显示。高度动画中出现新行或附件加载时释放旧高度限制，保留文字展开，避免裁切后跳高。退场期间的新更新合并为最新目标，不依次重放过时段落；入场被新段打断时从实际绘制边缘与高度接续。等待、错误、断线、页面隐藏、焦点进入正文和减少动态效果立即取消过渡并显示最新内容，不延迟真实状态。

Codex 根专员有公开工具记录时，主对话按原始消息和调用顺序穿插展示正文、文件、命令、任务更新与集成名称。相邻调用默认折叠为固定高度的单行表头。蓝色开口环按本组已成功调用数显示进度，全组成功后显示绿色满环。点击表头可查看逐条明细。流式输出保留手动收放状态，展开运行中的明细时，新增内容在表内滚动。正文和任务标签沿用对话原有样式。每条命令保留原始换行，按可用宽度最多预览三行，超过时在第三行末尾显示省略号。已保存的输出仍单独显示。只展示脱敏且有界的公开命令输出预览，以同一调用 ID 原位刷新；正文和输出均不能推断任务完成。执行期间，最新一段公开正文沿用专员的句尾动物光标，连续工具更新期间仍保留在该段末尾。报告送达后，由正式报告呈现结论；成功提交报告后另起的收尾正文保存在执行记录中。

Codex/ACP 公开正文按适配器提供的真实 messageId 分段，同段续写、换段原位替换，不按句子或工具调用猜测段落。完整累计文本仍保留在执行记录；无消息 ID 的旧适配器沿用累计兼容。按 2026-11-16 用户最新反馈，大段公开正文保持静态；持续跃动和扫光放在专员名称、思考状态及下方“执行过程”入口，共用 3.4 秒周期与从左往右的时钟。等待、断线、隐藏、结束与减少动态效果时停止。

任务执行成功结束与正式报告可能分开送达；这个交接空档保留同一准确任务和已观测 SDK root 的最后一段公开进度，不额外插入“执行结束”或接收结果提示，也不让晚到的收尾播报或空快照顶替正文。宿主正式报告到达后在原正文容器内直接过渡接替，保留过程入口、焦点与展开记录。 Pilot 状态岛在专员执行已收尾、对应正式回复已显示且正文接替过渡结束后才显示“已结束”；还有其他专员工作或等待时，继续显示他们的真实状态。真实失败、停止和等待仍如实展示，完整收尾内容保留在执行记录。

活动回复的运行状态与任务业务状态分开投影：任务受阻或待核实期间，若专员确实正在接收模型回复，仍显示回复状态或实际执行进度。不能因展示等待动画而恢复任务、扩大执行范围、变更审批或声称验收通过。

### 频道与历史执行合同

专员行右键及 Shift+F10 使用共享 NavigationMenu，提供带删除 Glyph 的“删除专员”。确认框明确命名目标、说明停止当前及待派发任务并保留历史，默认聚焦取消；Escape 取消并恢复原行焦点。提交期间禁用重复操作，失败原位显示并聚焦错误，成功立即移除准确角色及更新计数；当前频道被删时回到 Pilot 并聚焦入口。项目切换关闭旧菜单与确认框。沿用共享弹窗、控制圆角和明暗主题，窄窗口不得裁切按钮或错误文字。

不同任务的连续记录之间使用“任务标题 + 主题淡灰细线”标明边界，以准确 TaskID 判断，不按标题或正文猜测；同一任务的相邻过程与回复保持连续，不逐段加线。标题与正文阅读列对齐，长标题省略并保留完整提示，明暗主题和窄栏均可辨认；历史分页和流式更新保留原记录节点与滚动锚点。没有可信任务绑定的用户输入保持原气泡，不擅自归入邻近任务。分隔标题仅说明任务归属，不添加 Pilot 转述、重复专员署名或执行状态结论。

Pilot 与专员会话都不显示内部派单或补充转述气泡；专员直接呈现实际回复，不插入“Pilot”“补充要求”等内部协调标记。仅按宿主持久 dispatch 元数据隐藏派单及对应的重复转发消息，不依赖正文关键词，正常回复、用户直接发送的消息及其附件继续显示。任务分派、补充输入和准确来源保留在原任务/路由记录中，执行上下文、审批和验收不受显示过滤影响。

Agent SDK 专员按准确来源 Session 与 SDK RootTurnID 将一次执行的进展聚合在同一个位置，使用共享状态文字自动更新最新播报，不逐条追加过程正文。等待确认、离线和结束时停止工作动效；页面隐藏与减少动态效果沿用共享规则。结束后由宿主冻结的本次报告接替状态，保留实际结果、未完成部分和必要限制；不能把前一次回复或最后一条过程播报冒充失败接续的总结。分页、轮询及迟到的活动快照不能降级已结束报告。旧记录缺少可信执行绑定时保留原来源，不删除或改写消息、工具回执和验收；完整操作仍在原任务的右栏执行过程查看。

专员频道的任务记录和顶部任务清单都按准确的原任务进入主区域详情。详情使用真实的任务标题和记录，轮询保留当前页签和阅读位置。问题、审批、停止及附件使用真实来源 Session/task/root，多个任务不能共用“最近 Worker”的隐式目标；频道本身不显示可执行审批。历史分页保留滚动锚点，流式转持久消息按原源ID衔接，同正文的独立报告不得合并。


同一任务交给多位长期专员时，各参与频道使用相同的任务标题和公共任务 ID。任务详情显示每位参与者的执行状态、已提交人数和宿主的统一验收结果。「正在查看」标明当前执行所属专员；结果、业务回执、命令和停止按钮均绑定这位专员的原执行会话。某位专员提交后，其他人仍可继续执行；全员证据经宿主验收后，各频道与 Pilot 才显示统一通过。

频道窗口隐藏或短暂离线时保留已加载记录、分页游标和滚动锚点；只有切换准确频道ID才重置。状态岛按标题/状态文字固有宽度和固定控件预算计算首选宽度；头像、状态、详情箭头、任务清单及共享内边距/间距各计入一次，隐藏控件不保留空位。300px 以下仍按状态实际内容排版，不为状态预留固定列宽，不提前截断可完整容纳的短名称。紧凑模式的标题上限与徽标padding不能反馈进测量，避免300px阈值来回触发。浅/深色、普通/临界/长标题和窄轨连续采样验证见[频道验证记录](validation/lake-specialist-channels.md)。

切换聊天时先显示中性骨架与三点加载状态，首批记录在隐藏状态下定位，布局稳定后整体淡入；不播放从首条滚到末条的历史回放。在对话或展开的实时执行表末尾阅读时，新增行平滑跟随。同一行文字和状态原位更新。表内上翻只暂停表内跟随，对话上翻只暂停对话跟随。回到各自末尾后继续。开启减少动态效果时直接定位。

频道接单、路由、执行及等待用户期间，空草稿的输入框保留“停止该专员全部任务”。频道停止由宿主映射到本角色的待派发输入和原任务，不能把展示频道当作 Worker 身份，也不能停止其他角色或把远端未知结果记为完成。同一角色任一原任务有待回答问题、审批或主机信任确认时，侧栏显示蓝色“需确认”文字徽标；不能只依据最近任务或仅使用颜色表达。

同一专员并行处理多个任务时，侧栏副标题按真实活动 Worker 显示执行、待确认和排队数量；两个及以上实际执行任务另显示紧凑数量徽标。状态岛的完整提示与无障碍名称同步执行数量，可见徽标继续使用统一短状态。仅余一个活动任务时显示它的准确标题，不把已停止任务标题配上其他任务的转圈；空闲时优先展示最后更新时间最新的任务，旧端点无该字段时回退创建时间和既有顺序。角色身份、任务清单和详情选择保持独立。

用户停止任务后，宿主等待 SDK 与实际业务回执结算再提交最终停止报告。已核验的只读取消显示“已停止”，不以红色失败或“结果待核实”代替；真实 unknown 写入继续保留核实提示。旧宿主误提示只能在准确 outbox、任务身份和取消回执都匹配时通过只读投影修正，原消息、Operation、退出码和验收不改写。

Pilot 的湖心水滴使用稳定的饱满外轮廓与内部双层水面，在 14/20/22px 保持可辨；工作时内部水面以 2.6 秒周期明显起伏，闲时低幅呼吸，等待与失败静止，不再缩放整个头像或绘制同心圆；顶部原有扫光与头像共同跟随真实会话活动，不被旧任务的暂停/受阻状态压住。等待确认和结束后扫光淡出，页面隐藏暂停。Pilot 思考、整理上下文和专员接单共用状态文字扫光与相应文案；采用透明背景，与连续正文分开呈现。专员真实思考使用普通角色署名、共享动物头像及专属小字；工具进度、审批及完成保持真实状态，页面隐藏或减少动态效果时停止工作动画。

Pilot 的工具前播报和工具后的实际结果沿用上述过程 / 正文分层，创建专员、调整执行 Agent 和普通业务工具同样适用。内部派单转发仍仅按宿主持久 dispatch 元数据及准确交接回执识别，不根据自由文字猜测来源；独立任务与专员报告不合并。

正常的任务查阅、路由与步骤登记属于内部协调，日常会话继续显示“正在思考”，不生成“执行操作”回复气泡或自动展开内部步骤；首个非空正文片段到达后直接接替等待。仅按准确的已知协调工具身份与正常状态区分，不用工具名片段或模型正文猜测。原记录仍可手动展开查看；真实资源操作、未知工具、待确认、失败与结果不明仍显示其实际进度和提示。

按 2026-11-12 用户要求，聊天框底部移除独立 Plan 按钮及其专用样式，不留空白占位。Pilot 主会话（准确 workspaceRole=router）继续支持输入 /plan 切换模式；已有计划记录、计划操作和当前模式提示保留。专员仍如实展示继承的任务模式和已有计划，浏览不更改运行状态。


Pilot 和长期专员行末的绿色圆点表示“有新消息未读”，与任务验收独立。执行中或准备处理时优先显示旋转图标，结束后按已读位置显示绿点。“需确认”使用独立标签。宿主按消息版本保存已读位置。失败说明、回复和问题均可提示。Pilot 在最新消息进入前台视口时保存已读位置，专员也可通过点击侧栏入口确认已显示的通知。原生 macOS 的自动确认同时检查应用活跃、主窗口焦点与窗口可见性。迟到的回执只覆盖已确认的消息版本。

TypeScript 的 Mini Box 使用实际 commandExecutionId、Task、Operation、资源配置版本和 Worker generation，直接投影经脱敏的 SDK 命令输出；它不伪造 PTY 的 terminal ID。单命令终止由宿主再次验证完整归属及当前资格，只取消准确命令；同 Task/generation 的同资源命令不自动重试，其他资源继续。旧 PTY 保留原 terminal ID/generation/entry ID 验证。没有可验证的活动句柄时仍可查看原始输出，终止按钮禁用；中断或未知写入不显示成功。

Pilot 与专员、以及不同专员的相邻消息分组，使用 24px 角色切换间距（原 12px 分组间距上增加 12px）；同角色续写沿用原来的紧凑间距。按实际消息角色身份决定分组，跳过内部派发与隐藏过程记录，不改变消息正文、顺序或原始作者。

任务详情的结果页采用“任务概览 → 结果摘要 → 核验依据”的阅读顺序。概览只显示一次宿主的真实验收状态，专员来源和更新时间使用次要文字；多专员任务保留统一验收与各参与者的独立执行状态。结果复用共享 AssistantMarkdown，正确显示链接、列表、表格和代码，窄栏内长链接换行，宽表与代码仅在自身区域滚动，不执行原始 HTML 或自动加载报告中的图片。业务工具回执与执行步骤默认折叠，仍可展开原始失败、未知结果及历史执行；缺少回执时明确显示为空，不从报告正文推断通过或制造证据。切换准确任务时重置折叠状态，同一任务更新保留阅读位置与已有展开状态。

纯文本“再查一下”的派单只能通过准确 predecessor_task_id 取得原目标上下文；resource_ids 只代表本条人工输入实际选择的资源，不能复制上轮选择。若误传旧资源后被拒绝，只有宿主确认同一请求、专员、前驱、冻结资源和持久派单回执全部一致，且新的合法派单已记录，才在展示层标记“派单重试后已恢复”，不再计为未恢复失败。原始失败、参数与回执仍在执行详情；真实业务失败独立计数，未成功、换目标、跨轮、未知结果或无宿主证明不恢复。此标记不代表任务或业务操作成功，不改变资源权限与执行校验。
