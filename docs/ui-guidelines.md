# Lake 前端 UI 规范

适用范围：`web-agent/web/src` 的 React 工作台，包括 macOS、Windows 桌面内嵌页面和独立 Web。新功能与修改已有页面时均遵守本规范。

会话、任务检查与 SSH 终端的整栏底色统一沿用最左侧资源/会话栏的 `--sidebar`；浅色和深色的 `--background`、`--terminal-background` 均引用同一值。终端渲染器、输入框外侧及上下渐隐遮罩一起跟随，避免残留不同色块；卡片、输入气泡和 Lake Island 继续使用各自的表面材质，保留层次。

Lake Island 是 Lake 状态岛的正式名称，语义与象形为“湖中岛”。会话状态、任务进度与终端围绕同一岛关联，沿用 Lake 的轻盈材质、连续轮廓与统一交互；后续命名、设计和实现均保留这一语义。

## 设置界面的圆角比例

设置页统一使用窗口的连续曲线 `--corner-window`，按层级缩放圆角展开范围；不把所有控件都变成胶囊。共享值定义在 `theme.css`，由 `.model-settings-dialog` 映射到通用圆角变量，其他页面不被连带放大。

| 元素 | 共享 token | 圆角 |
| --- | --- | --- |
| 设置弹窗外框 | `--radius-settings-dialog` | 22px |
| 供应商选中卡片、模型列表外框、编辑/发现面板 | `--radius-settings-panel` | 14px |
| 输入框、API Key、AppSelect、添加/保存/测试按钮、普通菜单行 | `--radius-settings-control` | 10px |
| 小尺寸供应商图标底板 | `--radius-settings-icon` | 8px |
| 上下文容量等紧凑标签 | `--radius-settings-badge` | 5px |

开关保留胶囊、状态点保留圆形；半径不能超过元素短边的一半，不为容纳圆角随意放大控件。模型列表仅外框拥有圆角并裁切首尾行，内部横线保持直线，不给每行重复画框。嵌套的模型菜单沿用外框 18px、内缩 5px、选中/悬停底 13px；供应商侧边菜单外框同为 18px，实色底且仅单层细边，原生滚动容器显式关闭 bezel 和 focus ring。输入聚焦用细描边与轻量焦点反馈，不使用弹窗大阴影。

问答框、通用弹窗、操作审批和资源管理浮层复用这套层级，由 `surfaceGeometry.css` 在对应容器内映射通用圆角变量；不改全局紧凑对话的比例。问答框及独立弹窗外框为 22px，内层卡片和普通菜单外框为 14px，输入、按钮和菜单选中底为 10px；模型菜单继续使用其 18px/13px 的内缩比例。圆角和 `corner-shape` 必须同时覆盖选中、悬停底色，避免只有外框变圆、内部控件仍使用旧的小圆角。

支持 `corner-shape` 时使用 `superellipse(1.5)`；不支持时保留同一比例的标准圆角，不假称其为原生液态玻璃。弹窗背景、底部操作区和列表首尾必须跟随外轮廓裁切，禁止圆角外漏出方形背景。明暗主题、桌面/窄窗口、选中/悬停/键盘焦点均需检查实际显示；不能只比较 computed radius。AI 修改此类界面时同时遵守根目录 AGENTS.md 的圆角约束。

## SSH 主机信任

SSH 结构化文件工具与手动终端共用 Lake 的主机指纹确认流程；未确认指纹前不认证、不读写远端文件，也不为文件工具额外打开终端。连接错误区分端口不可达、主机信任、身份认证及未知原因，不能将 SSH 255 退出码统一解释为密码错误。Dev 与正式版信任记录继续隔离，不自动复制或信任。

## 焦点反馈

焦点描边共用 `--focus-outline`，由 `focusModality.ts` 在应用启动时统一跟踪鼠标/触摸与键盘导航。鼠标或触摸打开弹窗、菜单、点击按钮以及恢复焦点时，不绘制键盘蓝框；Tab、方向键、Enter/Space 等键盘操作恢复可见描边。保留真实 DOM 焦点、弹窗焦点限制、Escape 关闭和返回入口，不用 blur() 或全局 outline:none 取消键盘可达性。输入框自己的聚焦边框使用 `--focus`，与按钮的键盘描边分开。

## 下拉选择框

所有表单单选字段统一使用 `AppSelect`（`web-agent/web/src/AppSelect.tsx`），不得在业务组件中直接添加可见的原生 `<select>`，也不得另写一套下拉弹层。模型设置、会话配置、资源类型、SSH 登录方式与 Shell、工作流角色、目录和记忆类型已统一接入。聊天输入框的模型选择器也使用 `AppSelect`，通过选项渲染、分组及头尾插槽保留搜索和设置入口；不得另写模型下拉弹层。项目切换等专用菜单视觉上复用相同主题变量。

“新建资源”弹窗仅允许选择 SSH 主机和 Kubernetes；MySQL、PostgreSQL、Redis、APISIX、Prometheus 和 VictoriaMetrics 保留展示，使用 AppSelect 的禁用选项样式置灰，鼠标与键盘均不可选择。Kubernetes 默认使用 Kubeconfig，支持文件选择或粘贴 YAML/JSON，内容默认遮蔽并可显式显示；选择新文件、切换认证方式和关闭弹窗清除对应凭据草稿。高级选项包含 Context、命名空间、1～60 秒超时和 TLS 验证方式；点击“测试连接”才读取版本信息，取消或改动配置后忽略旧测试响应。按类型展示连接字段，切换类型和关闭弹窗清除凭据草稿；保存只添加配置，不隐式测试连接。Docker / SQLite 保留已有资源及服务能力。

聊天输入框将模型与思考强度合并到同一个 `AppSelect` 弹层，工具栏仅保留带 `ProviderIcon` 的 28px 模型入口；模型名后用次要文字展示当前模型实际生效的中文思考级别。按会话、模型和供应商识别读取结果，切换后不沿用上一模型档位；调整保存完成后同步更新。默认项显示服务端返回的实际默认级别，未知、读取失败或无思考能力时不编造级别。弹层顶部单行显示当前供应商的本地品牌图标与名称，点击右侧箭头展开供应商侧边菜单，列出供应商、当前勾选与“管理模型”；再次点击入口可收起。菜单支持上下键、首尾键、Enter 与 Escape，只显示所选供应商下的真实可用模型与视觉能力；打开时回到当前模型所属分类，切换供应商不改变实际模型，长列表搜索仅作用于当前分类，不再增加 API 徽标，下部通过 footer 插槽展示会话的思考强度。Web 供应商子菜单仍使用公共 AppSelect，父菜单保留对子菜单的点击归属，选择分类不关闭模型卡片。思考强度使用离散滑杆，仅使用服务端返回的支持档位，采用 28px 胶囊，已选部分为系统蓝色、未选部分为中性灰色；按实际支持级别等距显示固定小圆点，不再使用紫色渐变和漂浮光点。中性玻璃滑钮在点击/键盘选档时以 240ms 轻缓过渡、拖动时直接跟手，松开后自然吸附；减少动态效果时取消过渡；默认是滑杆首档，不再显示刷新/重置图标，后续仅列出当前模型实际支持的级别。使用默认时显示“默认 · 模型实际默认档位”，拖回首档仍保存空 effort。弹层右边缘与下方模型入口对齐，最小宽度 240px，入口更宽时随入口加宽，受屏幕安全边界约束；供应商行与模型列表用细分隔线区分，固定图标与勾选位置。模型名去掉重复的供应商路径前缀，保留自定义别名；原始全名保留在提示及搜索中，超长名称单行省略，思考强度标题必要时换行；模型行高 32px；触摸设备保留至少 44px 点击区。轨道与滑钮共用窗口的连续圆角曲线；填充和档位点在同一轨道内裁切，滑钮独立绘制并使用轻阴影，避免左端出现双重圆角的彩色缺口。macOS 26 及以上的桌面客户端使用系统 `NSGlassEffectView`（clear）承载模型卡片，以通透的液体玻璃显示正文后的材质，原生 18px 圆角、边缘反光和透光由系统合成；透明 WKWebView 只复用公共 AppSelect 分类、模型和强度内容，不再叠加 CSS 底色、边框、阴影或背景模糊。供应商子菜单使用实色原生面板，不使用液态玻璃；与主卡片统一 18px 连续外圆角，使用单层单物理像素描边，明确关闭 NSScrollView 的凹槽边框与焦点环，避免双层框。模型行与供应商入口的灰色底使用向内缩进后的 13px 连续圆角。原生弹层共享同一认证 origin 与 cookie store，不传递密钥；验证主 frame 和消息 origin，点击外部、Escape、移窗、最小化和失活关闭，保存请求在关闭后仍能完成。Web、Windows、旧 macOS 或旧 SDK 构建继续复用顶部会话标题的 `--title-glass-*` CSS 材质，并保留减少透明度和背景模糊不支持时的主题实色回退。拖动时仅预览，松开或键盘调整结束后保存；方向键、Home/End 不触发模型列表选择，Escape 关闭整个弹层。切换模型后重新读取能力，未知、加载失败及运行期间不可调整；保存期间滑杆保持可用和焦点，采用串行后台保存并合并未派发的中间选择，始终显示最新选择，较早响应不能把滑钮拉回旧值；错误在弹层内展示并支持重试。无思考能力的模型不显示该分区。默认项保留模型默认语义，不能将默认偷偷保存为显式档位。模型列表继续使用公共定位、勾选、搜索及键盘行为，适配窄窗口、深色主题和长列表滚动。

输入框默认提示使用“想让 Lake 帮你做什么？”，引用类型在 `@` 菜单展示；排队、待确认时继续显示对应状态提示。思考强度在运行期间保留级别和完整不透明度并说明不可调整；保存状态仅用不占布局的无障碍播报表达，不临时禁用滑杆或增减提示段落，卡片尺寸和输入焦点保持稳定。模型行在强度保存期间保留高亮与颜色，不切换禁用外观或重新加载列表，但锁定模型提交，避免模型与强度的保存相互覆盖。强度保存按会话单独记录忙碌状态，不占用全局 pendingOperation，资源侧栏、附件和工作区入口不因此刷新禁用外观；仅在当前会话强度保存期间锁定发送。

首次使用尚未配置模型时，保留正常的会话布局、输入框和占位提示，不增加横贯工作区的警告条，也不禁用草稿编辑。模型位置显示透明的“连接模型”入口，直接打开模型设置；发送位置使用插头图标，同样打开设置并保留草稿与附件，配置完成后仍由用户发送，不自动提交。未配置模型期间不请求文字补齐。无项目的欢迎页也提供次要的“连接模型”入口，创建项目和浏览资源保持可用。

厂商的 API 格式与地址必须匹配。小米 MiMo 官方域名下切换 OpenAI / Anthropic 格式时，同步使用 `/v1` / `/anthropic/v1` 前缀；已有配置在服务端兼容解析。代理地址、自定义路径和未知域名保持用户输入，不按厂商名称猜测地址。上下文整理失败须区分本地预算、接口地址错误、鉴权、限流和上游渠道不可用，给出对应恢复办法并说明历史保留，不把 HTTP 404 / 503 显示为上下文超限。

- 默认高度 36px；紧凑场景使用 28px，低高度桌面模型设置使用 34px。字段宽度随容器变化，标签和字段上下间距为 7px。聊天输入框的模型触发器采用无边框、透明背景的紧凑样式，悬停或展开时使用主题悬停底色；保留键盘焦点指示，弹层继续沿用公共样式。
- 统一使用 `--surface`、`--foreground`、`--border`、`--border-strong`、`--text-muted`、`--focus`、`--radius-control`、`--radius-panel` 和 `--shadow-popover`，不得写死浅色背景或系统蓝色焦点边框。
- 触发器右侧使用 `Glyph` 的 `chevron`，展开时旋转；选项右侧使用 `check` 标记当前值，不使用字符箭头、emoji 或文本勾号代替图标。
- 弹层由组件挂载到所在对话框顶层；无对话框时挂载到页面顶层，层级 120。使用视口固定定位，避免滚动面板裁切，同时保留在对话框的无障碍区域内。宽度至少覆盖触发器，保留视口四周 8px；下方空间不足时向上展开；长列表内部滚动。多行选项允许换行，触发器中的长文字可省略。
- 禁用项不可选；父级禁用的 `fieldset` 同样有效。点击外部关闭。方向键移动，Home/End 跳到首尾，Enter/Space 确认，输入字符可定位选项；Escape 仅关闭当前选择框并保留外层弹窗，Tab 关闭后正常移动焦点。
- 触发器必须具有可访问名称，采用 `combobox`、`listbox`、`option` 语义，报告展开、选中、禁用和活动项状态。优先显式提供 `label` 或 `aria-label`；已有包裹式 `<label>` 也受支持。
- `AppSelect` 内部保留不可见的原生控件，以兼容真实 change 事件、原有表单取值及受控状态；业务层不得操作或显示该控件。组件支持单选，不应将多选列表强行塞进下拉框。

```tsx
<label className="field-label">API 格式
  <AppSelect
    label="API 格式"
    value={protocol}
    icon={<Glyph name="code" size={15}/>}
    onChange={event => setProtocol(event.target.value)}
  >
    <option value="openai">OpenAI · Chat Completions</option>
    <option value="claude">Anthropic · Messages</option>
  </AppSelect>
</label>
```

## 轻量工作区侧栏

- 浅色主题正文、标题与主要名称采用桌面参考色 `--foreground: #1a1c1f`，次要文字采用同色的 70% 透明度，muted 文字采用 50% 透明度。侧栏会话、资源与目录名称使用正文色；时间、数量与提示继续使用次要色或 muted 色。深色主题沿用独立的浅色文字，不将黑色写死在组件内。

- 浅色工作区采用接近的近白色系：侧栏使用 `--sidebar: #fafaf9`，正文使用 `--background: #fcfcfc`，通过轻微明度差区分左右；输入框与浮层保留 `--surface`，选中、悬停和搜索继续使用主题淡灰层次。设置中的主题预览及原生窗口背景同步此配色，不在组件内各写一套底色。

- 顶部采用轻量纯文字品牌栏：Lake 使用 20px、600 字重、-0.9px 字距和主题正文色，不添加图标。品牌行高 36px，左右留白 12px，下方间距 10px；Dev 标记以 10px 次要文字置于高 18px 的无边框淡灰圆角底，沿用 5px 紧凑徽标圆角与窗口曲线。移动导航展开时为关闭按钮预留空间，Windows 保留 48px 原生标题栏高度。当前项目是 16px 的主要标题，保留文件夹图标，切换箭头紧随项目名称，更多操作独立靠右；长名称省略并始终为箭头和更多按钮留出空间。项目入口在默认、悬停和菜单展开时均保持透明背景，不铺整行灰底；键盘焦点保留轮廓，选中高亮仅在项目菜单内展示。常驻搜索在桌面为 36px 高的轻底色入口，左右保留 13px 留白，圆角沿用窗口曲线并缩放至 18px；触摸设备保留至少 44px 点击高度，支持原有快捷键与清空操作；通过下方细线和留白衔接最近会话。样式仅作用于工作区侧栏，不改变欢迎页品牌、项目切换逻辑或其他菜单。

- 桌面侧栏滚动滑块为 3px 宽的主题浅灰细条，高度按可见内容占总内容的真实比例计算，最短 28px，不再限制为 72px；滑块在底部工作区入口上方结束，不延伸到窗口底部。不溢出时不显示，不与原生滚动条叠加；滑块距左右分界线约 3px，点击区域保留 10px。滚动、进入侧栏及靠近右侧边缘时显示，闲置 1 秒后用 160ms 淡出，鼠标悬停滑块、拖动和键盘焦点期间保持可见；减少动态效果时取消渐变。滚轮、触控板和触摸滚动沿用系统实际速率与原生惯性，不拦截或缩放输入位移，不额外添加平滑动画；滑块位置直接由真实 scrollTop 与可滚动范围映射，同一滚动帧同步 transform，不再额外延后一帧。支持直接拖动、方向键、PageUp/PageDown、Home/End，并提供 scrollbar 无障碍语义。触摸设备使用原生细滚动条。
- 侧栏以Lake品牌左边缘12px为统一基准：会话图标、根资源/目录图标、查看全部入口及底部工作区图标对齐这一列。移除行前为隐藏拖动手柄保留的空轨道，手柄改在右侧动作区，和状态点、添加到对话、终端及更多按钮各自预留空间；悬停或聚焦不推移名称。顶级资源目录不显示展开箭头，整行按钮保留展开/收起及aria-expanded语义；子目录箭头位于图标左侧独立9px区，层级继续每级13px。列表右侧与底部工作区外框左右保留8px，品牌位置不移动。手柄焦点轮廓向内绘制，批量选择时列表左侧恢复8px以容纳勾选框焦点。保留行高、字号及共享圆角规则；底部入口采用下述轻量入口样式。
- 侧栏与正文之间常显 1px 主题细分隔线。边界保留 8px 拖动区域，悬停时使用稍深的中性细线，键盘聚焦保留清晰的主题焦点线；拖动、双击重置和方向键调整继续有效。

## 回复正文排版

界面与回复共用系统优先字体栈 `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`，普通文字采用系统字体与 500 字重，按用户当前并排截图校准为共享 14px（不再把 Codex 包的 13px 默认值当作用户当前显示值）。`--font-size-body` 引用 `--font-size-ui`，常规文字与选中名称共用字重，不能按侧栏、正文、状态或颜色另设大小。普通文字只使用黑色 `--foreground` 和灰色 `--text-muted` 两档（浅色界面按截图使用固定 `#8e8f90`，避免不同底色透出第三档灰度）；`--text-secondary` 为同一灰色的语义别名，不再建立第三档灰度。输入占位文字、计时、提示、计划入口、计划日期和错误说明沿用共享字号；输入工具栏采用 `--font-size-toolbar: 12px`，实验型徽标采用 `--font-size-badge: 10px`，保持紧凑但不缩小按钮点击区域。不同颜色不改变字重。代码采用 450，标题 650。

助手正文采用共享系统字体、14px、500；正文 strong/b 保留语义，不另加粗，避免局部文字再形成另一套外观。真正的页面标题和品牌标识可以保留标题尺寸与 650 字重；代码、终端保留等宽字体，错误、警告和状态色保留功能含义。不能把局部缩小或减字重当成灰色文字样式。

会话标题采用随项目名、会话名和真实状态收缩宽度的悬浮圆角气泡，圆角使用 `--radius-window`，不添加横贯正文的分隔线或背景条。顶部空白区域和标题气泡支持窗口拖动及双击缩放，交互控件、弹窗和菜单不触发拖动；Windows 在移动超过 4px 后才交给原生拖动，保留完整的双击事件。标题气泡外框、正文容器和输入框外框共用工作区宽度计算的左边界和内容宽度；滚动条位于右侧留白，不通过正文两侧额外占位导致错位。正文滚动区域延伸到气泡背后，首屏和跳转预留标题空间；长标题省略并提供完整悬浮提示，窄窗口保留导航入口。左侧底部只保留一个“工作区”轻量入口，常态透明、无可见边框或阴影；悬停和键盘焦点显示主题浅底，展开时使用选中底色。使用共享Glyph的16px四格工作区图标，菜单里的设置仍用齿轮。保留44px点击高度、共享窗口曲线、图标与Lake品牌12px左边缘对齐和右侧箭头；底部及两侧8px。入口在侧栏flex布局中独占底部区域，列表不滚到文字背后，列表底部仅保留16px呼吸空间；最后一项和“收起历史”能完整滚到入口上方。标签筛选、设置、检查更新和已删除统一收进向上展开的轻量弹层；当前标签在按钮中保留可见提示，发现未读新版本时，在“工作区”按钮右侧、展开箭头前显示 6px 红点，折叠和展开工作区都保留；仅查看更新窗口后标记为已读。无新版本不显示提示，按钮可访问名称同步说明有新版本。弹层支持方向键、Home/End、Escape、外部点击与焦点恢复，限制在视口内；更新弹窗继续挂载到页面顶层，避免侧栏变换或裁切影响。会话的视图切换、重命名、图标、标签和删除统一收在侧栏对应会话的三个点菜单，当前会话入口常显，右键复用同一菜单；保留禁用约束、键盘导航、Escape 和编辑弹窗的焦点恢复。

开启Lake Pilot时，顶部状态岛采用单行紧凑布局，保留原标题的玻璃表面、边线、窗口圆角和共享14px字体；专员使用原AgentIcon，不加头像圆底、字母占位或另一套品牌图标。采用 B「当前行动岛」：主行显示一个当前专员与实际活动，次行保留其他专员状态，右侧只保留状态色细环或结束图标及展开箭头，顶部不展示3/3等数字；真实已完成/总步骤数保留在入口无障碍说明和展开详情中；等待或未知结果优先显示需要介入的专员。关闭时信息 120ms 淡出、宽度 280ms 收回普通会话状态，标题锚点、正文和滚动位置不变，退场内容隐藏并禁止交互；减少动态效果时取消过渡。不按调用次数增加进度，Pilot 的实际运行状态沿用共享标题扫光，等待、暂停和结束时立即冻结当前相位并淡出；正在暂停但原命令仍在途时也停止运行扫光，保留真实在途说明和静态进度。等待选择/补充/审批、排队、实际执行、暂停和未完成必须区分，不能把等待中的专员计作并行执行；原操作尚在途和未知变更保留实际提示。暂停用中性灰，关注用现有警告色，实际失败保留错误色。会话状态岛在所有窗口宽度下均不渲染项目图标、项目名称及其斜杠分隔符，直接从会话标题开始；窄窗口优先省略长会话标题，保留状态图标和展开入口；Windows预留原窗口控制区。点击 Lake Island 的专员区打开会话右侧的固定“任务检查”栏，任务计划与执行详情共用同一栏；再次点击状态岛、关闭按钮或 Escape 收起。新 Pilot 任务首次进入运行或计划阶段时自动展开右栏且不抢输入焦点；同任务被用户收起后，计数和快照更新不再弹出。专员状态已展示时不再追加底部“几个子任务执行中”的重复运行行，结束后的真实耗时入口保留。右栏采用随内容增高的悬浮卡片，计划 / 执行页签与关闭入口置于卡片内部顶部；统一通过状态岛尾部箭头开合右栏，关闭后该箭头继续常驻，再次打开默认跟随当前会话最新一轮，仅保留页签偏好；最新一轮暂无执行记录时展示空状态，不回退到旧任务。默认跟随时新轮次自动更新右栏；仅在用户显式打开历史用时、历史任务或步骤时固定该历史目标，快照和新轮次不覆盖手动选择；不另外显示右上方“计划与执行”按钮。箭头固定向右，开合不旋转。普通模式在状态标签旁提供相同的箭头按钮与键盘操作，沿用右栏入场240ms、退场180ms动效。目标与范围默认折叠，避免摘要与原始长目标重复占位。桌面右栏宽 382px，与正文并排，窄窗口改为靠右覆盖并保留可关闭入口。沿用主题表面、单层细边、共享字体与图标；步骤、资源、Mini Box 和原始证据复用已有组件。右栏切换步骤只查看记录，不开始任务或派发命令。旧轮次显式打开的 attempt 必须使用原计划与原运行记录，不能借用新计划的同名步骤。当前快照优先于入口保留的历史任务，切换会话、资源详情或 Plan 页面立即清空选择。主对话保留交付正文、方向选择和审批，计划与原始执行内容收进右栏；点击证据引用直接定位右栏中的原始证据。普通会话的用时入口同样打开该轮执行详情。打开和关闭保留可见消息的位置，输入框随可用宽度布局；右栏独立滚动，不滚动主会话。入场 240ms、退场 180ms 淡入淡出和轻微横移，退场立即 inert，减少动态效果时直接切换。关闭恢复入口焦点，标签支持键盘切换，快照更新保留已展开资源、输出和输入状态。

方向选择区域仅在新的请求出现时，以280ms淡入、轻微上移及实际高度展开进入；同一请求的计数、快照、方向选择和命令展开不重播动画、不重建控件。结束后恢复自动高度与可见溢出，聚焦或窗口尺寸变化立即结束入场以免裁切操作；后台或减少动态效果直接展示。计划底部“修订与详情”与共享箭头保持单行，空间不足时整组操作换行。已结束/已取消的状态岛用静态勾号/关闭符号代替进度圆环，仍保留真实完成数与结论不足说明；进度图标、圆环直接共用下方上下文的当前会话状态与--session-state-color，运行蓝、待确认黄、完成绿、失败/需要关注红，结论不充分按原会话关注色显示。此颜色只表达会话状态，不改写恢复验收结果。

领航模式的防刷新约束与运行动画独立：正文、步骤导航及已展开记录保留节点，流式内部播报仍在运行详情中，计时按最近活动快照显示，不恢复每秒整行更新。实际执行的专员状态、当前运行步骤复用共享文字扫光，活动指示保持浏览器原生循环；工具计数、证据数或快照更新不重建节点、不重启动画或触发无增高滚动。等待选择/补充/审批、暂停、失败、未知变更、完成和历史记录不播放执行动画；减少动态效果时静态可读，顶部状态岛仅在实际执行时保留共享标题扫光，快照更新不重新挂载动效。

“权限”入口使用共享 Glyph 的 lakePermission 图标（细线盾牌＋湖面水纹），16px、1.4px 线宽，与文字间距6px。继承按钮的主题字色、悬停/展开颜色，保留28px按钮高度及原有焦点反馈，与相邻 Plan、Lake Pilot 入口对齐。

Lake Pilot 只保留一个罗盘文字按钮，不再显示滑动槽、浮层或设置箭头。单击按关闭→手动选择→自动推进→关闭循环；关闭为灰色，手动选择为主题前景色，自动推进仍为前景色并在文字右侧加AUTO小标签。标签使用主题信息浅蓝底/蓝字，深色主题对应深蓝灰底/浅蓝字，高16px、10px字号、5px圆角，无边框、不闪烁，距文字6px。悬停和可访问名称说明当前状态与下一次点击的作用，保留键盘Enter/Space。连续快速点击串行保存并按最终意图推进，不能因前次保存中而丢掉第二次点击；服务端确认后才更新状态，失败保留实际值并提示，未知结果不自动重试。运行中与断线禁用，关闭后下次开启固定从手动选择开始，不沿用旧autoAdvance隐藏值。只影响新任务，现有任务快照、角色职责与权限确认保持原样。

手动领航的方向选择使用原生语义单选框，显式提供可访问名称；选中行使用主题中性淡底和单层细边，说明自然换行。确认方向或固定命令的主按钮使用主题前景色实底、背景色文字，深色主题自动反转；整步委托为独立次要按钮，取消保持次要层级。普通控件采用共享10px曲线，保留键盘与焦点反馈；切换/展开不会提交，保存期间阻止重复提交，失败保留所选项。不要把确认操作与灰色说明混在一起。


会话工作区的纵向滚动只由 `.conversation` 承担，外层工作区和 `.session-view` 不再产生第二条滚动条。会话正文可缩至剩余高度，不能沿用 110px 最小高度把多行输入框挤出低高度窗口。多行草稿、代码与工具详情仍可在各自区域内滚动；资源详情和欢迎页保留原工作区滚动行为。

默认回复采用简洁对话：直接说明结果，接一小段关键依据、验证或必要限制；不强制“结论先行”、编号分节、大表格和整段加粗。用户明确要求报告、审计、完整表格、步骤或代码时保留必要细节；简洁不能省略失败、未知或待确认事项。SRE 最终汇总也不强制列出 3～5 点，结构化事实和证据字段继续保留。

包含多项具体标识或验证结果的完成回复使用轻量“信息摘要”排版：简短结果说明后，用已有的“提交：/ 分支：/ 检查：/ 耗时：”等明确字段排成两列；标题和摘要直接融入正文，不增加面板外框。提交号可通过旁边的共享复制图标复制，普通标识保持中性等宽轻底色；数值使用常规字重、单位用次要文字，IP、版本与代码不拆开着色。独立文件链接显示文件图标、原名称和真实域名来源，下方来源不包含查询参数；正文内链接仍保持行内。仅在展示层整理明确字段，不从自由描述推断状态、不补造提交、检查或耗时，不修改消息和证据；普通说明、混合列表、嵌套列表和完整代码保留原结构。普通回复与 SRE 正文共用渲染器，浅色、深色、窄窗口与键盘复制均需验证。

普通回复和 SRE 正文完整展示，不按字数或章节自动折叠；观察事实、假设、未知项和后续检查同样直接展示。操作记录、思考过程、证据原始输出和审批保留各自的交互。完整历史和用户原文不修改。

“查看详细结果”采用与正文同字号的次要文字与右侧共享细线箭头，隐藏原生实心三角；保持透明背景，悬停才显示主题淡底色。展开时箭头转向下方，保留原生 details/summary 的键盘开合和可见焦点，减少动态效果时关闭过渡；普通回复与 SRE 正文使用同一入口组件。

Agent 正文使用 `assistant-prose`，在现有对话布局内限制最长行宽为 860px，字号使用共享 14px、行高 1.85；正文、strong 和列表内容采用共享 UI 500 字重，章节标题采用 650 字重，用间距与字色建立层次。保留 Markdown 的语义标记。表格恢复 Lake 原有的中性细框线、单元格分隔线与主题淡底表头，单元格使用 6px × 10px 留白；使用内容所需列宽，短服务名与比较数值不强行挤断，长说明正常换行，宽表只在自身区域横向滚动。横向滚动由外层表格容器统一承担，表格本身不再声明滚动或自带段间距；容器底部为滚动条预留8px、与后续正文间隔16px。滚动条使用主题中性细条，WebKit高度6px，不能浮到表格外遮住下一段文字。表头保持字段文字，不自动装饰为文件或资源引用；数据单元格保留原引用和代码样式。长代码与表格在各自区域内滚动，不撑宽会话。正文容器和输入框共用对称的左右留白：桌面最少 48px，700px 以下窗口保留 32px；较宽窗口按各自内容上限居中，左侧会话刻度位于留白内，不挤占正文。

- 正文提到的明确对象在原句位置显示为行内引用，不另设资源标签栏。资源按当前项目唯一名称、完整地址或 ID 关联；同名或共用地址不猜测。软件组件使用有限名称目录，版本与名称在同一标签内，不表示部署或健康状态已经验证。明确文件路径与本轮已记录文件、命名任务也可引用；没有可靠身份的数据库表、服务实例保持原文。
- 行内引用使用共享 `AssistantMarkdown`、`ObjectReferencesProvider` 和 `Glyph`，约 22px 行内高度、常规字重，不展示推断的状态色。已关联资源复用 `ResourceIcon`、`message-reference-token` 的无边框类型配色和 `--radius-message-reference` / `--corner-window`；软件与未关联文件使用中性淡底色、5px 小圆角与细边框。长名称省略时保留完整提示，窄窗口不得撑宽正文。普通回复、终端会话与 SRE 使用同一渲染路径；代码块、命令、已有链接、URL 和参数名不进行名称替换。
- 资源标签点击只展示只读详情，已记录文件可查看会话中保存的内容；软件标签只说明软件类型，不伪装成已关联资源的按钮。标签不直接执行命令。详情仅展示白名单字段，不序列化连接设置或凭据。

- Markdown 解析后的展示层可兼容 `**磁盘： **` 这类带多余空格的短标签，以及中文整句加粗、中文引号或括号旁未解析的成对双星号；不限定为短冒号标签。只处理与原始文本完全一致的普通正文节点，不改代码、链接、显式转义、三重星号或 HTML，不补齐未闭合标记，不改写存储的消息、命令与证据。普通回复、SRE 正文和精简进展预览共用此兼容逻辑。
- 以“结论 / 综合结论 / 小结”开头的段落继续普通正文排版，不增加外框、色条、底色或状态卡片；不根据自由文本推断成功、异常或告警颜色。
- 正文与结论样式使用主题变量，验证浅色、深色、窄窗口及代码、表格和嵌套列表。用户要求暂不更新时，仅验证源码与隔离预览，不安装客户端、不调整版本或发布。

## 旧会话恢复与上下文压缩

- 默认上下文预算跟随当前模型的已知容量，取其 90%，并另外预留单次输出；容量未知时使用 64K，不把默认预算当作模型容量。旧版保存的 64K 默认值升级为自动模式，其他自定义预算保留为手动模式；显式手动设置可以保留较低预算，但不能突破已知模型容量。切换模型后自动重新计算。
- Lake 与 ADK 的自动压缩共用实测占用判断，SDK 回调不能绕过预算强制重复摘要。摘要完成后尽量降到输入预算的 75%，给后续对话和工具结果留出余量。压缩仅改变模型上下文投影，历史消息、原始操作记录和持久证据保留。
- 聊天输入框和用户消息气泡的圆角统一使用 `--radius-window`，桌面宿主按系统窗口外角提供尺寸与曲线（macOS 26 为 22px 展开范围、`superellipse(1.5)`，旧版回退为 10px / round），浅色、深色及窄窗口保持一致。输入框单行外框高 48px，上下内边距为 8px，保留现有横向长度与文字字号；多行按内容展开。聊天输入框明确使用文本鼠标指针和主题前景色光标。自适应高度使用独立测量层，不得在输入期间将聚焦的 textarea 高度先设为 0；多行展开、缩回单行及补齐建议变化应保留焦点和选区。

- 会话不会因闲置而过期。闲置至少 30 分钟且模型历史达到 8192 个估算字符时，下一轮先整理历史；较短会话直接续聊。日常对话达到上下文预算时仍按预算触发压缩，不依赖闲置时间。
- 自动压缩进行中，在当前轮唯一的底部状态行显示“正在压缩上下文…”，沿用计时和停止操作；不增加第二条进度、不展示内部摘要。已完成或旧轮的压缩卡片不得让当前轮显示忙碌。
- 压缩请求共享 45 秒上限（包含排队及摘要输出超限的一次重试）。失败或停止保留原消息、操作证据和回退点，解除忙碌状态；服务重启后遗留的整理状态标为中断，可以继续。
- 闲置恢复的可选整理失败，仅在原历史仍符合当前模型预算时继续，并显示保留原上下文的说明。超预算时必须先成功压缩，明确提示原会话重试或切换可用模型；不得靠删除用户约束或重放命令恢复。摘要仅供上下文参考，不构成操作授权。

## 流式文字呈现

- 左侧会话刻度统一为 8px 长、2px 粗，当前轮次及悬停仅改变颜色，不再伸长。刻度按轮次分别悬停预览：仅显示当前刻度对应的真实提问和已保存回复摘录，不展开整份目录、不额外调用模型生成摘要、不把工具原始输出当回复。卡片短标题最多两行、正文最多四行，跟随对应刻度定位并限制视口边界；移出收起，进入卡片时保持稳定。点击刻度或标题跳转，键盘方向键切换、Enter 跳转、Escape 关闭并恢复焦点。悬停不暂停正文跟随，完整历史仍保留。

- 普通工具会话运行时，在本轮耗时/状态行上方常显一行最新进度，不要求展开执行详情或三联。使用本轮已被后续真实工具调用证实为过程的最新助手说明，尚无说明时使用最近真实工具的既有动作描述；不额外生成总结、不推断百分比、不读取内部思考或工具原始输出。该进度文字始终使用正文前景色，深色模式保持白色、不因执行阶段变灰；从出现到更新均保持静态，不使用文字跃动或扫光；计时等其他状态动效保持各自规则。长文单行省略并提供完整提示，后续进展原位替换，不累积段落或重建该节点；打开详情时该行仍保留。原过程段落转成进度行时在同一帧替换，不让旧段落淡出与新行同时绘制。工具后正文首个非空文字分块到达即隐藏进度行，不等整轮结束；空包/纯空白不触发切换，后续真实工具再次出现时可恢复进度阶段。已证实的前置过程正文保留在执行详情；最后一次真实工具之后的潜在最终/部分回复从首包完整保留在正文，不凭措辞归类或按相似语义去重；普通纯文字回答、Plan 和 Pilot/子任务各自呈现不变。展开保留原文、工具参数、输出和时间顺序，执行记录视图继续保留完整记录；不修改持久历史。审批、失败、结果不明、停止、系统通知及子任务控制不并入正常进度。减少动态效果时取消切换动效，底部仍只有一条真实计时状态。

- 对当前页面中新出现的生成中回复，从首个分块开始使用短缓冲，跟随浏览器显示帧率平滑呈现，不设置固定 30fps 上限；显示缓冲最多保留 80ms，连续分块不延后已有追赶截止；有待显示内容的每个刷新帧都推进字素，短分块的基础速度为每秒 320 字素。恢复会话时已有正文与历史消息直接显示，不补造文本或改变保存内容。
- 正常连接时通过 SSE 直接更新指定消息或专员正文，同一显示帧合并处理事件；不为每次文字更新重新拉取全量会话。实时文字事件携带目标正文的已接收前缀，重复或漏帧不会造成文字重复；完成、审批和结构变化仍以权威快照为准。断线重连或目标尚未加载时恢复快照，不通过动画推断成功。
- SRE 专员必须透传实际文本增量；结构化调查报告仅呈现已收到的 summary 正文，不暴露未完成 JSON。流式展示不按分块重写任务审计记录；专员结束到最终报告保存之间保留已收到的正文，不退回原步骤描述。
- 定时目录同步复用未变化的数据，模型信息更新不得重建会话订阅。并发快照按事件游标拒绝旧响应，避免正文、确认状态或任务状态回退。
- 按 Unicode 字素边界呈现中文、组合字符和表情。完成、停止、错误或正文替换立即显示实际完整内容，不让视觉缓冲延长任务状态或等待确认。普通回复的完成标记以本轮已证实的模型结果和错误记录为准，旧暂停任务的遗留操作保留原会话警示，但不能把后来独立完成的回复标为未完成。只自动校正最近一轮有完整结束记录、无本轮错误/待核实操作的计时，不推断早期历史或改写操作账本。
- 页面进入后台、或系统开启“减少动态效果”时直接补齐，取消未完成动画。Markdown 使用稳定组件引用，追加正文不得重建已有表格和链接；沿用现有滚动跟随，用户阅读历史时不强制拉到底部。

## 流式回复结束

- 回复是否结束以当前模型协议的完成标记为准，不等待供应商或代理关闭 HTTP 连接。完成后同步结束正文状态、会话调查状态和本轮计时，允许继续发送下一条消息。
- OpenAI 兼容接口的 `finish_reason` 后最多等待 1 秒收取用量尾帧；收到用量或 `[DONE]` 即完成。未收到用量时保持未知，不能当作零消耗。空的完成原因、正文中提到 `[DONE]`、心跳均不代表完成，工具调用仍须完整校验。
- 已有回复开始输出后连续 60 秒没有新的有效流事件，停止等待并以“未完成”结束本轮，保留已收到内容、操作记录和继续发送入口；不能把缺少完成标记的半条回复标为成功。用户停止始终优先，不被正常收尾覆盖。

## 图标

聊天输入框的停止按钮使用圆形中性背景，中央保留方形停止图标；圆形外观在悬停、聚焦和深色主题下保持一致，排队输入时的次级停止按钮也保持圆形，沿用原有尺寸、停止操作与无障碍名称。

通用操作图标统一通过 `Glyph`（`Icons.tsx`）使用 Lucide，常用尺寸为 14/16/18px，线宽沿用组件默认值。图标与文字间隔 8～10px。仅图标按钮必须提供 `aria-label`；装饰图标设为 `aria-hidden`，不重复朗读相邻文字。

资源侧栏保留实际已连接终端的绿色状态点，悬停和键盘聚焦时同样可见，不显示终端数量。连接状态未知或已断开不能显示绿点。“管理终端”使用 `Glyph` 的 `more` 图标、零内边距的固定尺寸按钮，与打开终端按钮留出间隔，避免图标裁切或覆盖名称。

厂商品牌图标统一通过 `ProviderIcon` 使用。快速接入卡片、供应商侧栏和详情标题必须保持同一品牌图形，不得以首字母、随意几何字符或自制近似标志替代。自定义 API 使用通用插头图标；不识别的代理地址不伪装成某个厂商。侧栏可按准确厂商名或受信任的预设端点匹配图标，域名必须完整匹配，本机服务还必须匹配端口。

聊天模型列表和当前模型触发器同样显示 `ProviderIcon`。由 `modelBrand` 优先按模型 ID / 系列识别实际厂商（含 Magpie 和聚合接口的路由前缀），其次按显示名、已知厂商来源识别；无法识别时使用通用插头。聚合平台和本地运行器的图标不得用作未知模型的厂商图标。来源分组保持独立，同名模型通过供应商 ID 和模型 ID 区分。当前模型的显示名称、来源和图标必须使用启动响应里的 `modelSelection`，刷新页面后即可显示；不得依赖先打开菜单加载目录，也不得从同名模型的第一行猜测来源。页面可见时每 2 秒读取本地模型状态，窗口重新聚焦或页面恢复可见时立即同步 Magpie 的目录、显示信息和默认模型；设置页打开期间也自动同步，保留未保存的供应商编辑。同步不得触发上游模型发现请求或覆盖手动供应商选择，暂停期间及旧请求返回不得回滚本地保存结果。每次展开模型菜单时仍同步刷新当前选择。菜单刷新期间保留当前模型的展示信息，长名称在触发器省略并通过提示显示完整名称和模型 ID。

厂商 SVG 位于 `web-agent/web/public/providers/`，当前来源为 MIT 授权的 Lobe Icons 静态 SVG 包。新增或更新时同时维护 `provenance.json`、原始许可文件和第三方声明。不得运行时请求远程图标；保留 SVG 原始比例和彩色品牌色。单色图标在深色主题下统一反色，彩色图标不反色；不拉伸、不加文字水印。

待发送消息采用输入框上方的轻量气泡队列，移除整块外框和横线；所有待发送消息直接列出，不提供收起或展开入口；长队列内部滚动。不显示“接下来”标题或常驻暂停按钮，数量和发送状态仅用于无障碍播报。编辑或异常使队列暂停后，在消息下方按需显示无底色的“继续发送”，避免无法恢复；操作悬停、按下及聚焦时也不加背景，保留文字反馈与键盘焦点框。编辑入口仅使用铅笔图标，与移除按钮始终可见，不再依赖悬停；保留无障碍名称与悬停说明。多条消息常显 28px 操作区的拖动手柄，采用指针捕获，移动超过 4px 后开始排序，显示插入位置并在列表边缘自动滚动；拖动期间队列修订变化时取消并提示重试，Escape 可取消，不再显示上下移箭头按钮；手柄继续支持键盘方向键排序；仅一条时不显示排序控件。键盘排序保留移动后消息的焦点；编辑继续先暂停队列，引用、附件、修订检查和错误恢复沿用现有逻辑。排队成功用队列内容与无障碍状态反馈，不再叠加成功提示；输入框提示为“继续输入，稍后发送…”。

## 聊天文字补齐

聊天主输入框统一使用 `ComposerTextInput`，灰色行内续写与已输入文本必须使用相同字体、行高、宽度、换行与滚动位置，颜色使用 `--text-muted`；建议不可写入 textarea 值。输入框随草稿及建议自动增高，最高 160px 后内部滚动，适配窄窗口与深色主题。

- 输入框为空且聚焦时，约 120ms 内优先显示经过过滤的会话历史表达，无合适历史时使用常用表达；仅显示灰色建议，不写入草稿、不自动发送，也不调用空草稿的模型接口。已有文字时，光标折叠在末尾、输入任意非空白文字、停顿 650ms 后生成续写建议（1～3 字短草稿也会请求模型，不设最少字数）；中文输入期间、资源候选展开时、禁用或失焦时不请求、不显示建议。建议出现时替代占位提示，避免两段文字叠加。空框有灰色建议时退格或 Delete 会在约 120ms 内换下一条，兼容键盘及 beforeinput 删除；按住删除键不连续消耗新候选；本会话中已跳过、接受或开始编辑的空框候选不重复，删空已接受文字时选其他候选。候选按最终显示文字去重，用完后恢复占位，不循环旧句子。Esc 后同一草稿不重复弹出，实际编辑后可重新建议。
- 中文输入法与 `@资源` 的按键处理优先。无修饰键的 Tab 接受当前续写并保留焦点；Esc 忽略当前草稿的建议；Shift+Tab 保持焦点导航。Enter 沿用发送快捷键，只提交已输入的文字，不能自动接受建议。
- 先用当前会话提问历史和常用运维表达做本地建议，再调用当前选中的模型生成短续写。最多附带最近 3 条、每条不超过 500 字的用户提问，不附带资源内容、附件或 Agent 工具；不能进入工具调用流程，也不能保存为消息。模型失败时保留可用本地建议，不打断输入。
- 继续输入、切换会话或模型、关闭补齐、失焦时取消请求；只采用与当前草稿、会话及模型一致的回复，忽略过期回复。服务端最多等待 8 秒，并取消同一会话的上一个补齐请求。
- “设置 → 对话 → 文字补齐”提供自动保存的开关，并明确说明会调用当前模型。输入框内不显示 Tab / Esc 提示按钮，也不为提示预留额外高度；保留键盘接受/忽略行为及无障碍状态文本。

## MCP 与 Skills 配置

在统一设置弹窗内提供 MCP 和 Skills 标签页，沿用主题色和 `Glyph` 图标。MCP 使用服务器列表和独立编辑页，编辑页右上角以胶囊选项切换“表单 / JSON”，作用域显示实际支持的“用户 · 本机”；连接类型与协议版本使用共享 `AppSelect`。表单包括名称、类型、超时毫秒、协议版本、命令与空格分隔参数或远程地址，环境变量 / 请求头默认折叠。保存后返回列表，保留单独的连接测试、启停和移除操作。Skills 保留左侧来源与详情结构；窄窗口相应堆叠，保存操作保持可见。

- MCP JSON 支持服务器名称映射和 `mcpServers` 包装对象，可粘贴或选择不超过 100 KB 的 JSON 文件，一次导入 1～50 个服务。完整校验后在同一私有文件事务中保存；同名服务不覆盖，任何条目无效均不部分导入。多条配置只在 JSON 模式保存，不在切回表单时丢弃条目；单条表单 / JSON 切换保留参数顺序、引号、空格、空参数与全部控制字符；包含控制字符时用 JSON 字符串数组展示，避免改变实际传入参数。超时范围 1000～300000ms，新配置默认 30000ms；协议默认自动协商，可显式选择当前 SDK 支持的版本。校验错误不得带出用户粘贴的认证内容。

- MCP 支持 Streamable HTTP、SSE 与本机 stdio。保存只写入配置，测试连接才进行握手、读取工具列表；不得以保存操作隐式启动程序。连接错误保持表单可编辑，返回可读错误，不显示认证材料或服务原始错误。正常工具发现和调用按服务配置共享握手，不让慢服务阻塞其他服务；停用、移除或改配可取消未完成握手，旧连接失败不得断开替换后的连接，不自动重放已发出的工具调用。
- 请求头和环境变量使用密码输入，保存后不回填原值。留空保留原配置，输入 `{}` 清空；服务地址不得携带用户密码、查询参数令牌或片段。
- MCP 工具按启用配置提供给聊天 Agent；没有启用服务时，不占用工具目录与默认上下文。调用遵循会话的静默执行命令、本机执行和资源范围权限。操作确认显示服务名、实际工具名和本次参数，隐藏内部服务 ID；MCP 工具自述不能代替授权。
- Skills 支持新建和编辑 Lake 管理的 `SKILL.md`、导入本机技能根目录或单个技能目录、刷新与启停。外部导入的内容只读，移除目录配置保留原文件与相对引用。
- Skill 停用后不得再次发现或加载；目录和内容不构成越权授权。默认目录及启停状态跟随当前 Lake Home，Dev 和正式版保持隔离。

## 窗口转角一致性

主要容器通过 `windowCorners.css` 共用 `--radius-window` 与 `--corner-window`：侧栏入口、选中行、资源目录、工作区按钮、悬浮标题、输入框、消息气泡、代码框、引用候选外框和候选行。macOS 26 以实际窗口截图的轮廓为基准，使用 22px 转角展开范围和 `superellipse(1.5)`；宽高至少为半径的两倍，避免浏览器因高度不足把 22px 压缩为不同尺寸。文字字号与横向留白保留，仅调整必要的最小行高。支持的浏览器直接绘制同一曲线；macOS 26 的旧 WKWebView 通过本地九宫格矢量蒙版绘制相同背景与边框，随主题、悬停和焦点继承样式，不添加轮询或逐帧测量；不得把仅 computed border-radius 相同当作实际一致。

会话状态徽标、输入区已选引用与消息引用标签使用相同窗口曲线，转角展开范围缩放为 8px，保留原有 20.5～24px 高度、类型配色、状态点与无边框的引用底色，不扩成 44px 标签；原生兼容绘制使用对应的小尺寸曲线遮罩。图标按钮和系统红黄绿按钮保留圆形语义。旧版 macOS 继续由宿主提供系统对应的尺寸与 round 回退。验收同时测量宽高、有效半径和 corner-shape，并比较实际截图中的转角轮廓；覆盖悬停、选中、深色与窄窗口，检查滚动、焦点、弹层和复制交互。

## 聊天 @ 引用

主输入框的 `@` 候选统一包含资源、Skills 和 MCP，提供“全部 / 资源 / Skills / MCP”分类、数量、名称及简介搜索。资源候选保留真实 `resourceKind`，与输入区已选标签、发送后的引用共用 `ResourceIcon`：SSH 主机、数据库、Redis、容器与本机分别展示实际类型图标，右侧同时显示类型名称；Skill 使用 `book`、MCP 使用 `plug` 的 `Glyph`。不按名称或 IP 猜资源类型，同名对象通过稳定类型和 ID 区分；按“数据库”等类型名称也可筛选。只列出已启用扩展，展开时重新读取配置；读取失败显示重试入口，不隐式连接 MCP。

资源引用标签按真实类型使用浅底、深色文字的圆角配色：SSH 主机蓝色、数据库青绿色、Redis 琥珀色、容器紫色、本机中性灰色。侧栏资源图标及 `@` 候选图标使用相同的类型前景色；资源目录图标使用主题淡金色，箭头、名称、数量与操作按钮保留中性色，悬停、选中与键盘活动时不改变类型色。输入区与消息共用配色规则，图标和文字使用同一前景色；标签不加彩色边框与阴影，以内边距维持原有宽高和文字位置。深色主题使用对应的低明度底色和高明度文字。未知类型和非资源引用保留中性样式，不能按名称或 IP 推断类型，不把类型颜色当作连接或执行状态。

输入区已选引用使用 24px 高 / 12px 转角，消息引用使用 22px 高 / 11px 转角，均按短边缩放同一窗口曲线；上下文引用及文件附件标签沿用 `--radius-window`；代码块复制与标签移除图标按钮沿用相同圆角，在方形点击区内自然呈圆形。保留标签大小、原始文本、复制、移除与键盘焦点行为；行内代码继续使用文字层级的小圆角。

`@` 弹层外框、候选行与分类标签沿用 `--radius-window`，与工作区胶囊控件一致。列表只用唯一的 `aria-selected` 绘制活动背景；真实鼠标移动同步活动项，键盘上下键更新同一项，静止鼠标和列表滚动不反向抢回选择，不能同时出现悬停与键盘两块高亮。点击、Enter、Tab 继续按实际选中对象引用，焦点保留在输入区。

- 长列表内部滚动，不截断后面的扩展选项；键盘活动项自动滚入可视范围。方向键移动，Enter / Tab 选择且不发送消息，Esc 关闭；空结果时 Enter 不得误发消息。中文输入法优先，候选展开期间暂停行内文字补齐。保留焦点、无障碍名称、活动项及展开状态，点击外部关闭。
- 引用由实际选择的类型与稳定 ID 建立，在草稿内以可移除的标签表示，正文编辑不影响标签选择。资源 ID、Skill 名称与 MCP 服务 ID 分开传递，同名对象互不混淆。发送时扩展引用保留服务端校验的真实文字范围；待发送队列保留引用，编辑时移除被删改的扩展引用，派发前重新校验启用状态。
- 服务端从本地配置解析 Skill / MCP 元数据，不信任客户端传入的内容、描述、调用参数或权限声明。所选 Skill 引导 Agent 使用 `load_skill` 加载，所选 MCP 指定工具发现的服务；选择操作不执行工具、不新增授权、不改变资源目标。MCP 认证材料不得进入候选或消息引用。

## SRE 专员回复

输入框的 SRE 协作开关保存时保持当前颜色、尺寸和焦点，不通过原生禁用按钮显示禁止光标或变灰闪动；使用 `aria-busy`、`aria-disabled` 和提交保护防止重复写入。运行中或连接中断时保留禁用约束，以普通箭头光标和提示说明原因。保存失败可重试，不先展示尚未确认的开关状态。

专员沿用无底色、小尺寸湖生态头像和对话正文，不把报告包成独立大卡片。正文最大宽度 820px，使用 14px 字号、1.85 行高；分组之间保留 20px，事实列表之间保留 9px。浅色、深色、窄窗口共用主题变量。

旧顺序分工的多步调查计划应说明“调查员先完成采集，协调者再汇总”，不能让单专员执行看起来像已并行。升级沿用的完成记录显示“已沿用”，提示未重新执行。执行中的专员使用共享 StatusText 和轻量旋转指示显示真实活动、耗时与证据数量；暂停、待确认、未知和结束停止执行动效，prefers-reduced-motion 下完全静止。Plan 的未知结果优先于“处理中”，核实入口直接定位实际操作记录。并行专员分别在对话中显示发言，定向交流在名称旁以 `Glyph` 箭头和接收专员名称标识。进展状态来自真实 AgentRun，等待确认不能显示为正在执行。进展与团队交流不重复附带整个操作记录；最终回复在完成时追加，保留交流时间顺序。

同次专员的成功操作默认合并为一行折叠记录，按需展开查看每条参数和原文。失败、等待确认、未知和未执行的操作保持直接可见，未知结果的人工核实入口不可收入成功分组。同次失败依据 attempt 归属和完成时间去除父错误卡、系统消息的重复副本；不能删除其他轮次的错误，也不修改持久审计记录。

中断或停止 SRE 后，不在输入框上方自动显示“原操作结果待核实”面板或核实表单。原始操作与未知状态保留在执行记录中，按需查看，不用额外弹窗占用对话输入区。普通会话不因历史操作 unknown 或仍在运行就锁住后续新命令；新调用按当前目标和权限执行，同一持久调用不重复派发。“执行记录”仍提供默认折叠的“待核实操作”：仅列出服务端返回的 unknown 变更，运行中只查看、停止后才可记录。核实是审计入口，不是解锁普通会话的前置条件；记录时必须显式选择真实结果并填写核实依据，不能以“忽略/放弃”代替事实，也不能从该入口重试原操作。

调查报告直接使用后端已保存的 `attempt.report`：先显示结论，再分别展示观察事实、待验证假设、尚未确认、后续检查；隐藏空分组，不通过正文关键词猜测事实或验收状态。证据编号只匹配同次 attempt 的真实记录，点击展开该消息的证据区并聚焦对应原文；不执行新的采样操作。错误、进度和用户消息不得继承已完成报告。没有结构化报告时，以及其他专员的正文，使用禁止原始 HTML 的 Markdown 渲染，支持段落、列表、表格和等宽代码。

SRE 正文的 Markdown 渲染器必须保持稳定引用；未变化的正文复用已有节点，快照和计时更新不得重建表格或链接。耗时使用固定宽度，已在底部且内容高度未变化时不重复写入滚动位置。命令因静默检查未通过而额外确认时，不应仅凭审批类别就显示为“删除或移动”；保留实际审批要求和目标确认。

普通对话在当前轮运行及等待确认期间，黑色正文统一显示在该轮灰色进度上方；后续新增说明仍插入进度区之前，正文之间保留原始顺序。已完成及恢复的普通对话也保持正文在上、灰色过程入口在下；执行记录视图仍按原始顺序展示。执行过程入口在同一轮内保持稳定挂载，不得因流式更新重建进度节点或丢失展开状态，审批、错误及子任务入口保留。每轮回答中，同一真实资源只保留一条灰色操作摘要，固定使用首次出现的卡片 ID；后续思考、黑色说明、其他资源交错、终端或容器切换、失败与审批均不另起该资源的进度行。摘要原位更新当前操作与累计项数，失败、待确认、未知、未执行、已停止和后台操作在原行明确计数，不用后续成功掩盖。展开后保留全部工具参数、结果和原始思考；审批、错误正文和子任务仍保留各自入口，不改变执行或权限。不同资源保持独立，不因名称相同就合并；新一轮提问重新建立分组。后台命令的失败、完成及等待/读取/停止记录按原始 shell_id 和派发资源归组，后台卡保存原始资源与父操作身份；旧记录仅在精确句柄能找到唯一派发资源时关联，不沿用当前选中主机或按邻近位置猜测。来源不明或冲突时保留独立记录，不能隐藏错误。仅新资源行播放入场动画，既有行更新不重播、不重新挂载、不改变开合状态。下方仍有空白时不写入滚动位置；溢出视口后正常跟随，用户上滚阅读时暂停。同高度的进度与计时更新不得触发额外滚动。

主会话输入区上方的确认面板与问题入口使用共享 composer-session-controls 内容列，宽度、居中位置随输入框和会话列同步变化；不得沿用独立660/860px上限使宽窗口偏左。专员内嵌确认仍服从其所在报告列。

附件上传确认使用中性表面、细边框和共享文件图标，直接展示原文件名、大小、目标名称与完整保存路径。工具名、资源 ID 和原始参数收在默认折叠的“技术参数”中。按钮使用“取消 / 上传文件”；明确请求覆盖时使用“覆盖并上传”并提示同名文件的影响。保留原有权限、输入目标确认和操作记录，不用大面积警告色表达普通上传。

文件读写与删除确认同样使用中性表面和轻量文件面板，直接显示操作名称、文件名、目标与完整路径；不默认展开资源 ID 或整段 JSON。内容预览默认折叠，准备好的 Markdown 文件展开后按文档排版，支持切换原文，不加载远程图片或执行原始 HTML；其他内容保持等宽文本。预览仅滚动内容区域，授权按钮始终在其外部，保留空文件及原始精确内容。已有变更前后版本时显示真实增删行数；缺少完整预览时不把补丁伪装成完整文件。技术参数按需展开，按钮明确为允许写入、允许修改、允许追加、允许读取或删除文件；高风险、目标确认输入、排队数量和单次授权规则继续保留。

## 验证要求

每轮真实文件变更在折叠统计上方直接列出文件超链接，方案 Markdown、YAML 和脚本均可点击；本轮已成功写入且未删除的本机文件使用独立文件卡片：左侧共享文件图标、完整文件名入口和“本机 · 文件类型”，右侧“打开”在 Lake 内预览已记录版本；窄窗口截断长文件名，同名文件补充路径，完整路径保留在提示和预览中。失败、待确认和已删除记录不得伪造为可打开的新文件，差异统计与原记录继续保留。来源主机或容器重名时保留区别。预览只使用本轮操作中已保存的文件版本，明确注明来源和完整路径，不额外读取主机、不执行脚本。Markdown 方案默认排版阅读并保留原文，相关文件链接仅解析到同一目标、同一目录语义下的已记录文件；未知或歧义路径不猜测，不加载远程图片或原始 HTML。原有差异对比保留，已删除记录可查看变更前内容。预览使用原生模态对话框，Escape 关闭、焦点返回原链接，窄窗口可完整滚动查看。

“跟随系统”必须保留为独立的外观偏好；macOS 窗口清除显式 appearance，继承系统外观，再由 WebKit 的媒体查询同步正文、导航、终端和弹窗。不得把当前解析出的浅色或深色重新固定到原生窗口，否则后续系统切换不会生效。手动浅色、深色继续固定，重启后恢复已保存的偏好。

修改公共选择框时，检查键盘导航、禁用项、受控值和默认值、Escape 与外层弹窗的关系、焦点回到触发器、窄窗口边界、底部向上展开、长列表滚动和深色主题。SSH 等字段还需确认原有变更事件及凭据保留/清空逻辑正常。厂商图标检查快速入口、侧栏、详情的一致性及离线可用性。

运行 TypeScript 检查和相关前端测试，通过签名脚本构建并在 Lake Dev 中验证。仅使用隔离测试数据；不在截图或验证记录中包含密钥。验证结果和截图存放在 `docs/validation/`。

历史任务不占用会话任务槽位，新目标可直接建立独立任务，不要求先取消、收尾或恢复旧任务；旧计划、证据与记录原样保留。运行中的父轮仍串行调度，实际操作继续使用原权限、审批和持久调用防重放规则，建立新任务不代表恢复或执行旧任务。

SRE 输出节奏按实际 Plan 节点区分：observe/analyze/act/verify 完成时给 1～3 句节点小结；summarize 只在结束时汇总一次。调查报告正文只默认展示 summary，结构化事实、假设和缺失证据收在“查看节点详情”；历史长篇节点回复收在“查看节点小结”，不删减持久记录、不自动编造摘要。不能仅凭协调者身份或旧消息 kind=summary 判定为任务最终总结，必须关联该 attempt 实际执行的历史 Plan 步骤。正在执行、协作请求、错误和审批不受节点详情折叠影响。

持久终端命令的等待超时与命令失败必须分开。原命令仍有实际终端/entry 句柄时应继续通过 wait/output 查询，不重复派发，也不把专员或其同伴一并取消。Plan 的操作完成状态只根据唯一匹配的原终端完成记录与退出码更新；不能由模型文字、相似命令、其他会话或不完整输出推断。明确“重新开始”通过 restart_task 原子结束旧的暂停只读调查并建立同目标同范围的新调查，保留历史；结果不明的变更、仍在运行的操作和变更任务不能靠重启绕过。只读超时保留原记录并允许新采样；只有结果不明且不能证明为只读的操作才提供核实入口。正在运行的操作仅显示原命令进度，不能提示人工确认成功。正常回复结束沿用下方“计时与执行过程入口”的中文用时样式；没有真实起止时间则不编造耗时。正常运行的思考动画满 1 秒后才显示，不足 1 秒不显示动画或小于 1 秒的耗时提示；确认、失败、停止和结果未知等重要状态立即显示。停止、未完成、中断、后台执行和结果待核查仍须显示，任务状态独立保留。并行专员对同一主机和配置共同等待一个真实指纹决定，不自动信任。

## 轻量交互细节

回复正文和 SRE 报告的代码块使用共享 `MarkdownCodeBlock`：主题底色、细边框、`--radius-window` 圆角，单行随内容收缩，长代码在自身区域横向滚动。右侧仅常显 Glyph 复制图标，不显示执行按钮，也不再使用独立的顶部工具栏；多行代码的复制按钮靠右上角。复制按钮不随长命令滚出可视范围、不遮挡代码。明确标记为 Shell 的单行命令采用主题终端蓝色命令名和绿色参数，多行、其他语言与普通文本不套用此配色。复制保留整段原始文本的路径、引号、空格及换行；成功短暂切换为勾选图标并报告“已复制代码”，失败明确提示使用键盘复制，不误报成功。行内代码保持原样，按钮支持键盘、触摸与深色主题。

次级详情、证据、操作记录和技术参数统一使用 `DisclosureSummary`，透明入口配右侧细线箭头，保留原生键盘开合、可见焦点和原文；执行过程等具有独立布局的主入口保留原布局。排队消息与普通问题使用中性主题表面，真实错误才使用错误色。操作按钮统一使用共享 Glyph，不用字符拼接关闭、编辑或排序图标；深色模式的表单、问题和资源标签不得写死白底。

待发送消息气泡使用浮层材质变量：55% 中性底色、12px 背景模糊、系统窗口圆角、细边框，悬停/聚焦为 68%。待发送气泡使用更轻的独立阴影，外层及滚动列表完全透明，避免阴影被裁成整块方形底。队列悬浮在正文滚动区域上，不占用正文高度；仅在记录末尾按实际队列高度预留空间，正文可从其背后经过。队列增减、编辑和窄窗口随测量更新留白；减少透明度或不支持背景模糊时使用实色回退。 新追加的待发送消息在 260ms 内展开高度、轻微上移并淡入；发送或移除时在 200ms 内淡出收高。剩余消息保持稳定身份，排序以 260ms 平滑移位；退场副本立即 inert、隐藏于辅助技术且不再提供队列操作目标，不延迟实际发送。队列接入下一轮后，新用户消息以相同的 260ms 轻移淡入承接；同一队列/正文刷新与历史恢复不重播，减少动态效果及后台页面直接切换。

新增黑色正文和灰色操作行使用 360ms 缓出动效，从下方一行（23px）上移并淡入；只作用于新追加的记录，不缩放、合并或重建前面的行。既有行的文字/状态更新、历史恢复及完成状态切换不重播。遵循减少动态效果偏好。回复正文不另占一行展示流式圆点，整轮执行状态由每轮开头的参数行承接；运行与结束状态保持相同的耗时行高度和底部留白，避免完成时滚动区域骤缩。

执行中的灰色操作摘要使用中性扫光文字，3.6 秒循环，仅重绘文字，不位移、重建节点或改变行高；失败、待确认、未知、后台和已结束轮次的记录不播放。减少动态效果时保持静态可读文字。每轮耗时与状态放在用户提问之后、回答正文与灰色执行行之前，不放在整轮末尾；历史轮次同样保留准确归属。该参数行保持固定的单行高度，避免状态切换推动下方正文。仅移动展示位置，不改变模型、权限与思考级别的操作入口。

## 项目定时任务

“工作区 → 定时任务”展示当前项目的已有巡检和提醒，不另行开放工作流编辑入口。列表保留启停、频率、下次执行和最近状态；详情展示来源会话与最近 100 次真实执行记录，成功、失败、中断、错过不能混为完成。周期任务恢复后从下个执行时间继续，单次任务约 1 分钟后执行，不立即补跑；暂停只阻止后续触发，已运行任务继续执行。只读巡检沿用工作流执行，启用前校验当前项目已开启 SRE 协作且模型已配置；暂停和查看不受此前置条件限制。界面需明确显示此依赖，提醒不依赖模型。所有启停操作使用当前修订号，冲突须显示错误并重新读取，不能悄悄覆盖调度器新状态。旧版任务没有完整历史时如实说明，从升级后的执行开始记录。每条执行可跳到其实际结果会话，来源会话单独提供入口。

弹窗沿用紧凑、中性主题；项目列表与详情分区，窄窗口纵向排列并保持内容可滚动，关闭、Escape、Tab 焦点循环和返回工作区入口有效。空列表提示需在会话中明确说明目标与频率，不替用户创建任务。模型不得因连续手动检查就主动弹出定时巡检提议；用户明确要求定时工作后才使用调度工具，并依据成功返回说明创建结果。

同轮属于同一项目功能类别的普通操作也始终复用首行：工作流、定时任务、任务进度、资源目录、Skills、历史会话、工具结果、任务输出与 MCP 分别归组。历史会话、工具结果、任务和 MCP 服务必须保留真实 session_id/result_id/task_id/server_id 的作用域，不把不同对象或缺失句柄的记录误合并。工作流与定时任务不能因都显示“当前项目/会话”就混为一行；询问用户、正文和审批保留独立入口，但不打断同作用域的摘要分组；失败、未知、停止和后台状态在该行明确显示。展开后保留全部原始操作，新增同类项不重建行、不重播入场或扫光、不写入滚动位置。新增会话工具时必须明确分组类别或边界规则。

输入区使用同一可编辑文档混排正文和原子引用标签，文字可位于标签前、后及标签之间，侧栏添加和 `@` 选择均插入光标位置。标签只显示类型图标和名称，不显示 `@`，不另列一行重复资源名。引用在文档中占一个原子位置，按稳定类型和 ID 解析；移动光标、跨标签选择删除、点叉、撤销和重做保持正确身份与顺序。Shift+Enter 保留换行，中文组合输入期间不重建编辑节点、不误发消息。粘贴默认只接收纯文本；同一编辑会话的内部剪切粘贴可保留已选引用，其他来源不得仅凭名称或剪贴板声明新建绑定。自动补齐、附件、发送及排队入口继续有效，发送按句子实际顺序展开引用并保留服务端校验的真实文字范围。

发送后的用户消息按已保存的 UTF-16 引用位置恢复内联标签，与文字保持原顺序；标签显示资源/扩展图标与名称，不显示 @ 和删除按钮，刷新会话后仍保留。展示引用不改变发送文字、模型上下文或资源权限。新消息显式保存空标签数组时保留字面 @ 文本；旧消息仅以当前已知资源名兼容展示，匹配优先完整长名称，不改写历史。队列保留标签位置，编辑时随文字移动或移除，实际发送后沿用同一展示。

每轮计时行与第一条进度/正文之间保持 12px，计时行不额外叠加底部 margin；同轮条目沿用 12px 间距。当前轮最后一条正常灰色进度在工具已返回、模型准备下一步期间继续文字扫光，本轮结束后停止；生成正文期间继续显示当前正常摘要的扫光；历史、失败、待确认、未知和后台状态保持静态。同一资源行更新不重新挂载或重启动画，减少动态效果设置继续禁用扫光。

每轮进行中的状态图标采用首版“湖面流动”：共享 Glyph 的 waves，18px 单色细线、20px 固定占位，使用次要文字颜色；三条水纹按 0 / -0.35 / -0.7 秒错峰，在 2.4 秒内柔和明暗和 ±0.5px 轻微横移，不旋转整体。待确认与完成时沿用现有隐藏规则；减少动态效果时显示静态清晰水纹。

文件变更摘要使用透明、无边框的轻量详情入口：左侧文件图标，文件数量、绿色新增和红色删除统计及右侧展开箭头保持单行水平对齐。默认不铺灰底，悬停或展开时使用主题浅底色，保留键盘焦点与原生 details 行为；窄窗口文字可换行，统计不可截断。回答进行中沿用“正在思考…”等真实状态，耗时、停止状态与执行过程入口统一使用下方规定的中文用时样式，不再重复定义时钟或英文单位；运行中的动态水纹继续保留。用户停止本轮后，仅在计时行以次要文字显示“用时 … · 已停止”；该轮已有停止计时状态时，普通对话不再重复显示红色“已停止本轮”。真实错误、工具停止状态及执行记录继续保留；旧记录缺少计时信息时仍保留停止提示。

本地终端是项目内置入口，固定在资源列表根目录顶部，不显示“内置”文字标签，不显示拖动手柄、移动和删除操作，也不参与资源批量删除或全选。保留终端打开、新建连接、Shell 配置、资源信息和添加到对话。服务端拒绝本地资源删除及移动，不能只依赖前端隐藏。升级时为缺失的活动项目补齐入口，恢复旧版已删除的本地资源并保留 ID、名称、Shell 配置及历史引用；已嵌套的移回根目录。恢复旧目录不得把本地终端重新收进去；项目本身仍可删除与恢复，本地入口随项目生命周期展示。

普通 Agent 的目标资源、终端创建、MCP、SQL、命令和导入确认统一使用中性紧凑面板，不再使用整块黄色底色。突出目标名称和本次影响，资源/终端 ID 与完整技术参数默认折叠；完整命令或 SQL 仍直接可见，导入预览与文件差异继续展示。高风险、必填目标输入、等待队列及未执行状态不得隐藏。仅替换展示组件，原有单次决策 ID、子任务身份和确认校验保持不变；SRE 专属动作继续使用其影响、停止条件及回退说明。

普通操作、文件和附件确认面板的标题图标统一使用共享 `Glyph` 的 `lakeConfirm`（湖面确认）：上方勾选、下方双水纹，24px 画布、1.4px 圆头细线，以 18px 显示并沿用主题次要文字灰色，保持与标题对齐。图标保持静态，文件类型、危险/删除提示仍使用各自语义图标，不以品牌图标替代风险说明。

灰色执行摘要在文字前使用 20px 固定占位、18px 共享 Lake 语义图标，命令/终端、文件、搜索、目录、主机、数据库、容器、工作流、定时任务、MCP 和提问分别区分；仅根据真实工具身份选择，未知工具使用通用水纹，不从命令或返回内容猜图标。展开记录复用同一映射。非运行图标静态、保留类型色、圆头细线；运行时使用下方执行图标的横向彩色水流规则；保留同资源唯一行与全部异常计数，图标更新不改变行高、不添加状态环或重启入场动画。

对话自动跟随按实际滚动意图区分：内容未溢出时，点击正文或展开/收起短进度不得永久暂停跟随；新增正文溢出后继续平滑跟到底部。底部向下滚轮/按键因无法产生 scroll 事件，不得误锁跟随。向上滚动、拖动滚动条、触摸滚动、选择文本或阅读可滚动的操作详情时暂停；手动回到真正底部后恢复，仍保留像素取整容差、无高度变化时零滚动写入和减少动态效果偏好。加载更早记录继续表明阅读历史的意图。

后端最近 300 条卡片的连续分页窗口向前推进时，前端保留本会话已展示的前缀，并按卡片 ID 应用新的结果。不能把分页淘汰当成历史删除，导致每执行一步都改变正文高度、替换历史节点或重新定位滚动。切换会话不混入其他会话记录；真正缩短历史及非连续的页面仍保留正确的替换/加载更早边界。新增步骤保留原进度行和已展开的命令详情。

上下文用量圆环与顶部会话状态共用当前会话（含 SRE 展示状态）和同一主题色：调查中蓝色、待确认黄色、回复结束绿色、需要关注红色、待命灰色。状态和主题变更在同一轮渲染更新，不单独缓存颜色。圆环长度和详情继续使用当前模型的服务端实测用量，未知时不编造比例；接近输入预算上限时在详情和无障碍说明中保留警告，不覆盖状态色。

上下文详情采用约 292px 的紧凑浮层，使用共享 UI 字体与等宽数字排版，不使用整块等宽字体。概览展示输入预算使用率、实测输入 / 有效输入预算、剩余预算和最近请求缓存命中；缓存率按该次请求输入计算，不称为平均命中率，也不扣除缓存来缩短占用。没有服务端分类明细时不生成消息、工具或技能占比。模型窗口、总预算、输出预留、输入/输出、缓存 token 和会话累计收在默认折叠的“用量明细”中。浮层按视口避让，展开后重新定位，低矮窗口内部滚动；悬停可进入卡片，点击固定、外部点击关闭，Escape 关闭并返回入口焦点。

计时行中的用时、分隔点与运行状态文字作为同一个共享 StatusText 整体扫光，耗时每秒更新但不重建节点或重启动画；等待确认、结束或停止时不播放。工具已返回、随后新增正文或正在生成正文时，当前最新正常执行摘要继续扫光，直到本轮结束或出现下一条操作；包含失败、待确认、未知、未执行、停止或后台结果的摘要保持静态。更新文字与计时不重新挂载节点、不重启动画，减少动态效果设置下全部静态可读。

普通对话的“本轮文件”入口与文件变更统计在整轮回复结束后统一出现，作为一个整体复用 360ms 淡入上移入场；模型仍运行或等待确认时不提前展示。失败、停止和中断结束后仍展示实际已完成的变更，不把部分成功写成整轮成功。实时完成记录只入场一次，后续更新、展开详情和预览不重播；恢复已结束的历史直接显示，减少动态效果时静态展示。执行记录视图仍可实时查看已落地的文件差异。

工具执行阶段的计时与执行过程入口位于本轮末尾；结论首个非空片段到达时，先移至用户消息之后、本轮回复正文上方，随后呈现正文，采用参考图的紧凑样式：13px、基础 UI 字重 430、20px 行高的主题浅灰文字，“用时 9分钟 54秒”中文时长，紧邻 11px 右向箭头，下方一条淡分界线；完成后不再放时钟图标或英文 h/m/s。普通对话运行期间默认展开执行区域，二级条目仅显示唯一资源名称、类型图标及必要状态；同一资源的不同工具操作归入同一行，以真实资源 ID 优先，名称仅作精确且无歧义的兼容匹配。每个资源的具体操作作为三级条目动态追加，资源和具体操作默认折叠，参数及原始输出只在用户继续展开时挂载。展开状态在同轮更新中保持；会话结束时执行区域以 220ms 淡出和 360ms 缓出收高自动消失，消除残留行间距，减少动态效果时直接收起。历史默认折叠，可经此入口点击或 Enter/Space 回看完整步骤与原文。资源实时进度放在资源名称、操作数量所在的同一灰色行，以单行省略显示最新一条，完整文字可经提示或点击/键盘展开查看；正常执行时参与共享中性文字扫光，等待确认、异常、停止、结束及减少动态效果时保持静态。后续进度原位替换，不重建资源行或重启动画、不改变折叠状态；完整最新进度、此前记录及具体操作收在同一资源展开区，原始会话和证据不删除。资源阶段仅在明确资源 ID、精确且唯一的资源名称，或唯一资源的紧邻操作上下文中展示。多资源共同涉及不等于文字归属；联合或歧义结果保留在原始过程记录与最终回复中，不把同段原文复制到多个资源，也不猜测“源端/目标端”指代。阶段文本按规范化内容去重，不依赖消息 ID；同一资源重复播报合并为一条，不增加历史计数，归属冲突的重复文本保留在原始记录中。原始记录完整保留供回看。不再追加跨资源的综合进度摘要或额外生成请求，原始记录仍可按需回看。不要显示独立的“整体进展”分区，不通过 IP 缩写猜测单一资源身份。真实最终总结独立保留在正文，普通回答、失败或 SRE 角色报告保留原呈现。执行区域底部不添加分隔线或伪元素，也不为已移除的总结预留空行；最后一个资源之后沿用正常段落间距。常显最新进度存在时不重复追加耗时旁的操作说明；其他情况下，耗时栏旁的最新操作图标和说明仅在当前轮运行且执行区域折叠时显示，完成、失败、停止、中断和历史轮次均隐藏；保留真实耗时、异常计数及回看入口，不能因持久化操作卡仍为 running 而残留。回复正文与单独的审批/错误控件仍可见，失败、待确认、未知、后台等异常计数在折叠入口直接展示。无可靠计时的旧记录使用“执行过程”，不编造用时；独立执行记录视图保留完整展示。工具阶段在本轮末尾显示真实计时“已处理 18秒”与当前状态，不添加分隔线；结论开始输出前将同一节点移到回复上方，静态显示当时的真实处理用时，细分隔线位于计时行下方；整轮结束后在原位更新真实总用时与结束状态。新增思考结果和进度不重建此状态节点或重启扫光。Pilot 运行中隐藏整轮计时，不重复各专员已有的子任务状态；结束后显示同样的完成计时与分隔线。恢复历史直接显示完成样式，不补播入场动画，减少动态效果时直接呈现。

### Mini Box

普通会话及 Pilot 专员执行子级中，每个已明确解析的本机或 SSH 资源在“执行命令”三级节点内复用一个 Mini Box，本机标注“本机”、远程标注“SSH”；单台执行时命令派发默认展开；同轮涉及两个及以上不同本机/SSH 命令资源时，Mini Box 默认仅显示 36px 标题栏。计数包含已完成命令，不依赖同一采样时刻是否都在运行；执行完成和历史恢复仍适用。第二台出现时首台若尚未手动操作，自动收起一次；手动开合或查看原始输出后不再自动改变。折叠标题栏直接展示当前命令（等宽单行、长命令省略、悬停显示全文），没有命令时显示“等待命令派发…”，保留状态、终止按钮和异常入口；同台多命令、非终端工具、其他资源类型不增加资源计数，各轮单独判断；Pilot 以当前计划运行中所有专员的实际命令资源计数，同资源归回首次出现的分组。Mini Box 首次出现以 320ms 淡入、轻微上移及布局高度展开，折叠/展开以 280ms 平滑改变 36/144px 高度，预览文字随之淡入淡出，开合箭头同步旋转；收起预览立即从辅助技术和键盘导航隐藏，输出更新不重播入场或改变开合状态。减少动态效果时取消上述过渡。统一最大宽度 720px、高度 144px（标题 36px、预览区域 106px），窄窗口只压缩宽度；当前命令固定一行，默认最多三行输出，新命令及输出原位更新、不随输出撑高。空行清理、连续重复合并计数、回车进度原位更新，原始记录不受预览整理影响。首处异常线索及相邻上下文固定，其余位置显示最新输出；异常入口显示数量并展开定位，不能将文本匹配直接判为失败。退出码、未知结果、终止和连接状态以真实执行记录为准；退出码零但有异常线索时明确提示核查。完整输出按资源独立展开为 280px 内滚动区，保留全部已收到记录，用户阅读期间不自动抢滚动；Mini Box 自身尺寸保持不变。终端接近原有 32KiB 记录上限或尾部已滑动时，入口改为“保留输出”并提示容量限制，不虚称完整记录；当前视图已观察到的异常单独保留，收起资源不卸载其异常缓存。权限失效、切换会话/轮次/资源及 terminal generation 替换清除相应缓存和操作目标。沿用 Lake 主题、14px 面板窗口曲线、轻微磨砂材质及共享 Glyph；文字不参与背景模糊。原始命令记录按需展开，其他工具和资源保持原分组。

`inspect_host` 的主机检查同样会执行真实终端命令，须从工具派发的首次渲染就显示 Mini Box，不等后续 shell 调用、历史接口返回、effect 或进度入场动画。原始工具参数与结果收在“原始执行记录”；终止检查中的当前命令后，不再派发该次检查的后续命令，其他资源不受影响。

工具之后开始输出总结时，采用顺序切换：先停止刷新并淡出、收起原过程与中途播报，待旧区域完全清空后再淡入总结。切换期间收到的总结保留在原始状态中，暂不绘制正文；过程退出约 360ms，总结以 240ms 的整块淡入、轻微位移和裁切展开进入，不能同时显示旧过程和新总结，也不能重复两层入场动画。正文一旦显示，后续追加和完成保持同一节点、不重播。若后续又有工具调用，取消待显示的总结并恢复真实过程，不提前伪装成结束；失败、停止及历史恢复保持直接可读。减少动态效果或后台页面跳过等待和入场动画。原过程、命令及文字记录仅从当前视图收起，仍能通过用时入口回看。

正在执行时状态文案统一为“Lake 正在操作”；当前 Mini Box 使用 2px 短蓝色光带沿真实圆角周长匀速绕行，每圈 5.2 秒；亮头约占周长 4%，连同两段渐弱尾迹总长约 18%。整圈底边及框内 12px 柔光只用 6% 强度，让移动位置清晰可见；无亮白尖峰、呼吸或闪烁。使用归一化 SVG 路径与固定 2px 圆角遮罩，三段光带保持相同周期和固定相位差；输出刷新保留动画对象与起始时间，尺寸只在真实 resize 时测量。受控状态跟随该资源真实操作生命周期，inspect_host 等多命令操作中的短命令间隔不退出蓝框。动效只覆盖当前 Mini Box，不遮盖正文或拦截点击；执行 240ms 淡入，等待确认、断线、终止、未知及操作结束暂停并在 600ms 淡出。减少动态效果下静止，后台暂停；检查明暗、窄窗口、圆角和终止按钮。

Mini Box 只读取本会话、本轮、本资源、准确终端 generation 的 AI 命令块；Pilot 同时按专员 attempt 的实际派发与准确句柄隔离并行命令，无句柄时仅接受唯一最近派发且在两秒窗口内的同命令记录，歧义不展示/操作；不混入手动终端屏幕。终止请求必须同时绑定 terminal ID、generation 和 entry ID，服务端再次验证当前命令及写权限；过期按钮不得影响替代命令或其他资源。用户终止后向 AI 返回明确通知并阻止同轮自动重试该命令，其他资源继续独立执行。会话结束后在正文保留资源级终止说明，未知结果须提示核查，不将停止请求解释为命令成功。

## 首次使用与空工作台

欢迎页由 WelcomePage 承载，使用已批准的 Lake 山水 Logo，高清母版来自 assets/branding/lake-app-icon.png，前端通过 LakeLogo 复用本地资源。Logo 只在欢迎页主区域展示；侧栏保留 Lake 文字品牌，不额外添加 Logo。连接工作台入口复用同一 Logo，不以工具图标代替品牌。不使用英文标语、轨道装饰、步骤编号、模型厂商展示或宣传式文案。

首次进入显示“欢迎使用 Lake”和“连接模型 / 创建项目”两项操作，以共享圆角面板中的两行呈现；两个入口独立可用，不强制配置顺序。已有项目时显示项目名称和新建会话入口，模型状态只依据 bootstrap.modelConfigured 展示“已配置”，不编造连接状态。未创建项目时侧栏只显示“暂无项目”与新建入口，不使用伪加载占位。

欢迎页复用共享主题、窗口曲线及 Glyph，不加载远程字体或图片，不自动请求模型、创建项目或会话。检查明暗主题、键盘焦点、hover/禁用状态及窄、低高度窗口；内容正常纵向滚动，保留项目导航入口。

用户消息气泡悬停时在左侧显示复制按钮，指针移到按钮时保持显示；键盘聚焦同样可见，触摸设备直接显示并保留 44px 点击区。复制原始消息全文，保留资源引用标签、空白和换行，不将图标、附件地址或反馈文字混入剪贴板。成功显示勾选并自动复位，失败显示明确提示；纯图片消息不增加空文本复制入口。


会话右侧“任务检查”在 macOS 桌面通过受主 frame 和同源检查保护的原生桥接扩展整个窗口，默认增加 382px；动画中锁住原会话画布，保留正文宽度和当前位置。先利用右侧空间，不足时将窗口向左避让；总宽受当前屏幕可用区域约束，全屏或屏幕已满时采用并排布局，不能将面板盖在正文上。关闭时仅收回本面板实际增加的宽度，保留用户期间的移窗与调整；刷新页面或退出时还原扩展宽度，避免下次启动重复加宽。减少动态效果时取消原生扩窗动画。浏览器、旧客户端及 Windows 不宣称支持原生扩窗；桌面视口采用并排布局，手机视口保留抽屉。


任务检查栏的概览卡将“步骤进度”和“任务结论”分开：真实成功步骤使用主题绿色，执行中蓝色，待选择/审批和结果待核实使用琥珀色，失败红色，待开始与暂停保持中性。全部步骤完成可以显示绿色勾与完成数量，但 `inconclusive` 仍独立显示“结论不充分”和琥珀色提示，不能因 3/3 已完成而宣称恢复。仅服务端 `recoveryStatus=verified` 才显示“恢复已验证”；修订计划不沿用旧运行的进度，暂停和结束不保留运行中的段状态。进度提供真实完成数和无障碍文字，不编造百分比；主题、节点和记录保持原有来源。

输入框底部工具栏使用 `lake-composer` 实际容器宽度进行紧凑适配，不依赖整个窗口宽度。会话、任务检查与终端并排时，620px 以下缩短间距、模型入口允许省略，并保持单行；480px 以下权限和 Plan 使用带原有可访问名称和提示的图标入口。360px 以下仅省去模型的行内思考强度文字（完整值仍在入口名称和菜单中），300px 以下再省略 Lake Pilot 标签，保留图标与 AUTO 标记。保持既有控件高度和焦点反馈，不隐藏权限、模式、模型选择或上下文入口，不改变设置值。

右侧检查栏的开合和页签切换不暂停主对话的滚动跟随：原本正在查看最新回复时，布局重排和新增正文后继续保持末行可见；主动上滚阅读历史时保留原阅读锚点，不强制拉到底部。正文内的用时/执行过程入口始终使用朝右的导航箭头，点击打开或定位右侧详情，不再旋转为向下箭头；内嵌展开区仍按原来的上下展开语义。

工具执行后的结论收到第一个非空片段时，将原计时节点移至结论前并淡入，正文随后接替，不得在正文出现后才补插用时行；空片段不提前触发。输出期间显示截至正文接替时的真实处理用时，停止秒级更新与扫光；整轮正常结束后在同一位置更新为真实总用时，仅保留“用时 …”与详情箭头，不显示“· 已完成”，不重播动画。失败、停止、中断和待核实状态仍如实显示。正文接替至少让计时行先呈现120ms，并沿用过程收起后的正文入场；减少动态效果或页面隐藏时立即呈现。后续实际工具调用恢复执行状态；审批、问题和原始记录继续保留。

完成时计时行的位移不充当正文滚动锚点；仅原本跟随最新回复时在绘制前校准到底部，之后由布局触发的滚动继续跟随。主动阅读历史不被完成事件拉回。侧栏以Lake品牌左边缘统一会话图标、查看全部、资源标题与一级资源图标；资源子项按层级缩进，拖动入口位于右侧操作区，只有子目录保留前导展开箭头。

Pilot 运行期间不展示整轮计时行，也不为它预留空行；结束后沿用普通模式在回复前显示真实用时及下方分隔线。同一用户轮次、同一 Pilot 任务的每个角色只保留一个稳定区域，最新内容和状态原位更新，不能合并不同任务或用户轮次。计划入口、所有待审批/待选择控件及历史错误提醒仍保留；活动记录与持久化原文不合并或删除。

Pilot 角色区域沿用普通会话的 AssistantMarkdown 正文和共享灰色进度入口，保留角色图标与名称；运行进度参与原有文字扫光，不再使用分栏计数与旋转小圆环，进度行不展示用时。详尽结构化报告和原始记录在右侧回看，方向选择及变更审批继续原位可操作。

右侧检查栏不保留说明性底栏，“主对话保持在当前位置 / 返回对话”由顶部关闭入口替代。计划底部仅保留“详情”和实际可用操作；在途命令提示简写为“等待命令结束”，真实失败、审批及待核实提示仍完整呈现。

侧栏资源/目录的拖动把手默认透明，悬浮当前行或键盘焦点进入该行时显示，不改变布局；无悬浮能力的触摸设备保持可见，减少动态效果时取消淡入淡出。

会话和终端并排且使用 Lake Island 时，分界线采用常显的 1px 主题淡灰细线；任务检查卡片使用自己的外边线，栏间拖动热区常态透明、悬停或键盘聚焦时再显示调整线。其余分界线统一从岛下方 76px（Windows 为 124px）延伸到聊天输入框上方 12px，输入框及底部工具栏两侧不画分割线；底端跟随输入框实际位置变化，不再在拖动区域内部额外截掉上下 10%；侧栏和终端的常显细线起止严格一致，检查栏仅在调整宽度时显示热区指示线。栏间保留 12px 宽的透明拖动区域，位于岛下方，避免遮住岛内控件；鼠标靠近时显示左右调整光标，分割线以 160ms 加深，拖动或键盘聚焦时采用主题蓝色，离开后恢复淡灰。取消或结束拖动立即清除活动状态，减少动态效果时取消渐变。方向键微调、Shift 加速、双击恢复默认、无障碍宽度数值与桌面持久化保持有效。检查栏保留最小宽度，窗口变窄时优先保留会话阅读空间。回复正文在栏宽变化时按实际换行高度重新排版，不得与相邻段落重叠；项目侧栏保留原拖动热区，常显同样的内缩分割线，并在悬停、拖动或键盘聚焦时加深。浮岛下各栏的拖动区域使用相同顶部与底部避让，细线的上下端严格对齐；检查栏及终端移除旧的贯穿边框，细线位于栏间边界中央，不产生双线。

各岛桌面视图保留共享字号和 Glyph，不重复“任务检查”标题或专员双行状态。检查栏与聊天区共用原生细滚动条、主题灰色滑块与透明轨道。“步骤记录”标题保持单行并保留完整宽度，长步骤名占用剩余空间并省略，箭头拥有独立列，不把标签挤成竖排。检查栏正文在卡片内独立滚动，顶部不再为外部检查岛保留 72px/112px 空白；计划与执行查看已有记录，不派发操作。步骤继续展示真实状态、独立结果未知提示及原始记录，不能以步骤完成冒充恢复成功。

底部“工作区”采用原位分层：只创建一个固定弹层，首页显示当前项目入口、标签与公共工具；“管理当前项目”收进项目子菜单，与“新建项目”一起固定在列表下方；不再把更多按钮挂在展开列表旁。项目列表、项目管理、新建表单和删除确认都在同一表面换页，顶部提供返回按钮；新建及项目管理返回项目列表，删除确认返回项目管理，项目列表返回首页。Escape 逐级返回，首页再按一次关闭并恢复工作区入口焦点；未显示的页面隐藏且 inert，输入框保留原生文字编辑按键。标签展开状态在页间保留，项目切换继续清空标签与批量选择并导航到该项目最近会话。

工作区弹层与底部入口同宽、左右外缘对齐，底部固定在入口上方 8px；首页按实际内容确定高度，上限 432px，不预留空白底栏；访问子页时保持本次首页高度，低窗口按可用空间收缩，页头与底部动作固定，内容区独立滚动。切换子页不重算锚点或追随旧按钮坐标；拖动侧栏和窗口缩放时跟随入口尺寸更新。外层采用 18px 窗口曲线与单层细边，内部行与输入用 10px 控制曲线，沿用共享字号、Glyph、主题与窄屏规则，不添加嵌套浮层或双轮廓。

分栏浮岛沿用 Pilot 当前行动区，不能因启用独立浮岛而切回普通状态标签。普通状态与 Pilot 区互斥，普通区隐藏时必须 inert；收起、展开任务检查和终端不改变 Pilot 模式。岛宽不足380px时保留专员图标、当前动作、次行说明及末尾进度/结束图标与箭头，省去重复专员名称，文字单行省略；完整专员与状态保留在入口无障碍说明中。首选宽度独立于已压缩宽度，扩大窗口后恢复完整布局。

会话列表每行末尾使用 6px 状态亮点，与更多按钮保留独立空间。普通会话复用 Island 的短状态与主题色（处理中蓝、待确认/需关注琥珀、待命/暂停/停止中性），绿色已结束状态不显示亮点；可用的当前 Pilot 快照复用其行动区色调。悬停及无障碍名称说明状态，不只依赖颜色；亮点保持静止，明暗与窄侧栏均不遮挡标题、标签或更多操作。后台目录更新优先于旧缓存，不能沿用过期任务状态。

发送消息后立即在发送按钮旁显示“正在发送”并使用共享 loader；请求确认后到会话刷新结束显示“已发送，正在更新”。反馈仅属于发起会话，发送期间阻止重复提交；接口失败保留原草稿和附件。已接受消息后的同步失败不恢复已提交草稿，不把发送反馈当作模型已经输出或工具开始执行。减少动态效果时 loader 静止，按钮尺寸保持不变。

从 API 添加模型的搜索框下方，常显独立的“全选当前结果”和“取消选择”按钮及已选数量，使用共享按钮、Glyph 和设置控制圆角。全选仅添加当前筛选中尚未添加的模型，保留其他筛选下的勾选；取消清空全部待添加选择，已添加模型维持已勾选且不可编辑。没有可选结果、当前结果已全选或没有已选项时分别禁用对应操作；窄窗口允许按钮组和计数自然换行，不裁切控件。

工作区菜单展开以 220ms 向上轻移 8px 并淡入，收起以 160ms 回到入口方向并淡出；触发器箭头保留 180ms 旋转。关闭立即设为 inert 并移出无障碍导航，退出动画结束后再卸载，快速反向开关从当前帧连续接续，不闪回、重播或缩放文字。减少动态效果、页面隐藏或动画 API 不可用时直接落位；卸载清理动画。

Lake Pilot 开启后顶部始终保留角色 Logo、真实短状态和执行详情箭头。自动推进/手动选择模式只保留在底部入口及顶部悬停、无障碍提示中，顶部不重复显示 Lake Pilot 名称和两行模式说明。当前轮存在 Pilot 任务时显示既有专员行动区；后续普通对话或尚无本轮任务时显示紧凑的角色入口、真实会话短状态和执行详情箭头，不因任务筛选退回纯普通状态。入口不得复活历史任务的活动专员、进度或结论，历史计划仍由用户主动打开检查栏查看；关闭 Pilot 后恢复普通入口，单栏、多联与窄窗口一致。

Pilot 顶部统一复用 AgentIcon 的角色 Logo。有当前任务时显示真实优先专员；无本轮任务的 Pilot 模式入口使用协调者 Logo，并以“协调者入口”提示区分角色入口与执行状态。角色图标不加圆底或字母替代，普通页眉、独立浮岛和窄栏均保留，优先省略文字。

无本轮专员任务时，Pilot 入口使用单行“角色 Logo · 短状态 · 右箭头”，不再使用状态胶囊底色及重复状态图标；角色区首选宽度收为 100px，不保留原专员两行布局的 238px 空间。有当前任务时仍沿用真实专员行动区。

会话记录距离底部超过 64px 时，在输入区上方居中显示 36px 的玻璃圆形“回到最新消息”按钮，使用共享向下 Glyph。按钮锚定会话内容列，检查栏、终端多联展开时不跨栏；有待发送队列时避让其高度。点击滚到最新并恢复正文跟随，焦点回到会话记录；手动上翻仍保留阅读位置，回到底部后隐藏。没有溢出或切换到短会话时不显示；明暗主题、键盘焦点及减少动态效果保持可用。


普通 core 的长期任务跟踪是内置运行机制，执行详情不展示内部工作账本、工作项卡片、模型调用额度及暂停/继续/停止跟进控件。用户通过正常会话补充条件或停止当前轮次；审批与需要实际回答的问题保留原入口。顶部继续复用七类短状态：外部等待为“处理中”，等待用户为“待确认”，额度暂停为“已暂停”，无法核对为“需关注”；不新增顶部双行文字或影响 Pilot 角色 Logo。只关联当前 RootTurnID 的目标影响当前岛和侧栏亮点，历史后台结果带任务名汇报，不覆盖新话题。

跟踪器自行观察原句柄并在结果到达后接续，完成/失败/取消后释放等待检查点、租约及已结束的临时接续缓存；真实消息、原始操作与观察证据保留，不删除审计记录。等待用户不自动满足前置条件。后台等待释放输入区，实际模型接续仍遵守同会话单执行占用。MCP 服务编辑页使用共享 AppSelect 显式选择可信发布状态适配器，默认不自动观察。

待发送消息每行右侧常显共享向上箭头，与编辑、移除并列。运行中点击“推送到本轮”将选中消息补充给当前任务，若正在等待模型回复则取消仅该模型请求，通过官方 ADK 回调携带真实补充继续同一轮；若工具已启动则等工具返回再接入，不能取消或重复已启动操作。保持当前 RootTurnID、额度和执行记录；其他排队消息及输入框草稿不变。请求成功后恢复输入框焦点，选中消息立即以用户消息显示在当前对话末尾，使用静态“补充已发送 · 等待接入”区分主机收件和模型实际接入；不等模型回执才显示，不播放持续加载图标。该消息从待发送列表隐藏，不能重复推送、编辑和移除；模型回执以同一消息标识替换展示，避免重复。未接入就停止或失败时恢复为待发送消息，保留恢复提示；其他队列项排序仍须携带完整服务端队列标识。空闲或本轮正在结束时不伪造即时接入，消息保留供继续发送。

消息以真实人类输入持久化，SDK 投影提交后才从队列移入对话；重启对照原消息 ID 去重，未接入的补充保留并暂停队列。补充不代替审批/问题答案，不取消已经开始的命令；在新输入到达前生成而尚未派发的后续调用先返回未执行，再由同一官方循环结合新输入决定下一步。正在进行的审批/问题先沿用原确认流程。工作流仍使用原有消息准入规则。
