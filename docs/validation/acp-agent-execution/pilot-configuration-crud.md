## 支持的行为

| 对象 | 范围与操作 | 保持的边界 |
| --- | --- | --- |
| 资源、资源文件夹 | 当前项目的查询、新增、局部编辑、改名、移动、移入回收站与恢复；资源连接复用现有 SSH/服务适配器 | 稳定 ID、目录层级、原任务历史与凭据保留；未交付的连接类型不冒充已支持 |
| SSH | 修改公开地址/端口/账号；显式指定同项目来源时内部复用已有凭据；没有凭据时可先保存 unavailable 草稿 | 模型不读取/填写密钥和私有凭据引用；执行侧仍拒绝未就绪连接；保存不连接 |
| Skills | Lake 全局查询/正文读取、新建、局部修改内容或启用状态、删除，以及注册/移除根目录 | 仅编辑 Lake 管理正文；管理目录移入私有 `.trash`，导入项只解除注册，不覆盖或删除来源文件；删除名同时停用，避免旧 reader 或同名来源误启用 |
| MCP 服务 | Lake 全局查询、新增、局部修改、启停和删除 | 省略公开字段、headers/env 时保留；不在模型工具中接收认证值，CRUD 不自动连接或启动进程 |
| MCP 项目绑定 | 显式测试保存的连接、分页查看真实工具目录，再向当前项目启用/停用指定工具 | 沿原版本和目录检查；省略工具列表保留旧范围，首次启用须明确列表，空数组明确表示全部；不修改全局继承或安全策略 |

资源 HTTP API 与 Pilot 复用 `resource-management.ts`，继续使用原 SSH、服务及目录写入器。专员、Worker、child 和 ACP 不注册这些控制工具。配置由 Pilot 直接处理，不为纯配置操作制造业务任务、操作证据或验收。

保存校验当前完整人工 event、准确原文、当前项目/对象 revision 与稳定 part。保存前写入 `pilotConfigMutations.pending`，成功后保存脱敏回执；同一 part 参数冲突拒绝，未确认的文件/网络提交在重启后不自动重放。文件与 SQLite 是独立事务域，失败可以留下需核对的结果，不能视作跨域原子成功。

读取、保存与显式连接测试分别沿用 Pilot 当前 silentReadFiles、silentWriteFiles、silentMCPCalls；Plan 只查询。资源删除仅排除当前准确配置事件与 Router 的占用，其他活动 Worker、未处理输入或终端仍阻止删除。
