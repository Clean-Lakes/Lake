## 布局与行为

右栏改为有外侧留白的悬浮卡片，计划 / 执行页签、文档 Glyph 和关闭按钮全部在卡片内部顶部。去掉独立检查岛、门户挂载点及对应的顶部留空；保留会话和终端浮岛、终端分出动画、分栏尺寸预算和调整热区。卡片使用共享窗口曲线、主题轻玻璃、单层边线和轻阴影；短内容自然收缩，长内容仅内部正文滚动，页签不滚走。

## Dev 原生验收阻塞

构建开始时旧版本覆盖保护发现其他工作区已更新 Security，因此先在本地集成准确的已安装来源再构建，未覆盖该更新。用户正常重开后原生应用显示“后端无法启动”。只读核查确认没有 Dev 后端持有 Home 锁、runtime.json 不存在；`lake security status --home ~/.lake-dev` 返回 `gate=closed`、`storeReady=false`，并存在 `security/legacy-inventory.pending`。当前安装的 Security 基线要求该历史迁移由管理流程恢复，不能靠 UI 分支清除标记或重开门禁。

因此本次已完成签名安装及浏览器布局验收，但未宣称卡片已在真实 Dev 窗口显示。未修改控制文件、清理门禁、回退存储或停止其他后端；正式版未操作。Security 恢复完成后仍需补充 WK 原生角线、点击与原生窗口拖动验收。
