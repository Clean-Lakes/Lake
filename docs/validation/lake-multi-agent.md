# Lake 多 Agent 首版实现

2026-10-12，本地实现，未提交、未推送。

已实现 Lake 主协调器，以及 Scout（主机）、Trace（应用日志）、Deep（数据库 / Redis）、Beacon（独立验证）的真实子会话。通用运维默认按需启用，可在会话配置中关闭。网络、变更分析、处置规划和复盘只预留名称与图标，未作为可执行角色开放。

## 执行与隔离

- `delegate_investigation` 同步等待一批独立子会话：最多三个调查任务并行，可附加一个等待调查完成后执行的验证任务。主 Agent 的消息历史不复制给子 Agent，只提供原始问题、明确目标、资源范围及有界交接。接口接受最多 16 KiB 的交接内容，模型实际接收最多 4 KiB；原始问题也裁切到最多 4 KiB。子 Agent 使用专用提示词，避免携带主 Agent 的完整工具说明。
- 每轮最多八个子任务，保留一个验证名额。服务端最多六个执行实例、三个子 Agent 模型请求，并有四个共享模型请求槽，为主 Agent 保留容量。子任务总期限 120 秒，单次模型请求 45 秒，观察操作 10 秒。
- 子 Agent 最多十二次工具调用，每个子 Agent 对每资源最多两次观察，同一资源最多两个观察操作并行。模型上下文窗口最多 16K，单次输出最多 2048 tokens。观察摘要传入模型最多 4 KiB，验证阶段的原始证据摘要合计最多 8 KiB，详情保留每条最多 16 KiB 的脱敏记录。用量预算按请求前的保守估算控制：单任务 32K、单轮委派 128K。估算不是账单金额或服务商准确计费承诺。
- 工具范围由服务器执行控制。调查角色没有任意 Shell、任意 SQL、Redis 写操作、文件写入、终端输入或继续委派工具。父会话的资源引用限制、禁用本机执行、文件和 SQL 读取权限继续生效，并在实际执行前再次核验。
- Scout 使用固定指标模板，通过短暂的非交互连接采集；不会使用用户的交互终端。主机概览包含相隔一秒的 CPU 样本；进程列表使用 `ps` 生命周期平均 CPU 并按占用排序，不能混作瞬时 CPU。
- Trace 读取指定 `.log` 文件或 `/var/log` 日志的末尾最多 200 行，拒绝凭据路径和链接文件。Deep 只读取固定的数据服务健康、连接和活动指标，数据库事务保持只读。

## 证据与恢复

观察证据的 ID、所属资源、时间、结果和退出码由服务器登记。没有成功观察，或者报告缺少有效证据引用时，任务标记为未通过核验。Beacon 只获得原始用户问题和登记的原始证据，不接收其他 Agent 的候选结论。Lake 的候选回复保留为私有草稿，经过验证任务后再生成最终回复；验证失败或用户停止验证会作为任务状态明确保留。

父任务记录保存在现有 Go 引擎的私有状态文件中；子任务历史保存在 `ai/children/<父会话>/<任务>.json`。目录权限 0700，文件权限 0600，沿用现有脱敏与原子写入。这里采用现有文件状态存储实现首版，没有新增 SQLite Agent 表；该点不同于完整架构方案的后续存储设计。

重启后，未结束的任务标记为中断，撤销待处理审批和取消能力，不自动重放命令。取消、审批与详情接口均核验父会话归属：`cancelAgent`、`agentDecision`、`agentDetails`。整轮停止通过父上下文取消所有子任务。

## 界面

采用已确认的紧凑任务列表。Lake 使用波纹图标，子任务使用固定职责图标，名称旁展示目标资源、状态和结果。多个相同角色按资源区分实例；状态另用旋转标记、时钟、勾选或停止标记表达，完成后保持图标与文字颜色。

点开任务可查看目标、耗时、工具次数、已记录证据、用量和结果。允许单独停止真实执行任务、停止整轮，并在任务旁处理审批。证据引用显示为可读的“证据 1”等标签。普通工具操作继续显示为 Lake 的操作，不生成虚假的子 Agent；旧专员记录保留兼容展示。

## 验证

- 引擎并发测试使用两个真正的模型请求同步屏障，验证并行和独立历史，而非仅检查卡片数量。
- 覆盖独立验证不接收候选结论、证据登记与引用核验、单任务取消、整轮取消、审批隔离、跨会话访问拒绝、调用范围限制、只读 SQLite 指标、重启不重放及私有文件权限。
- HTTP 集成测试验证子任务审批、详情、归属拦截和独立验证完成后的快照。
- 浏览器验证运行签名后的 `bin/lake`，使用临时数据目录与本地模型夹具。实际同时显示 Scout 和 Trace；点击停止 Trace 后 Scout 完成、Beacon 继续验证。没有连接生产 SSH、数据库或远端模型，临时服务和数据已清理。
- 浏览器检查 736、480、320 像素宽度，任务列表无横向溢出，无运行时错误。截图保存在本次任务的预览目录。
- 前端测试、TypeScript 检查、Go race 检查及 `scripts/build_lake.sh` 的签名构建用于最终验证。构建不替换或重启用户正在运行的客户端。

完整检查还恢复了消息队列重构后的附件校验：显式空图片数组和非对象图片数组不能进入模型执行队列。未修改消息队列的正常调度行为。
