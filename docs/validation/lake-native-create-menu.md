# macOS 创建菜单修复（0.3.1）

2026-10-12，在原生 WKWebView 客户端中复现：打开“新建”后点击“新建目录”，菜单消失，但输入框没有出现。菜单打开时会主动聚焦第一个按钮；Safari 的鼠标按钮激活先将焦点移到 body，触发父级 blur 关闭菜单，从而在 click 到达前卸载按钮。“新建资源”有同样问题。

修复保留菜单的鼠标焦点直到 click 执行。React 菜单处理主键 mousedown；原生客户端为复用旧 Go 服务所提供的页面注入同一焦点保护，范围仅限创建菜单项。Tab 离开和 Escape 关闭仍使用原来的规则。更新客户端可保留独立启动的 Web 服务。

实际验证：

- 在既有 Web 服务的页面上，鼠标点击“新建目录”后目录输入框、保存和取消按钮出现；点击“新建资源”后 SSH/数据库/Redis/Docker 表单出现，没有保存任何生产资源或目录。
- 在单独临时数据目录中，通过界面创建测试项目，鼠标打开并保存目录，目录出现在资源树。
- 通过 Return 从菜单打开资源表单，选择 Redis，保存仅含本机测试地址的资源，资源出现在项目资源树和详情页；未连接 Redis 或发送远程命令。
- 51 项前端测试通过，TypeScript 检查、React 生产构建和 Swift arm64 构建通过；应用和内置 CLI 均通过持久 Lake 本地证书签名及深度验证。

发布使用临时资产标签触发流水线，发布成功后自动清理标签，不再创建临时发布分支。安装包仅含 Apple Silicon arm64。
