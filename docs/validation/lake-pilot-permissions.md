## 行为

- 项目长期角色频道与普通任务 Worker 使用当前 Pilot 的八项权限设置。旧频道/Worker 自有配置不再成为权限来源，其他模型、目标与轮数设置仍按任务保存。
- 专员输入区移除“权限”按钮，服务端拒绝专员独立修改权限；Pilot 面板说明其设置作用于本项目专员。
- 新增默认关闭的“调用 MCP 工具”。在原宿主继承策略下开启后，项目 MCP 调用直接执行；明确项目策略、Plan 执行限制、引用资源与本机限制继续生效。MCP 不被改判为只读。
- 准备操作同时冻结 Pilot 来源与权限版本，评估和实际执行均重验；来源或版本变化使旧提案失效。旧已提交回执保留原会话权限快照，不将旧待确认卡片伪造为批准。

## 权限与回退

当前用户仅授权在正在使用的 Dev 项目开启 MCP 自动执行；其他项目不开启，既有全局 MCP 继承选择不变。开启意味着该项目已启用 MCP 的读取和变更工具都受此偏好控制，明确项目策略仍优先。

无需修改数据库结构。权限 JSON 新增布尔值，操作描述符增加可选权限来源字段；不重写历史操作与审批。关闭 Pilot 的 MCP 开关即可恢复后续操作确认。旧程序不能执行带新来源的操作快照；回退应先停止新任务，再关闭开关并核对未决操作，不能用旧二进制继续执行新描述符。
