# 真实上下文比例、只读嵌套查询与统一发送/停止按钮

2026-10-11。

上下文使用最近一次服务商报告的输入 token 数，窗口来自同一模型的 models 元数据（context_length/context_window 等），与 64K 压缩预算分离。新请求完成后更新；缺少输入计量或窗口数据时显示 --，不采用长度估计冒充实际占用。模型切换时隐藏旧模型计量，配置切换模型后清除上次请求测量。容量元数据在服务端缓存，配置更改时失效，模型 ID 绑定到端点、名称和协议。

实际配置端点 http://127.0.0.1:3425/v1 的模型列表返回 deepseek/deepseek-flash 上下文 1000000。实际保留会话的最近输入为 22636，因此比例为 2.2636%，显示 2.3%。这是已报告请求的计量，不是对正在生成请求的即时测量。最近输出 186、缓存命中 10752；累计记录与当前上下文分开展示。未对真实会话新发起商业模型请求。

静默查询误拦截源于把所有命令替换 $(...) 都判为危险。引入 mvdan.cc/sh/v3 语法分析，对整个脚本、管道及每个嵌套命令逐层验证。允许纯查询的局部变量、启动时间 sysctl、只读 sed 替换、date 格式化与显示参数；通过 command -p 解析标准程序，动态结果不能变成可执行程序或任意文件路径。重定向写入、执行型 sed、嵌套文件写入、读取凭据等仍不能被升级为只读。原命令/终端/资源的执行与授权绑定保持不变。截图中的完整启动时间查询在隔离本机 PTY 中执行成功，没有命令授权弹窗。

输入框右侧统一按钮：待命为发送箭头，运行中、等待授权或 Agent 终端忙碌时为停止方块。旧停止本轮按钮从上方工具栏移除。点击停止调用原 abort 操作，停止后恢复发送；停止不会删除会话，正常取消显示“已停止本轮”。

验证：
- 13 个前端测试通过，覆盖真实输入/真实容量、未知数据、报告为零与切换模型时不复用旧比例。
- Go web/ai 完整 race 测试通过（web 98.148s，ai 缓存已通过），Go vet 通过。
- 回归覆盖完全只读嵌套命令实际执行、开启或关闭静默执行均无查询确认、混入 touch/删除/凭据访问的负例、模型元数据缓存和容量与预算分离。
- 浏览器隔离会话验证 30.8K / 1M => 3.1%、未知模型显示 --；发送后唯一停止按钮位于 composer，停止流式模型回复和等待终端创建授权均成功，停止后恢复发送。
- macOS scripts/build_lake.sh 签名构建、严格签名校验、无 Node 运行测试通过。
- localhost:4177 更新并验证实际上下文 22.6K / 1M => 2.3%，嵌入资源 index-DTChjwD8.js。启动为独立进程，stdout/stderr 写入私有 web.log。
