## 已交付

- 在同一对话展示协调者、调查员、执行员、验证员的真实角色运行和阶段产物。旧子 Agent 记录保留原身份，未启动角色没有占位发言。
- 内嵌 Plan、草稿模式、不可变修订、步骤状态、暂停／继续／结束、事件记录与历史分页。活动记录支持任务筛选，待确认和结果不明的事实保持可见。
- 四个最大 22px、无背景的湖生态 SVG，明暗主题使用共享变量；确认卡片为纵向紧凑样式，保留精确动作、影响、停止条件与原审批路径。
- 任务、版本、运行、步骤尝试、消息、验证与事件持久化。状态与现有 `session` 通知同事务保存；迁移已有项目库前创建私有 SQLite 备份。
- 冻结工具与参数，操作派发前持久登记，同资源写操作串行。审批拒绝不会执行动作；即使模型声称成功，执行员的可见结果也由服务端派发事实计算。
- 已成功操作不因报告失败、重启或相同动作的计划修订而重放；未知结果阻止继续与改参。人工核实保留来源、依据和时间，不能代替独立验收。
- 验证员独立上下文、固定只读探针、新采样时间、阈值／布尔类型、样本数与观察窗；缺数据为 inconclusive，失败为 failed。文件写入和命令退出不作为业务恢复指标。
- `@专员` 路由当前／最近结束任务的解释性追问；不新增操作步骤，继续计算任务累计预算。保留资源／Skill／MCP 的引用身份与队列行为。
- 显式 JSON 手册草稿导出、旧只读工作流的 API 导入；开关按项目保存，默认关闭。

## 隔离运行与视觉检查

独立 home 位于 `/tmp/lake-sre-ui-20261016/home-*`，动态 loopback 端口；模型为本地合成 SSE provider，没有配置或复制真实模型密钥。签名 `bin/lake` 实际读取本地演练日志、等待审批、写入临时标记，并由另一角色运行重新采集本机磁盘快照。
