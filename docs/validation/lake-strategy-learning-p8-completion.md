## 真实执行与效果

使用用户已有 Dev 配置的 DeepSeek deepseek-flash，reasoning=low、context=64000、actor maxOutput=1024（无工具提案/合成上限 2048）。不复制凭据，不读取正式 Home 或 Keychain。provider 响应没有被替换；提供方版本从实际响应记录，seed 未暴露，费用未取得报价，不换算金额。

共冻结 16 个实际隔离案例，13 开发、3 保留：端口占用、配置缺失/解析、SQLite 只读/缺表/唯一约束、文件权限、瞬时断连、拒绝连接、HTTP503、普通写作、不可信日志、删除但仍打开的文件、退出容器、SSH 认证失败、工具缺失。宿主设置故障、验证初始断言并负责清理；模型只有准确命令或一条固定只读观察接口，不能执行任意 Shell/SQL。Docker 使用已存在的固定镜像 ID、禁网、只读文件系统、64MB 内存、无用户卷；SSH 为临时服务器与合成身份、固定其 host key。未访问生产资源。

16 个案例各有一次基线；端口占用、数据库只读、瞬时断连另做 A/B/C 每臂三次，顺序 ABC/BCA/CAB。每次独立 Home/ADK session/复位 nonce，Skills 与记忆均为空且 hash 一致，B/C 采用同一人工确认方法正文。保存实际答案、检查、调用、token、耗时、reset proof、prompt manifest 与纠错卡；失败不会删除、替换或另取最好一次。

M2 真实执行链以实际独立 SQLite 连接跑“基线开发→无工具提案→提案开发→无工具合成→合成开发→基线保留→合成保留”。五个变体和两次辅助共用最多 12 请求、100000 token、6 变体、600 秒；没有每阶段重领预算。保留数据库使用独立 URI mode=ro，开发数据库用 query_only，复位后检查写入确实失败且记录未变。提案/合成只接收开发答案与行为，不含隐藏评分或保留集。结果不自动保存或采用。

真实环境阶段由 opt-in 验收宿主编排，复用官方 ADK Actor 与无工具提案接口；没有宣称实时环境已接入产品 Web P6 协调器。产品 P6 的持久化、恢复、取消、血缘及共享预算由既有无凭据回归另外验证。

这些样本完成了真实执行与比较，不证明跨模型/生产通用提升。M2 生成候选的真实优化只验证数据库任务族；另外三类保留案例的全量诊断基线不能被说成该候选在全部保留案例上获胜。正式 UI 的实验仍为合成快照；LiveRead 是宿主专用测试入口，没有通过 HTTP/模型开放。

## 失败与停止

保留先前所有预跑：Docker 短标签解析失败、实时复位证明与占位文件 hash 错配、普通任务用量误用新增纠错预算、共享目录切分支导致中断。它们不并入最终冻结样本做收益计算。修复的是执行/计量协议；固定答案检查、权限和产品预算未放宽。窗口定位失败、Windows CRLF golden 失败也保留 CI 链接与原始元数据；通过 LF 属性修复跨平台字节，不重写 golden 值。

最终结论以原始 JSON 为准。inconclusive/没有胜出候选是有效结果；推广/自动采用保持关闭。
