# Mini Box 验证记录

验证日期：2026-10-24。分支 `codex/mini-box`，基于 `origin/develop` 的 `49570605`。准确已测试 head SHA 记录在 PR 验证证据中；真实远程 SSH 的完整验收仍未完成。

## 行为

- 每个明确的本机或 SSH 资源复用一个 720px 最大宽度、144px 固定高度的会话内终端；窄窗口只收宽，输出内部滚动。使用真实 xterm 呈现命令块，保留按需展开的原始记录。标题按真实资源类型显示“本机”或“SSH”，不从命令内容猜测类型。
- Lake 中性磨砂材质，内缘极淡蓝色颗粒缓慢移动；无外扩光晕或窗口覆盖层。等待确认、断线及结束停止，减少动态效果时静态，后台页面暂停绘制。
- 终止 API 绑定 terminal ID、generation、entry ID 和命令所属会话。服务端在同一个 live-terminal 锁内验证并发送 Ctrl-C，旧按钮和跨会话请求不能终止其他命令。
- 持久化停止请求，AI 观察到 `userStopped` 及禁止自动重试的说明；在下一条用户消息前阻止同资源相同命令重试。其他资源独立继续。停止请求不等于已成功结束，结果未知时提示核查，回合结束保留资源级通知。

## 浏览器验收

通过 ego-browser 使用真实 `AITranscript` / `ThinkingTimeline` / `TerminalPane`，页面为 `web-agent/web/test/fixtures/mini-box.html`。资源、模型和 fetch 响应全部虚构，不连接真实主机。

- 明暗主题：两框均为 720 × 144；检查窗口曲线、材质、悬停及键盘焦点，文字清晰。
- 390px 视口：两框均为 268 × 144，页面 scrollWidth 为 390，无横向溢出，终止按钮可见。
- 点击第一个终止：只发送 terminal-0 / generation-0 / entry-0 的 POST；第一个显示“用户已终止 · 结果待核查”，另一个保持运行且继续追加输出。尺寸不变。
- 会话结束：无活动颗粒，正文保留仅涉及被终止资源的通知，执行详情按既有规则收起。
- 断线：保留已有可读记录，禁用终止及活动颗粒。权限 403：清除实时历史及终止目标。
- 切换会话与延迟历史响应：新会话不显示旧命令输出，不保留可用终止目标；原始手动屏幕文本不进入 Mini Box。
- `prefers-reduced-motion: reduce`：跨输出更新比较 Canvas 数据相同，颗粒静止；正常偏好下缓慢流动。

## 本机接入补验

用户要求本机也接入后，Mini Box 复用本机已有命令块、只读输出、按资源绑定的终止 API 和回合通知。仅将主机范围扩展为 `local` / `ssh`；Kubernetes API、主机检查等非命令操作保持原视图。命令派发时展开一次，避免短命令在快照捕获 busy 前结束而始终折叠；用户手动开合不被后续输出覆盖。

- 类型检查通过，前端 449 项通过，无跳过；新增组件回归覆盖本机/SSH 的标题和终端视图、其他资源及非命令工具不误触发。
- `go test -race ./internal/web ./internal/ai -run 'TestMiniBox|TestMiniSSHStop' -count=1` 通过，后端既有真实本机 PTY 的终止隔离与模型观察路径继续适用。
- 浏览器 `mini-box.html?local` 同时展示本机与 SSH。点击本机终止只发送 terminal-0 / generation-0 / entry-0；SSH 输出继续追加，两框固定 144px，回合通知只包含 Local machine。
- 暗色 390px 视口无横向溢出，本机终止按钮保持可见。更新后的 Dev 构建来源及原生回看结果记录在 PR 验证证据。

SQLite 通过现有 backup-first 迁移流程新增可空 `terminalEntries.stopRequestedAt` 列。API 使用原有终端访问控制，未新增宽泛控制能力。Ctrl-C 沿用现有未知结果/恢复语义，命令可能忽略中断；界面与模型均不得将请求成功解释为业务成功。回退应用代码即可移除新 UI/API，新增可空列可保留；如需恢复数据库，使用迁移前备份并核对备份后的会话记录。
