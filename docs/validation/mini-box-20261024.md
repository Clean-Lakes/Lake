# Mini Box 验证记录

验证日期：2026-10-24。分支 `codex/mini-box`，基于 `origin/develop` 的 `49570605`。准确已测试 head SHA 记录在 PR 验证证据中；真实远程 SSH 的完整验收仍未完成。

## 行为

- 每个明确的本机或 SSH 资源复用一个 720px 最大宽度、144px 固定高度的会话内终端；窄窗口只收宽，输出内部滚动。使用真实 xterm 呈现命令块，保留按需展开的原始记录。标题按真实资源类型显示“本机”或“SSH”，不从命令内容猜测类型。
- Lake 中性磨砂材质，内缘极淡蓝色颗粒缓慢移动；无外扩光晕或窗口覆盖层。等待确认、断线及结束停止，减少动态效果时静态，后台页面暂停绘制。
- 终止 API 绑定 terminal ID、generation、entry ID 和命令所属会话。服务端在同一个 live-terminal 锁内验证并发送 Ctrl-C，旧按钮和跨会话请求不能终止其他命令。
- 持久化停止请求，AI 观察到 `userStopped` 及禁止自动重试的说明；在下一条用户消息前阻止同资源相同命令重试。其他资源独立继续。停止请求不等于已成功结束，结果未知时提示核查，回合结束保留资源级通知。

## 出现时机与最终回复过渡补验

实际主机检查先通过 `inspect_host` 执行 uname、uptime、top 等终端命令，原先仅识别后续 shell 导致 Mini Box 出现较晚。现将主机检查纳入同一只读终端视图，在派发渲染时展开，取消该活动终端行的延迟入场；历史尚未返回时已有终端框与运行提示，准确句柄返回前不开放终止。检查中终止当前命令后退出该检查批次，保留已收到的检查结果并通知模型。

最终回复原先在运行期间被归入资源阶段，完成时才切换到主正文。现将工具之后最新一段正文直接留在主回复，停止更新过程综合摘要；生成、追加及结束均复用同一 DOM 节点，只有后续工具调用才确认此前回复为中途播报。

- 类型检查与前端 451 项通过；覆盖派发时的终端呈现、主机检查接入、流式最终回复的保留及过程/正文活动标记的唯一归属。
- Mini Box Go/race 回归通过。新增 macOS 原生主机检查测试在 top 采样仍运行时读取 HTTP snapshot，确认 running 检查卡已可见，再终止该命令；模型收到 userStopped，后续内存检查未派发。其他平台不运行依赖 macOS top 的此项用例。
- 浏览器 `?local&inspect&delay` 将历史响应延迟 1.2 秒，响应前两框均已出现，活动行无入场动画。
- 流式最终回复最初就在主正文，追加和完成后回复外层与内容卡 DOM 身份均不变，过程区没有最终回复副本，完成时无入场动画重播。
- 暗色 390px 视口 scrollWidth 等于 390；签名安装、原生工作台启动及来源 SHA 补充到 PR。

## 先清场、后输出的顺序切换

用户进一步明确要求“要输出总结时先优雅清空过程，再优雅输出”。此前只保持最终回复节点稳定，仍与过程收起同时显示；本轮改为严格分阶段：冻结退出中的过程视图，立即开始淡出和收高；在旧过程高度归零前缓冲总结，不挂载其正文。退出后以 240ms 的整块淡入、6px 位移及裁切展开显示总结，不叠加原回复入场动画。

过程关闭发生在总结开始时，而非等待整轮完成。退出期间收到的流式内容继续保留；即使模型很快结束也不会提前显示或丢失缓冲文字。若模型随后再次调用工具，取消等待并恢复过程。减少动态效果、后台页面和恢复历史不等待或重播。冻结仅覆盖退场时间，随后释放实时子视图，避免持续保留旧运行状态。

- 类型检查及前端 451 项通过，保留原始播报、失败/停止和普通回答的回归。
- 浏览器逐帧记录：首个可见总结出现时旧区域高度为 0，旧过程与总结同时可见的帧数为 0；切换期间追加文字完整保留，入场仅一次，完成后不替换正文节点。
- 快速完成场景同样先收空过程，已结束的完整总结保留；工具恢复场景取消等待并重新打开执行区域，不将中途回复标成成功总结。
- 减少动态效果约 58ms 内显示，无等待或动画；恢复历史直接显示、无动画。暗色 390px 无横向溢出。
- 签名安装及确切 Dev 来源提交补充到 PR；本轮未改变模型请求、SSH 或终止语义。

SQLite 通过现有 backup-first 迁移流程新增可空 `terminalEntries.stopRequestedAt` 列。API 使用原有终端访问控制，未新增宽泛控制能力。Ctrl-C 沿用现有未知结果/恢复语义，命令可能忽略中断；界面与模型均不得将请求成功解释为业务成功。回退应用代码即可移除新 UI/API，新增可空列可保留；如需恢复数据库，使用迁移前备份并核对备份后的会话记录。
