# 待发送消息推送为本轮补充

2026-10-29，PR #120 的增量修复。用户确认需要“补充”当前任务，不是停止本轮再发新消息。

实现：队列增加有 revision 校验的 push 操作，绑定当前真实 RootTurnID。共享向上 Glyph 提供入口；推送中禁用重复操作，保留其他队列项和草稿，焦点回到输入框。运行中的官方 ADK 在压缩后、下次模型请求前或当前工具结束后的安全步骤接入。旧模型响应中尚未执行的提案返回 not_executed；内部控制调用只留 SDK 事件，不混入供应商工具目录或伪造人类回答。操作审批、已执行命令和模型额度均保留。

不新增模型循环或数据库表。待补充标记存于现有私有队列 payload；真实输入及原消息 ID 进入 canonical SDK 投影后才确认移除队列。重复回执无副作用。重启先核对 canonical 回执；未接入的内容保留并暂停队列，不能自动作为新一轮执行。当前步骤尚未开始、正在结束或运行工作流时，拒绝本轮推送并保留原队列。正在进行的审批/问题继续原确认流程，补充不充当答案或批准。

已执行验收：

- HTTP/SDK：选中单条补充，原 RootTurnID/Turns 不变，主模型最多一个并发，过期 revision 拒绝，其他排队内容不变；旧写入提案未执行，消息仅作为真实 user 保存一次，重复回执不重复写入。
- 当前工具在途：原读取完成，后续旧写入被拦截，模型依据补充继续；不重放原读取。
- 压缩中途：补充在摘要结束后的下一次主模型请求出现，原任务不重启；删除 JSON 缓存后仍可从 canonical SDK 恢复回执。
- 停止：尚未接入的补充保留在暂停队列，没有伪装成已发送。
- 新增 AI/队列用例连续两轮 race 通过；既有前端 555/555、类型检查与构建通过，ADK 边界检查和 vet 通过。
- ego-browser 实际组件验收：浅/深色、键盘 Enter、推送状态、接入后仅移除选中项、空闲禁用、草稿及焦点保留；420px 无横向溢出、控制组不越界，减少动态效果时 loader 静止。截图 `/tmp/lake-supplement-light.png`、`/tmp/lake-supplement-dark-narrow.png`。只使用虚构队列/API，不操作真实发布任务。
