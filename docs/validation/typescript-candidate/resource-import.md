## 行为与边界

- 恢复认证 UI 的 POST `resource-import-preview` 和 `resource-import`，沿用现有预览行与计数合同。支持 JSON、HexHub v2/v4 结构导出、含表头 CSV/TSV，以及明确的 SSH Host 配置；不接模型推断循环或 Go 回退。
- 本机 HexHub 先使用公共 MCP 客户端读取 `list_assets`。只从唯一当前 Chromium assets 存储读取匹配登录信息；当前 manifest、SST、WAL、sequence 和 tombstone 决定有效值。CRC、Snappy、V8、文件稳定性、所有权与数量/大小限制均有检查。不开库、恢复、锁定、搜索陈旧文件或读取其他对象存储。
- 登录资料须唯一匹配名称、目录、种类/驱动、主机和端口。保存的密钥/密码对引用优先，失效引用不回退旧内联密钥；不支持的代理、数据库 TLS 配置及 Redis 集群模式明确报错。本地资料不可读时准确返回仅清单提示。
- 预览只准备当前 Home 下 0700/0600 文件，不连接现场，不创建资源。计划仅含准备后的配置引用、文件指纹、项目/策略绑定及 30 分钟期限，响应/SQLite/事件不保存原始密码或私钥。
- 提交先验证选择、归属、策略、源清单/登录变更、文件指纹、现有配置和活动任务/终端，再用单个事务写入资源/目录/版本及重放回执。完整连接跳过；唯一缺少登录信息的连接保留 ID、名称、目录、历史、数据库/TLS/Shell 等其他设置。重复行、重放与并发提交不新增重复资源。
- 新资源身份不匹配空端点。无密码但配置完整的可用数据库视为完整连接，不覆盖。导入不更改旧策略 `ResourceIDs`，不颁发 Worker 授权，不做现场探测。
