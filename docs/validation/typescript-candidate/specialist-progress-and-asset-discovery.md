## 问题与修复

实际 Dev 的失败调用没有触发权限拒绝：136 个资源的 `list_assets({})` 返回为 38,175 字节，超过工具 16,384 字节上限。模型收到截断 JSON，重复读取仍无法取得目标连接版本，最终没有调用 SSH 检查。此情况不证明服务器无法连接，也不应通过放开权限解决。

- `list_assets` 支持准确 `asset_ref`、中文名称 `query` 和分页；默认 20 条，最多 50 条，实际 JSON 每页最多 8192 字节。返回 `total/hasMore/nextCursor`，游标绑定项目、查询和目录版本。同名资源保持独立，完整保留 ID 和当前配置版本；连接参数和凭据不进入模型目录。单个损坏的旧连接不阻断其余资源。
- 专员快照增加临时 `activity`。工具活动只在 SDK 权限允许后的 started 事件开始，成功、错误和结束清理；并发调用分别追踪。审批、主机指纹、计划与问题按当前真实交互显示，排队必须满足实际调度条件。
- Pilot 对应回复下显示专员名称、当前行动和任务，点击进入准确专员频道。已交付输入确定活动归属；尚未交付的续问、另一频道来源或已裁剪的原问题不误挂到最新问题。没有实时活动的历史状态不产生动画。
- 思考和实际工具调用沿用水波与文字扫光，排队、确认、问题、外部等待保持静态；结束移除活动行，显示实际结果。顶部聚合专员活动，Pilot 自己回复结束不会使仍工作的专员显示“已结束”。断线或进度刷新失败停止动画。
