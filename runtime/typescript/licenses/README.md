# Pinned supplementary runtime attribution

`parse-bmfont-ascii-1.0.6-LICENSE.md` is copied verbatim from the package release v1.0.6, commit `5f22b037ae7460f629dd681db23cd9b543a76b06`:

https://raw.githubusercontent.com/mattdesl/parse-bmfont-ascii/5f22b037ae7460f629dd681db23cd9b543a76b06/LICENSE.md

The published npm package refers to this file but omits it. The bundle includes the pinned text without requiring network access at build time. Type-only and other unbundled dependencies are excluded using the esbuild input manifest.
