# Lake 产品语言与河狸

## 产品规则

- Lake 是应用对用户展示的产品名；桌面与 Web 的主要入口、提示、设置、菜单、帮助、错误说明和可访问性名称不再以 ZCode 自称。中英文界面同步：`ZCode` → `Lake`，`ZCode Agent` → `Lake Agent`；专有的第三方名称、模型名和实际服务地址不伪造为 Lake。
- 所有子智能体在产品界面统一称为「河狸」（英文 `Beaver`），包括内置、用户自建、工作区、插件及动态工作流中的子代理；来源可分别标为「内置河狸」「用户河狸」「工作区河狸」「插件河狸」。两个内置角色分别显示为「通用河狸」/`General Beaver` 和「探索河狸」/`Explore Beaver`；用户与插件创建的专有名称不改写。
- 「河狸」是子智能体的展示语义，不是湖中的资源类型，也不加入湖资源目录。主 Agent、任务、会话、资源、SSH 的所有者和生命周期不因改名而改变。
- 河狸使用一枚可复用的单色河狸头像图标：圆耳、宽吻和两颗门齿构成小尺寸识别特征。图标继承当前文字颜色，适配明暗主题；它是装饰性图形，名称仍由文字与可访问名称表达。插件的独立品牌图标仍可保留。
- 运行时内置 ID `general-purpose`、`Explore`、Subagent API、插件 profile、会话关联、协议字段、包名、环境变量、磁盘路径、URL scheme 与既有数据键保持原样；不执行破坏性的重命名或迁移。
- 帮助文字中如需说明仍保留的 `.zcode` 路径、`zcode://` 链接或上游域名，必须显示其真实值，不能把真实路径伪装成 `.lake`；产品名与技术定位符分开表达。

## 所有者与接口

```text
运行时内置 agent ID / 现有 SubagentService（不变）
    → UI 展示映射 + zh-CN/en-US 文案（Lake/河狸）
    → 设置页、输入建议、运行视图、插件与资源说明、辅助功能标签
```

- 用户可见文字以 `packages/ui/src/i18n/locales/` 为主要所有者；桌面 Main 的本地化文案仍由原有菜单/弹窗模块持有，不新增第二套状态。
- 保存模型覆盖、启停与任务执行仍使用原 ID。显示名称不写回 Markdown、数据库或协议。
- `/` 输入建议中的河狸分组由 UI 展示层使用候选项的本地化 `label`；选中后仍以原 `value` 插入和调用。内置角色的专有显示名仍由现有 mention 候选提供者映射，不另存名称状态；用户或插件自定义名称保持原样。
- 河狸图标由 `packages/ui` 的共享矢量组件持有，`/` 候选项和设置页根据现有子智能体类别渲染，不增加协议字段或持久化配置。图形缺失时仍显示名称与可操作行；当前 `@` 面板不提供子智能体候选项，不为图标扩展它的功能。
- 中文与英文的用户可见标题、操作、空态、提示、运行状态及错误说明统一使用「河狸」/`Beaver`；保留代码键、API、工具名、文件路径、用户自定义名称和实际 transcript 等技术定位符。缺少翻译时不写回或迁移旧数据。
- 新旧窗口同时存在时各自使用其安装版本文案，不做数据迁移；回退旧版本仍能读取同一配置。

## 验收场景

1. 新建任务输入框、欢迎/登录、设置与菜单中的应用自称为 Lake；中英文切换一致，不出现可见的「向 ZCode 提问」。
2. 设置 → 河狸中，内置分组显示「内置河狸」，两张卡显示通用河狸与探索河狸；用户/工作区/插件来源也用河狸语义，工具范围和只读含义仍清楚。
3. 搜索、模型覆盖与运行内置角色仍使用原有稳定 ID；已有会话及覆盖配置不因显示改名而丢失。
4. 用户自建和插件提供的河狸保持自己的专有名称及来源分组，不被误标为「内置河狸」。
5. 实际 `.zcode` 路径、`zcode://` scheme、包名与协议字符串在诊断/路径展示中保持真实；只改变产品自称，不误导用户复制错误路径。
6. Desktop 与 Web、窄屏与宽屏、中文与英文均能显示新名称；可访问性名称与可视名称一致。
7. Web 会话分享页在 Lake 下载地址未配置前不展示指向上游 `zcode.z.ai` 的下载按钮；「回到首页」返回当前站点，不跳至上游站点。
8. 在中英文会话输入框键入 `/河狸` 或 `/beaver` 时，建议分组标题为「河狸」/`Beavers`；内置建议行分别显示「通用河狸」/「探索河狸」或 `General Beaver`/`Explore Beaver`，自建与插件项显示其专有名称和对应河狸来源。键盘导航的可访问名称与可视名称一致；选中后仍插入原始调用值。
9. 在 Desktop/Web 的 `/` 建议面板及设置页，所有河狸项显示河狸图标（插件独立品牌图标可保留）；小尺寸、明暗主题下可辨认，图标不重复朗读名称。选中候选项后的插入值与执行行为不变。
10. 运行侧栏、工作流时间线/图、后台任务、分享页及插件/存储说明不再以「子智能体」「子代理」或 `Subagent` 自称；技术字段和真实文件名仍原样显示。中英文切换后语义一致，历史会话可正常读取。

## 不在本次范围

- 不重写上游仓库内部符号、历史文档、遥测字段、旧数据目录及外部协议；这些是兼容边界，不等于对用户展示的产品名。
- 不修改第三方品牌、服务域名或上游许可证与归属说明。
- 不重绘其他图标资产；既有技术资产文件名可以继续保留。
