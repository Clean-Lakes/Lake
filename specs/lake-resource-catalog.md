# Lake 资源目录（首版）

## 产品规则

- 「湖」代表一个业务系统或项目，不等同于本地 workspace、远程主机或 Agent 会话。
- 「资源」代表软件运维资产。首版支持服务、主机、Kubernetes 集群、数据库四类；只登记名称、类型、环境和可选说明，不采集凭据或建立连接。
- 资源有全局稳定 ID；一个资源可以加入多个湖。加入关系按 `(lakeId, resourceId)` 唯一，重复加入不产生第二条关系。
- 目录操作：创建湖、登记新资源并加入当前湖、将已有资源加入当前湖、查看湖与湖内资源。主机资源另有桌面 SSH 入口，遵循 `specs/lake-ssh-sessions.md`；目录本身不提供监控和 Agent 自动发现。
- 页面左侧保留湖列表，右侧一次只显示一个工作面板：资源列表、创建湖、登记新资源、加入已有资源，或当前主机的 SSH 会话。切换工作面板不把未提交表单写入目录；离开 SSH 面板会释放其终端。创建/加入成功后回到资源列表。
- 湖名去掉首尾空格后不能为空，且在本机目录中不区分大小写地唯一；资源名去掉首尾空格后不能为空。资源可以同名，不能据名称推断它是同一个真实系统。
- 「生产/预发/开发/其他」仅是人工标记，不代表实时运行状态。

## 资源管理页信息架构

- 页面采用「湖导航 + 当前湖工作面板」两栏结构。左栏只负责选择湖和进入创建湖面板；右栏一次只展示当前湖概览、一个资源操作表单或一台主机的 SSH 面板。
- 当前湖概览首先展示湖名称、说明、项目目录绑定和资源总数，再提供「登记新资源」「加入已有资源」两个清晰动作。资源数量、类型分布和环境分布全部由当前 `listLakeResources(lakeId)` 结果即时派生，不新增持久化统计。
- 资源清单支持按名称和说明搜索，并可按资源类型、环境组合筛选。筛选条件仅属于当前资源面板的临时 UI 状态；切换湖后重置，不能改变目录、湖绑定或资源顺序。
- 每条资源必须突出名称、类型、环境和说明。主机资源可在桌面端进入 SSH 管理；其他类型不展示不可执行的连接、监控、健康或告警动作。
- 加载、读取失败、湖为空、湖内无资源和筛选无结果是不同状态。筛选无结果必须提供清除筛选入口，不能复用「湖内无资源」文案。
- 桌面端左栏保持稳定宽度并允许主区独立增长；窄屏改为单列，湖导航横向滚动，主要动作与筛选控件可换行且仍可完成全部目录操作。

## 所有者、接口与持久化

```text
Desktop/Web UI（表单草稿、加载与错误状态、当前资源筛选）
    → base Host 的 ILakeCatalogService（校验与唯一写入路径）
    → 本机 lake-catalog.sqlite（lakes / resources / lake_resources）
```

- 目录是应用级本地数据，远程 workspace 切换不改变目录所有者；UI 始终请求 base Host。Web 服务端部署时，目录保存在服务端应用数据目录，首版不支持跨设备同步或多租户隔离。
- 接口：`listLakes()`、`createLake(input)`、`listResources()`、`listLakeResources(lakeId)`、`createResourceInLake(lakeId, input)`、`addResourceToLake(lakeId, resourceId)`。后两个写入在事务中完成，外键必须存在；已有关系返回原资源。
- 服务返回持久化后的结果。UI 不把草稿或 optimistic overlay 当成目录事实；写入成功后重新读取，失败保留表单并提示错误。重新进入页面和窗口重新聚焦时重新读取，以便看见其他窗口的写入。
- SQLite 新文件独立于任务索引。创建目录使用异步文件 IO；数据库约束承担跨窗口去重与事务原子性。无历史数据迁移。

## 验收场景

1. 创建「订单系统」湖后，页面能选中它；重启客户端后仍能列出。
2. 在湖中登记「订单 API」服务并标记生产，湖内显示它；全局资源只新增一条。
3. 将这条已有资源加入第二个湖，两湖都可见，资源 ID 相同；重复加入不重复显示。
4. 空名称、重复湖名或不存在的 ID 返回明确错误，失败不留下孤立资源或关系。
5. 切换到远程 workspace 后仍通过 base Host 读取同一目录；未建立连接时 UI 不出现健康、在线或已监控状态。
6. 窄屏布局可完成创建湖、登记新资源、加入已有资源，并能看到加载、空状态和写入错误。
7. 在资源列表与三个添加操作之间切换时，同一时间只出现一个主操作表单；打开 SSH 后不再同时展示添加表单，返回列表时 SSH 会话按其边界释放。
8. 当前湖有多类、多环境资源时，概览数量与清单一致；输入名称或说明、选择类型和环境可组合过滤，清除筛选恢复原顺序且不写入目录。
9. 没有资源时展示登记与加入入口；有资源但筛选无结果时展示独立提示和清除筛选入口。桌面与窄屏下主要动作、湖切换和资源信息均可操作、无横向溢出。

窄屏打开湖目录时主区占满可用宽度，隐藏固定 workspace 侧栏，并在页头提供返回聊天的按钮；桌面宽度保留侧栏。
