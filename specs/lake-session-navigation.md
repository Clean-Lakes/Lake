# Lake 会话选湖与 ⌘L 快速切换

## 产品规则

- ⌘L（Windows/Linux 为 Ctrl+L）打开「会话／湖／资源」三分类快速切换面板；每次打开默认选中「会话」，清空上次搜索与展开状态。快捷键走现有可配置命令表，不挪用 ⌘K 命令中心。
- 「会话」分类先列已绑定项目目录的湖。用户选中某个湖，才展开并查询该湖的会话；未选湖时不平铺所有会话。选择会话后进入该湖绑定的工作区与对应会话。「湖」分类定位到湖的项目工作区；「资源」分类定位到资源所属的湖与目录页。
- 选中湖展开会话后，提供「在此湖新建会话」入口；它仍走统一绑定校验与草稿创建动作，不在切换器另建会话写入路径。
- 一个湖绑定一个项目工作区（`workspacePath` 用于执行；`workspaceIdentity?.trim() || workspacePath` 用于身份）。一个工作区身份最多绑定一个湖，避免会话归属歧义。创建湖时可直接绑定目录；旧湖保持未绑定，允许后来显式绑定，不自动猜测对应关系，也不迁移或改写历史任务。
- 手动新建 Agent 会话／草稿必须以已绑定湖的工作区为目标。未绑定时不创建草稿或任务，而是打开选湖面板并给出提示。选湖后复用已有工作区任务索引与运行时，不复制会话正文。已经存在的任务在工作区被绑定时自然出现在该湖下；没有绑定的历史任务不会被删除。
- 启动恢复产生的临时空白草稿仍可作为壳显示，但未绑定湖时首条消息不可提交；它不进入湖会话列表，也不成为正式会话。
- 侧栏的项目、置顶、时间线、归档和分组任务视图只投影已绑定湖的工作区；内部 conversation 工作区不会作为一个湖或其会话出现。
- 侧栏中已绑定工作区的列表按「湖」呈现：分区标题、分组/湖切换文案和本地行图标都表达湖；行主标题是目录绑定事实对应的湖名称，而不是文件夹名。工作区路径继续作为执行身份与目录操作目标，不改写 `workspacePath`、tab 身份或任务索引。远程湖保留远程连接状态的云图标，仍由「湖」分区语义说明归属。湖名变更或绑定变化后从目录服务刷新展示，不缓存第二份持久化名称；查询失败时不把文件夹名冒充湖名。
- 湖内资源仍是应用级资产目录；资源加入多个湖时，在资源分类以「资源 · 湖」区分入口，不把 SSH 终端当作 Agent 会话。远程工作区按现有 identity 隔离，同路径不同 identity 可以绑定不同湖。

## 所有者与接口

```text
⌘L / 新建会话 → UI 快速切换草稿（分类、搜索、展开湖）
                  → base Host ILakeCatalogService（湖↔工作区绑定唯一事实源）
                  → 原有 workspace task index / Agent runtime（会话唯一事实源）
                  → UI 按选中的 lake.workspaceKey 查询和投影会话
```

- `ILakeCatalogService` 增加工作区绑定读写接口；SQLite `lakes` 增加可空 `workspace_path`、`workspace_identity`、`workspace_key`，后者非空时唯一。数据库升级只加列，不修改现有湖、资源和会话数据。UI 不另存持久化的会话—湖映射。
- 快速切换面板的打开状态、分类、搜索和展开湖均是当前窗口的短暂 UI 状态。选湖产生的工作区导航通过现有 tab store；正式会话由现有 task selection 命令打开。手动新建入口在 Root 命令边界通过 base Host 校验绑定，按钮禁用本身不算校验。
- 服务读写失败时不猜测绑定：面板显示错误；新会话保持未创建。不存在的湖、空路径、重复工作区身份均拒绝。目录选择取消不创建绑定。
- 已绑定的远程湖若当前窗口没有对应远程 tab/Host，选湖或选会话时提示先重新连接；不能凭远程路径创建本地 tab。首条消息的绑定查询失败时保留草稿并阻止发送。

## 验收场景

1. 打开 ⌘L，三分类存在，默认「会话」；关闭后重新打开仍回到「会话」，不继承搜索和展开湖。
2. 未展开湖时看不到任何会话条目；展开绑定的湖只看见它工作区身份下的会话；选择会话进入正确工作区与 taskId。
3. 新建湖绑定本地项目目录；重启后绑定仍在。旧湖未绑定时可显式绑定；同一工作区不能绑定两个湖。
4. 未绑定工作区的「新建任务」入口不产生草稿或 task，打开选湖面板；绑定后可以创建，已有该工作区会话随之可见。
5. 两个远程项目路径相同但 identity 不同，湖与会话不串用。资源分类中的同一资源可在多个所属湖出现，选择后进入相应湖目录。
6. 手机和桌面均可通过可见入口完成选湖；快捷键仅在具备键盘的客户端触发。加载、空状态、错误提示有中文和英文文案。
7. 已绑定远程湖断线、原 tab 不在时，切换器不会以同名路径创建本地项目；绑定服务不可用时首条消息不提交。
8. 侧栏「湖」视图显示绑定湖的名称与湖图标；目录仍可用于文件操作。桌面与手机 Web、中文与英文均不再把该列表称作「项目」；湖绑定刷新与重启后显示一致。
