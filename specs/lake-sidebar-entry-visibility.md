# Lake 左侧栏入口暂隐

## 产品规则

- 工作区左侧栏顶部暂时不展示「搜索」「自动化」「插件市场」三个入口；「新建任务」「湖与资源」以及项目/任务列表照常展示。
- 这是导航入口的可见性调整，不删除功能、服务、快捷键或其他页面入口。尤其搜索的键盘快捷键仍可用，已有自动化任务与插件数据不受影响。
- 隐藏的入口不占布局空间，也不能通过 Tab 键聚焦；桌面和 Web 共用同一规则。

## 所有者与边界

- `WorkspaceSidebar` 是这三个入口是否可见的唯一所有者；使用代码内的临时可见性开关，不增加设置项、Zustand 状态或持久化字段。
- 现有点击回调和主视图路由保持原样。恢复展示时只调整该开关，不需要迁移数据。
- 无新接口、异步时序或远程同步行为。

## 验收场景

1. 打开工作区，左栏看不到这三个入口，也没有空白占位；「新建任务」下方直接是「湖与资源」。
2. 键盘 Tab 不会聚焦这三个隐藏入口；搜索快捷键仍可打开搜索。
3. 已有自动化和插件功能可由现有其他入口继续访问，数据不被删除。
4. 桌面和窄屏 Web 左栏都遵循同一可见性规则。
