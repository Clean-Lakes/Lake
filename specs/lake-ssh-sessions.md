# Lake 主机 SSH 会话（首版）

## 目标与边界

- SSH 是湖中 `host` 资源的访问方式，不是 Agent 对话会话，也不是 ZCode 的远程工作区。
- 一个主机资源最多有一份 SSH 连接配置；同一资源加入多个湖时共享配置，不复制凭据或运行会话。
- 配置保存地址、端口、用户名和可选私钥路径。密码另存于当前应用的 `ICredentialService` 加密凭据库，以资源 ID 为键；SQLite 不含密码，Renderer 不回读已保存的明文。当前凭据库使用 AES-256-GCM，但默认派生密钥并非系统钥匙串；用户已明确接受这一现有应用级存储边界。私钥口令和终端输入/输出不持久化。
- 从主机资源卡片打开 SSH 终端，可以同时打开多个会话，切换、主动断开和重新连接。离开湖与资源页面或关闭窗口时释放该页面的 SSH 会话；重启后只恢复配置，不恢复 TCP/PTY 会话。
- 首版限桌面本地 Host。Web、手机远控、跳板机管理、文件传输、批量命令、自动修复和 Agent 自主执行不进入本功能。

## 所有者、接口和顺序

- `LakeCatalogService` 持有 `ssh_profiles` 持久化配置，以 `resourceId` 为唯一键，写入时检查资源存在且 `kind=host`。
- `ICredentialService` 是密码密文的唯一所有者。`LakeCatalogService` 只提供保存/删除密码和“是否已有密码”状态，不提供读取明文的 Renderer 接口。保存配置和保存密码是两个明确操作；失败不伪称两者同时成功。
- 现有本地 `ITerminalService` 持有运行中的 PTY；`createLakeSsh` 以配置构造参数数组启动本机 `ssh`，不经 shell 字符串拼接。OpenSSH 负责 `known_hosts` 与交互认证；显式使用询问式主机密钥校验。Host 在标准密码提示出现后只自动发送已保存密码一次；不将密码加入命令参数、环境变量、终端输出或日志。非标准交互提示保留用户在终端手输的路径。
- Renderer 仅持有当前页面的会话标签/选中项和输入草稿；它调用服务命令并订阅现有终端数据/退出事件。后端 PTY id 是运行态唯一会话身份，不写入 Lake 资源或 Agent task index。
- 连接创建成功仅表示本机 SSH 进程已启动，不等于远端认证成功；UI 使用「终端运行中」，不伪称「已连接」。退出事件是最终状态；迟到的数据不得恢复已关闭标签。
- SSH 进程可能在 Renderer 建立数据/退出订阅前结束。Host 需暂存首段终端输出并回放退出状态，直到页面订阅或主动释放；不能让此竞态留下永远显示「运行中」的标签。

```text
保存配置 → LakeCatalogService 校验 host → ssh_profiles 持久化
保存密码 → LakeCatalogService 校验 host → ICredentialService 加密保存
点击连接 → UI 会话标签 → ITerminalService.createLakeSsh(resourceId)
                            → 读取 profile 与密码 → 本机 ssh PTY
                            → 标准密码提示时一次性写入密码 → data/exit 事件
关闭标签/离开页面 → ITerminalService.dispose(id) → PTY 释放
Agent 会话、RemoteWorkspaceSession、tasks-index：不参与
```

## 失败和安全语义

- 非主机资源、缺失配置、非法地址/端口/用户名或找不到 `ssh` 可执行文件时，不创建 PTY，并给出可理解错误。
- 用户主动取消/切换页面后，迟到的创建结果须立即 dispose；重复关闭为幂等操作。
- SSH 退出后不自动重连；用户点击重连创建新会话。连接错误、指纹变更和密码提示直接显示在终端，由用户处理。
- 自动密码只响应与当前配置的用户名和主机地址精确匹配的 OpenSSH 密码提示，不能按超时或泛化的 `Password:` 文本盲写；主机指纹确认必须仍由用户在终端进行。已保存密码不在 UI 回显，可显式删除。密码错误时不自动重复尝试，避免账户锁定。
- 不根据 PTY 字节流推断命令审计或连接成功。操作审计属于将来的受控命令接口。

## 验收场景

| 案例 | 设置与动作                         | 断言                                                 | 证据                   |
| ---- | ---------------------------------- | ---------------------------------------------------- | ---------------------- |
| S1   | 给 host 资源保存配置，重启应用     | 配置仍在；没有运行中的 SSH 会话                      | 服务测试、桌面 E2E     |
| S2   | 同一 host 加入两个湖，从任一湖打开 | 读到同一配置；会话只归属该资源，不产生 Agent 任务    | 服务测试、桌面 E2E     |
| S3   | 对数据库资源保存 SSH 配置          | 拒绝且没有孤儿配置                                   | 服务测试               |
| S4   | 点击连接、切换两个会话、断开一个   | PTY 数据只进入对应标签；断开释放 PTY；另一个保持运行 | 桌面 E2E               |
| S5   | 主机密钥未知/变化或认证失败        | OpenSSH 提示/拒绝；UI 不标注远端已认证，不存密码     | 桌面手工验收           |
| S6   | 连接过程中离开页面                 | 迟到创建结果释放；不留下隐藏 SSH 进程                | 组件测试、桌面 E2E     |
| S7   | SSH 在数据/退出订阅建立前立即失败  | 错误输出可见，标签最终为已结束；关闭后不留事件缓存   | 服务测试、桌面 E2E     |
| S8   | 保存/删除主机密码并重新进入页面    | UI 仅显示是否已保存；凭据文件无明文；SQLite 无密码   | 服务测试、桌面 E2E     |
| S9   | 已保存密码遇到标准密码提示         | 仅该 PTY 自动发送一次，参数/环境/日志不含密码        | 服务测试、桌面 E2E     |
| S10  | 未知主机指纹或非标准认证提示       | 不提前发送密码；终端仍允许用户手工确认/输入          | 服务测试、桌面手工验收 |

## 剪枝

- 远程工作区向导和远端 Agent 部署不复用：它们改变任务/工作区状态，不属于主机访问。
- Web/手机不创建本机 SSH 进程：桌面能力显式不可用，不通过超时或静默 fallback 掩盖。
- 暂不持久化会话或终端输出，也不做自动重连；密码只进入应用级加密凭据库，避免和 Agent 对话及资源目录产生第二套真相源。
